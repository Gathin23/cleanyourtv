# TCL 55P635: CleanYourTV with stock TV controls

I set up the reference CleanYourTV launcher v2.7 on my TCL 55P635 (G07), running
Android TV 11 with Google TV Home, firmware `V8-R51AT01-LF1V138`, Android build
`RP1A.200622.001`. I tested this configuration on 2026-10-24, using commit
`538d260` with changes only to `launcher/app/src/main/res/values/config.xml`.

## Controls that stopped working

During the initial package changes, I ran into these problems:

- The TV/CH, LIST and INFO controls did not work as expected, and Live TV did not
  open the broadcast channels I wanted.
- The Google TV profile button stopped working.
- The settings entry in the popup at the top right did not open settings.

I restored every package I had disabled, including the stock Google TV launcher
(`com.google.android.apps.tv.launcherx`), setup wizard
(`com.google.android.tungsten.setupwraith`) and TCL components such as
`com.tcl.dashboard` and `com.tcl.partnercustomizer`. I then checked the physical
remote and confirmed that TV/CH, LIST, INFO, profiles and settings worked again.
I restored the packages as a group, so I did not isolate which one was responsible
for each problem. I had not disabled or removed the TV player (`com.tcl.tv`) or
its input provider (`com.tcl.tvinput`).

I kept the stock packages enabled in my final setup. I used CleanYourTV's existing
Home redirection instead of replacing TCL's remote-button handling with custom
key mappings. This is a configuration report from one session, not a debloat list.

## Configuration I used

I set these values in `launcher/app/src/main/res/values/config.xml`:

```xml
<string name="stock_home_redirect" translatable="false">com.google.android.apps.tv.launcherx</string>
<bool name="key_filter">false</bool>
<bool name="restore_key_services">true</bool>
<string name="live_tv_package" translatable="false">com.tcl.tv</string>
<string name="live_tv_input_id" translatable="false">com.tcl.tvinput/.TDTVInputService/HW1413742848</string>
```

I enabled `HomeKeyService` to redirect stock Home to CleanYourTV, with key
filtering disabled. I also enabled `restore_key_services`, which requires the
`WRITE_SECURE_SETTINGS` grant. These are existing launcher options; I did not
change Java code or the defaults for other TVs. Setting these values alone does
not enable the accessibility service; see the
[launcher and remote-key guidance](../../README.md#the-launcher).

## Opening broadcast TV from the launcher

I added `com.tcl.tv` to the dock. My TV had an aerial connected, but it was also
using TCL's internet channels, so opening the TV app alone did not reliably take
me to terrestrial TV.

I used the tuner input reported on my set,
`com.tcl.tvinput/.TDTVInputService/HW1413742848`, for `live_tv_input_id` so the
launcher selects the broadcast input explicitly. I checked broadcast playback
and could edit the terrestrial channel list through TCL's normal UI. The input ID
should be checked on the target TV before copying it to different firmware.

## What I checked

I confirmed the restored physical controls before reapplying the final launcher
configuration. I subsequently exercised CleanYourTV and its broadcast-TV entry,
but I did not repeat the complete remote-button check afterwards. I have not
validated the coloured teletext buttons, HDMI-CEC or several days of normal use.

I kept the original package and accessibility settings backup. To return to
stock Home, I can turn off CleanYourTV's Home helper in Android's accessibility
settings and restore the original Home selection; the stock packages remain
enabled. Other accessibility services should be left as they were.
