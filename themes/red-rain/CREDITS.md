# Wallpaper credits

- `wallpaper.jpg`: a red digital code rain, frozen on pure black, drawn from code for this
  theme by rotkppchn and released under CC0 1.0 (public domain dedication), not MIT. Columns of katakana, letters
  and digits in dark crimson (#B52239) on three depth layers; the glyphs behind the clock, the top buttons and the
  dock are dimmed so they stay readable. Saved as a JPEG without chroma subsampling (4:4:4, quality 95), so the
  red edges stay sharp on black.

The glyphs are rendered with Noto Sans CJK JP (Google, SIL Open Font License 1.1), the font Android TV ships;
the font itself is not included.
