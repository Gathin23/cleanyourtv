# Quirks on this firmware:
# - Network ADB is Wireless debugging only. Port 5555 refuses connections. The port is random and changes
#   whenever Wireless debugging restarts, the TV reboots or it rejoins Wi-Fi; scan the TV's own TCP ports and
#   use the one that answers as a device (stale ones answer offline).
# - The saved Wi-Fi network belongs to setupwraith (dumpsys wifi shows cname=...setupwraith), and Android
#   deletes it when the wizard is disabled, which takes the TV off Wi-Fi and ADB. Forget the network and
#   rejoin it in Settings first: afterwards dumpsys wifi shows android.uid.system:1000 as owner.
#   tools/disable.sh refuses the list until then.
# - cmd package set-home-activity prints Success and changes nothing here, also after a reboot. Disabling
#   launcherx on its own sends Home to setupwraith/.RecoveryActivity. Disable setupwraith, then launcherx:
#   Home then opens com.gathin.tvhome. The launcher package is commented out below so disable.sh does not remove
#   Home first; launcher/build-and-install.sh disables it after the new home is installed.
# - The stock screensaver is com.google.android.apps.tv.dreamx/.service.Backdrop. It was switched off with
#   settings put secure screensaver_enabled 0 (and screensaver_activate_on_sleep, screensaver_activate_on_dock),
#   rather than by disabling dreamx.
