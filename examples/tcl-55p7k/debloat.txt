# TCL 55P7K, Middle East (device G10, product G10_4K_GB, model "Smart TV Pro", Realtek RTD2875P, 1.8 GB)
# Android 12 (Google TV), firmware STT2.230203.001 AS16
# Same G10 platform and build as tcl-g10-google-tv/, but with Middle East preloads (OSN+, Disney+ MEA,
# iQIYI, Shahid) and nothing disabled at the factory: logkit, Samba TV ACR and ttvs all ship ENABLED.
# Second unit: TCL 55C655 (2024), Italy, same build (G10_4K_GB, STT2.230203.001 AS16, BT_RC833_U1 remote).
# Same factory state; it ran everything above except the streaming apps, Alexa and T-Solo (kept by choice)
# plus the extras at the end, for a day and two reboots. No com.tcl.browser and no com.tcl.hotelmenu on it.
# Remote buttons, the Web key and power-on on that unit: README.md.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-55p7k/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-55p7k/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
# Lived with for a day and a reboot so far, with a custom launcher as Home; nothing broke.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.tcl.tv.
# Keep: com.tcl.tv, com.tcl.tvinput, com.tcl.suspension (the Input picker, VIEW_INPUTS), com.tcl.dashboard,
# com.tcl.autopair, com.tcl.systemserver, com.android.tv.settings (also runs TCL's quick panels).
# com.tcl.browser is kept here because the remote's Web key opens it.
#
# Known quirks on this firmware:
# - Same as the other G10 sets: setupwraith claims Home once launcherx is disabled, so it goes too.
# - The remote sends Settings as KEYCODE_NOTIFICATION (83), Netflix and YouTube as KEYCODE_TCL_NETFLIX and
#   KEYCODE_TCL_YOUTUBE, and the Web key as raw code 4159. Keys injected with `input keyevent` never reach
#   an accessibility service; test remaps with the real remote.
# - Android's screen_brightness does nothing (TCL drives the backlight). TCL's own Audio Only mode turns
#   the panel off with sound playing: `am startservice -a com.tcl.settings.SHOW_WINDOW -p
#   com.android.tv.settings --es Type AudioOnly`.
# - App log lines rarely show up in logcat (64K buffer); write diagnostics to a file instead.
