# Notes from this stick:
# - HOME claimants on stock: com.google.android.tvlauncher/.MainActivity and
#   com.android.tv.settings/.system.FallbackHome. Unlike Google TV builds (such as MiTV-AFMU0/AFMU1),
#   com.google.android.tungsten.setupwraith does NOT claim HOME here, so setupwraith can stay enabled
#   and the saved Wi-Fi network (owned by setupwraith) does not need to be forgotten and re-joined.
# - The Bluetooth remote ("Xiaomi RC Consumer Control", vendor 0x2717 product 0x32b9,
#   /vendor/usr/keylayout/Vendor_2717_Product_32b9.kl) sends standard KEY_HOMEPAGE (scancode 0x000c0223 -> HOME)
#   on the round Home button, not ALL_APPS, so HOME_KEY_SERVICE=1 is not needed.
# - HDMI-CEC One Touch Play works with the custom launcher: system_server (HdmiControlService) sends
#   <Text View On> and <Active Source> before starting the HOME activity.
# - Kept on purpose: Google Assistant (katniss), Chromecast (mediashell), phone remote (tv.remote.service),
#   Miracast (smartshare, wfdsinkhelperservice), the Mi screensaver (com.mitv.dream),
#   com.xiaomi.tvqs.overseas (quick settings panel), com.xiaomi.android.tvsetup.partnercustomizer,
#   com.google.android.tungsten.setupwraith.
# - com.google.android.tvrecommendations does not stay disabled: com.droidlogic re-enables it on every boot
#   (lastDisabledCaller: com.droidlogic), so it is commented out below. The custom launcher never asks it for rows.
