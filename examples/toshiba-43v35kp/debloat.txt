# setupwraith: com.google.android.tungsten.setupwraith is disabled in this list. On this firmware
# it did NOT claim HOME (confirmed: set-home-activity succeeded without it). Its RecoveryActivity
# was not observed claiming Home. Check `dumpsys wifi | grep -o 'cname=[^ ]*'` first; if the TV's
# active Wi-Fi network belongs to setupwraith, forget and re-join it in Settings before running this.
# Note: setupwraith is kept on examples/motorola-mt4310 (also hayward). Disabling setupwraith gives Home back
# but costs Chromecast built-in (casting); keep it enabled if you cast.
#
# com.at.factory.factorymanager: disabled and confirmed safe on this unit. On examples/motorola-mt4310
# (same board, different firmware) it re-enables com.google.android.katniss and tvrecommendations at
# every boot. That was NOT observed here — katniss and tvrecommendations remained disabled across
# a full cold boot. Leave it enabled if you are unsure, or if those packages come back after a reboot.
#
# com.google.android.tvrecommendations: also confirmed stable across a full cold boot here. Disabled.
# If recommendations rows reappear after a reboot, re-enable it and leave it in; on other hayward
# firmware variants com.at.factory.factorymanager re-enables it at boot automatically.
#
# Status: disabled in batches on 2026-11-01. Full cold boot (mains power-off) verified on 2026-11-02.

# working as a side-effect. Leave it enabled if you use voice or the accessibility reader.
