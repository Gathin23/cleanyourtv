# KEEP, even though the names look like bloat (checked on this TV with dumpsys package):
# - fusion.android.tv.demo: receives com.mstar.android.intent.action.TV_INPUT_BUTTON (the remote's Input
#   key), as on examples/jvc-android-tv-menlo. The Panasonic SW4H list disables it; do not copy that here.
# - com.mediatek.partner.netflix: serves a TvInputService and handles the Netflix button.
# - com.mediatek.wwtv.tvrecommendation: asks for TV_INPUT_HARDWARE (disable.sh would skip it anyway).
# - com.smartdevice.firewall (purpose unclear), com.smartdevice.dtv.icast (CastPlay), com.tianci.localmedia
#   (USB media), com.google.android.backdrop (kept; the launcher's Clock is set as the active screensaver),
#   katniss (Assistant), mediashell (Chromecast), tv.remote.service: kept by the owner's choice.
# - Every streaming / user app is kept and shows in the launcher grid.
#
# Status: applied in four batches on one TV on 2026-10-22, with a screenshot and a Live TV / Input-key check
# after each; tools/restore.sh tested after batch 1 (package lists and Home identical to a snapshot), then
# re-applied. Verified after two reboots: nothing re-enabled (tools/check.py clean), launcher/ is Home, Inputs
# menu (HDMI 1-3, AV, Live TV), Live TV, Netflix, and on the real remote Home, Back, Input (Skyworth source
# panel), Netflix, YouTube, mic and Settings keys all work with no key service. Hours of use, not days yet.
# Measured at 180 s uptime after a reboot: Home drawn at 48.2 s -> 40.2 s, used PSS 810 MB -> 739 MB.
#
# Quirks on this firmware:
# - /proc/meminfo MemAvailable and dumpsys "Free RAM" report impossible values (hundreds of GB of cached
#   kernel memory on a 1.7 GB set): compare Used RAM (PSS) instead.
# - The Home handover needs the stock launcher disabled: with tvlauncher enabled (priority 2) Home keeps
#   resolving to it even after `set-home-activity` prints Success, so run launcher/build-and-install.sh with
#   the default STOCK_LAUNCHER (it disables tvlauncher, checks Home and rolls back on its own). setupwraith
#   (priority 4) did not take Home afterwards.
# - /vendor/etc/global_settings.txt forces animator_duration_scale=0.6 at every boot; window and transition
#   scales set to 0.5 stick.
# - USB debugging alone opened port 5555; ro.adb.secure=1.
# - Yango Play, Jawwy TV and STARZ ON wake at every boot from their own WorkManager/recommendation
#   receivers (~300 MB together). Kept installed here; `cmd appops set <pkg> RUN_ANY_IN_BACKGROUND ignore`
#   then `cmd appops write-settings` (survives reboot) leaves them cached-empty and stops Yango's
#   :passport and :AppMetrica processes; used PSS 739 MB -> 679 MB. Undo: `cmd appops reset <pkg>`.
