# TCL Q7C QD-Mini LED, Europe (device G08, model "Smart TV Pro", product G08_4K_GB, MediaTek tcl9618)
# Google TV, Android 14 (SDK 34), firmware UTT2.250416.001 AU02 - the same build as examples/tcl-85rm7l-google-tv.
# About 2.4 GB RAM. Set up on Ethernet in Austria (German/Austrian apps: ORF ON, Joyn, ServusTV, ZDF).
# This list goes further than the 85RM7L one: launcherx and setupwraith are off for the Clean Your TV launcher,
# and voice, AirPlay, mirroring and several streaming apps are off by the owner's choice.
#
# Tested on one set from 21 October 2026. Disabled by hand with `pm disable-user --user 0`, one call each, in five
# batches with a screenshot after each. The first 35 survived a reboot, none came back (three self-installed
# apps disabled alongside them are not listed here). launcherx and setupwraith were disabled afterwards, once the
# new launcher was installed. YouTube, Live TV and the HDMI input list checked.
# Second unit: TCL 65Q7D Pro, Greece, same build (AU02), on Wi-Fi, one day from 22 October 2026: this list minus
# AirPlay and com.tcl.UpdatePeripheral (kept), plus mediashell; Wireless debugging only. See README.
# Third unit: TCL 55Q6C (Smart TV Pro, G08_4K_GB), Vietnam, same build (AU02), on Wi-Fi, one day from 23 October 2026:
# 24 of this list (voice, Chromecast, AirPlay, Miracast, Netflix, the USB player, T-Solo, hearing test and soundbar
# updater kept), plus com.google.android.youtube.tvmusic. launcherx and setupwraith stay ENABLED so Chromecast keeps
# its credentials; Home goes to the new launcher through stock_home_redirect instead. Survived two reboots. See README.
# Fourth unit: TCL 65T8C, same build (AU02), on Wi-Fi, from 23 October 2026: AirPlay, Prime Video and mediashell kept,
# more TCL extras and the TCL keyboard off (Gboard set first); Wireless debugging only. See README.
#
# Apply:   FORCE_SETUPWRAITH=1 TV_HOST=<tv ip> tools/disable.sh examples/tcl-q7c-google-tv/debloat.txt
#          FORCE_SETUPWRAITH=1 only on Ethernet with no saved Wi-Fi: disable.sh otherwise skips setupwraith because
#          it cannot see a Wi-Fi owner. On Wi-Fi, check `dumpsys wifi | grep cname` first (README).
#          launcherx is skipped by disable.sh's Home guard until the new launcher is Home; see README for the order.
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-q7c-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
