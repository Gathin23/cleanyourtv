# This set has no Play Store and no Google apps: the stock home is Dangbei ChinaHome, not
# Google TV, so the Google TV lists in this repo do not match it row for row.

# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-kd-55x80j/debloat.txt

# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.

# Stock launcher / Home:
#   com.dangbei.TVHomeLauncher/com.dangbei.leard.leradlauncher.ui.sony.main.MainActivity
#   (当贝桌面 "电视桌面"; system_ext/priv-app/ChinaHome)
# It is not in build-and-install.sh's known stock launchers, so install the reference launcher
# with STOCK_LAUNCHER=none and set Home with 'cmd package set-home-activity'; the Undo line
# passes com.dangbei.TVHomeLauncher so the original Home can be put back.
# Live TV / tuner app: com.sony.dtv.tvx (.MainActivity). Keep com.sony.dtv.tvinput.*, tvapi,
# sonysystemservice, settingsprovider, braviasync* (HDMI-CEC), irblaster/irbservice,
# remotecontrolsettings, recapp, reminderservice, timers, com.uei.quicksetsdk.sony, imeproxy,
# webapi.core (Sony IP control), homenetwork and all com.mediatek.*: they drive HDMI, the
# tuner, CEC, the remote, recordings and the network.
# Kept by owner's choice: OTA (systemupdate), Sony Media Player (osat.album/music/video),
# i-Manual (imanual), the IR blaster settings (irblaster), the phone remote
# (tv.remote.service*) and 乐播投屏 (com.hpplay.happyplay.aw, the only casting path here).
# Not on this build at all: Google's assistant and cast apps (katniss, tv.assistant,
# assistantadapter, voicesearch, apps.mediashell) and Sony's AirPlay app.
# Off from the factory, and left off: com.sony.dtv.b2b.softap and
# com.sony.dtv.b2b.vendorprotocol (the shell cannot toggle the latter).
#
# Quirks on this firmware:
# - /data is small on this class of set and was 99% full with a few streaming apps: run
#   'pm trim-caches 1G' before installing the launcher or the install fails with
#   "Requested internal only, but not enough space".
# - 'svc power reboot' is killed on this firmware; use 'adb reboot' and check 'uptime'.
# - A key remapper (Button Mapper) sending Home to another launcher breaks the Home button.
# - PackageManagerService flushes packages.xml a while after the disables, so a reboot right
#   after a batch can bring the packages back. Wait a minute before rebooting; with that
#   wait the state held across a reboot on this set (checked 2026-11-01).
#
# Disabled on this set on 2026-11-01 and reboot-checked the same day: Home stayed on the new
# launcher and the state survived the reboot. The set was restored to its factory state
# afterwards, so this list records that run rather than the set's present state.
#
