# examples/tcl-85rm7l-google-tv; that list was the starting point.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-c89b-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-c89b-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Theme:   TV_HOST=<tv ip> tools/theme.sh examples/tcl-c89b-google-tv   (config.json: Live TV, remote keys)
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Tested 2026-10-21 on one C89B set on Ethernet, applied in batches with screenshots between them: Home, the
# Inputs menu (HDMI 1-4 and Live TV), the Chromecast, AirPlay and Miracast processes, and the remote's
# gear, Netflix, Prime Video and YouTube buttons worked; the disabled set was identical after a reboot,
# and HomeKeyService bound on its own after another once AUTO_START was saved. One day of use, not weeks.
#
# Second unit: TCL 65C89K, France (Smart TV Pro, G08, G08_4K_GB, Google TV 14, UTT2.250416.001 AU02).
# Status 2026-11-02: the owner used the launcher for several days. Home stayed the default launcher;
# the theme, Sources, Live TV and Ethernet were used. This unit keeps Game Bar and the
# hearing test, so their lines below are comments. Its personal theme and optional add-ons are not part of
# this shared list.
#
# Connection: USB debugging alone opens port 5555 on Ethernet. Wireless debugging switches itself back off
# there: Android only enables it on Wi-Fi.
#
# Launcher, in this order: launcher/build-and-install.sh with STOCK_LAUNCHER=none (installs it, then stops
# with an error because Home stays on launcherx), then this list (setupwraith is listed before launcherx, so the wizard never gets Home;
# it owned no saved network here), then enable HomeKeyService with the settings command
# build-and-install.sh runs for HOME_KEY_SERVICE=1.
# TclAppBoot blocks HomeKeyService at every boot until the launcher has AUTO_START, saved to disk:
#   TV_HOST=<tv ip> tools/venv/bin/python -I tools/tv.py 'appops set com.gathin.tvhome AUTO_START allow; appops write-settings'
#
# Remote (BT_RC933_U1): every TCL button arrives on scancode 240 and TCL's own key table picks the keycode,
# so config.json matches keycodes: gear 83, Netflix 4062, Prime Video 4099, YouTube 190 (BUTTON_3). The
# owner pointed 190 at SmartTube (org.smarttube.stable). The Input button works without a service. Info,
# TV and LIST are Live TV keys and do nothing on Home.
#
# Kept: Chromecast, AirPlay, Miracast, Google Assistant (katniss), com.google.android.tv.remote.service (the
# remote's mic), the USB media player and gallery, com.tcl.tv, com.tcl.suspension, and Netflix, Prime
# Video and Disney+.
