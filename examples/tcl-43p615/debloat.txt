# TCL 43P615 (ro.product.model BeyondTV, board RTD2851, Android TV 11, API 30,
# build PPR1.180610.011 AR06, fingerprint TCL/BeyondTV/BeyondTV:11/PPR1.180610.011/AR06).
# Sibling firmware of examples/tcl-beyondtv2-android-11 (AR05, board rtd285o): same package
# set except com.tcl.tv.tclhome_master (absent here; only tclhome_passive) plus a few extras
# below that AR05 does not ship. UK/EU set: the 15 uk.co.freeview.* catch-up apps, au.com.stan.and,
# com.google.android.apps.nbu.smartconnect.tv and com.tcl.gallery were already disabled at the
# factory and are left alone.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-43p615/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-43p615/debloat.txt
# Install the launcher BEFORE disabling the stock launcher (launcher/build-and-install.sh).
# Stock launcher: com.google.android.tvlauncher (priority 2). Other HOME claimants are only
# fallbacks: com.tcl.keycustomfunctionservice/.FallbackHome and com.android.tv.settings
# FallbackHome; setupwraith does not claim HOME on this build.
# Live TV app: com.tcl.tv. Tuner and HDMI: com.tcl.tvinput (never disable either).
# 2 HDMI ports and AV through the TV input framework, TvInputManager lists them normally
# (with the input labels the owner set in Settings), so the launcher's Inputs menu needs
# no source_panel_service.
#
# Tested 2026-10-21 on a real unit, applied in six batches with a screenshot after each,
# and then verified over three reboots (final state identical). Wi-Fi, D-pad, the Inputs
# menu, Live TV, Play Store, TV Bro, SmartTube and the remote's app/Input/Settings buttons
# all worked after the changes, also after replacing the stock launcher. Not yet lived
# with for weeks; treat the list as reboot-checked rather than long-term.
#
