# Hisense 43QD65QFC Fire TV (Amazon model AFTOLCBC82, codename ginza, MediaTek), Fire OS 8.1.8.0
# (RS8180.3746N), Android 11 (SDK 30), 1.8 GB of RAM, US market. The 43-inch sibling of the 55QD6QF
# whose list is debloat.txt beside this one: the same AFTOLCBC82 model code on the same build, so the
# two units share a folder and each has its own list. Every name below was checked as installed on
# THIS set with pm list packages before it was disabled.
#
# FIRE OS: DEBLOAT ONLY. com.amazon.tv.launcher (Home: .ui.HomeActivity_vNext) is protected, and Fire OS
# never hands Home to a third-party launcher, so launcher/ does not apply here; the stock Home and Live TV
# (com.amazon.vodcsp.livefiretv) are kept. AirPlay, casting, the input row, Silk and the firmware updater
# are kept. Wi-Fi is owned by com.amazon.tv.oobe: never disable it.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/hisense-fire-tv-55qd6qf/debloat-43qd65qfc.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/hisense-fire-tv-55qd6qf/debloat-43qd65qfc.txt com.amazon.tv.launcher
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
#
# Reported by @rabbit718 in #3523 (opened 2026-11-07): applied with tools/disable.ps1 over the native-ADB
# backend, each name checked as installed first, then rebooted. tools/check.py read 0 drift after the
# reboot and Home was still com.amazon.tv.launcher/.ui.HomeActivity_vNext; 547 MB free of 1.8 GB at boot
# after. Netflix, YouTube, Prime Video, Apple TV, Spotify, casting, AirPlay, HDMI-CEC, the input row and
# the firmware updater all worked. One session on one unit and one reboot read back, so this is not a
# multi-week soak test.
#
# How this list differs from debloat.txt (the 55QD6QF, Canada):
# - com.tubitv.ott is not a line here: Tubi is a user-installed app on US sets rather than a retailer
#   preload, and it is not installed on this set. naatyam and miniTV ARE installed here and stay off.
# - com.amazon.providers.contentsupport is commented out, although this owner disabled it. The 55QD6QF
#   header measured what that costs: with it off, voice typing inside apps stops (the Fire TV keyboard
#   logs "Voice input is disabled since user's locale = en_US is not supported") while the remote's
#   Alexa button still works. Uncomment the line if you do not voice-type inside apps.
# - com.amazon.vizzini (Alexa voice) stayed DISABLED_USER across the reboot here, where the 55QD6QF has
#   it coming back at every boot. Re-check after a reboot and re-run this list if it does come back.
#
# ADB quirk on this firmware (ro.adb.secure=1): the "Allow USB debugging?" popup only renders when a
# fresh client challenges right after adbd restarts. If a connection sits at unauthorized, start the
# client and toggle ADB debugging off and on; adbd serves one client, so kill other adb clients first.
# "Always allow from this computer" persists across reboots, and the ADB debugging switch itself
# survived the reboot here. Turn ADB debugging off in Developer options when you are done.
#
# Living with this set: the Home tiles of the disabled retailer preloads linger until cleared per app
# from Settings > Applications > Manage all installed apps. The owner also runs AdGuard's Private DNS,
# which thins the sponsored banners in the Home feed; the rows themselves stay.
