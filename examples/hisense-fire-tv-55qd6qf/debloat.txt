# Fire OS 8 notes on this set:
# - com.amazon.vizzini (Alexa voice) comes back ENABLED AT EVERY BOOT, as on hisense-fire-tv-aftcibfbd1/; the rest of
#   the Alexa group stays off. Re-run the list after a reboot if you don't use Alexa.
# - Third-party apps preinstalled by the retailer or Hisense (Bell Fibe TV / Crave, VIDAA, a YouTube player, Twitch)
#   came back ENABLED after a reboot when disabled. They are ordinary user apps, so they are not in this list;
#   remove them in Settings > Applications if you don't want them.
# - The saved Wi-Fi network belongs to com.amazon.tv.oobe (`dumpsys wifi | grep -o 'cname=[^ ]*'`): never disable it.
# - No package in this list was refused; the protected ones are the same as on hisense-fire-tv-aftcibfbd1/.
# - AdGuard Private DNS works (mads.amazon-adsystem.com resolves to 127.0.0.1) and removes the third-party ads from the
#   hero banner; Amazon's own promotions stay (they come from the protected launcher's feed).
# - Animation scales at 0.5 make the ☰ side menu open nothing, as on amazon-fire-tv-stick-4k-2023/.
# - ADB Debugging switched itself off after one of the three reboots: check Developer Options before running a script.
#
# For launcher authors (what Fire OS 8 reserves to Amazon here, read from the APKs' manifests):
# - Switching to an HDMI input: com.amazon.tv.inputpreference.service's PassthroughPlayerActivity needs
#   com.amazon.tv.permission.TUNE_INPUT, InputTabActivity and StartAmazonInputActivity LAUNCH_INPUTS,
#   GameBoardInputSwitchActivity SET_UPDATE_INPUT_STATE; the standard passthrough request opens Live TV. The remote's
#   Input button and HDMI-CEC still work.
# - The Home key never reaches an accessibility service's key filter, and the CLOSE_SYSTEM_DIALOGS "homekey" broadcast
#   requires com.amazon.permission.ENABLE_KEYGUARD_FLAGS (signature|privileged|amazon).
# - ACTION_SETTINGS goes through Amazon's Home; the settings grid itself, com.amazon.tv.launcher/.ui.MainSettingsActivity
#   (action amazon.intent.action.MAINSETTINGS), is exported without a permission.
# - The Appstore (com.amazon.venezia/.grid.AppsGridLauncherActivity) has no screen of its own: it opens Amazon's Home on
#   its Apps page.
# - An accessibility service that opens another home screen over HomeActivity_vNext works as a replacement Home.
#
