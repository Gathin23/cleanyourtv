# ADB: this GMUI 6 build has no working ADB switch in Developer options. Network ADB was opened with
# the open-source code-ant/z7x-adb app (package local.z7x.adb), installed from USB after renaming the

# look for a switch; the repository's rules forbid starting factory/test packages. The firmware
# reports ro.adb.secure=0: while adbd runs, any device on the LAN has a shell. Deep standby drops
# the TCP connection after about 70 seconds; adb connect again.
#
# XGIMI Settings is a service window, not an Activity: android.settings.SETTINGS resolves to nothing.
# The Settings UI is com.android.newsettings / com.xgimi.newsettings.SettingService, action
# com.xgimi.settings.SETTINGS. The launcher's Settings pill needs
# com.android.newsettings/com.xgimi.newsettings.mock.MockActivity in settings_fallback_components
# (config.xml only; see README.md) and a <queries> entry for com.android.newsettings.
#
