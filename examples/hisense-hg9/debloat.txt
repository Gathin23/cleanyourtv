# Hisense HG9 (HiSmart 4K A4FFM, device laohushan, MediaTek), Android TV 9 (API 28),
# build PTMR.190127.037, security patch 2021-02-05, kernel 4.9.118. 2 GB RAM class.
# Tested on a set used as an Apple TV display over HDMI.
#
# Stock launcher: com.google.android.tvlauncher (pass it to restore.sh; replaced
# here by FLauncher from the Play Store, not launcher/, set as default with
# `cmd package set-home-activity me.efesser.flauncher/.MainActivity`).
# Live TV app: stock Live TV was left alone; HDMI input is com.hisense.tv.hitvinput.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/hisense-hg9/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/hisense-hg9/debloat.txt com.google.android.tvlauncher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Reboot-tested: the TV boots normally with this full list applied, including
# com.hisense.tv.smartsense, com.vt.tv.smartsense.ui and
# com.hisense.tv.smartservice all disabled (verified after a settings-reset
# reboot, followed by a full evening of use: streaming, Store, launcher).
# This differs from the #45 SmartTV 4K FFM (Android TV 10) report where the
# smartsense pair sent that set to Recovery — model/firmware difference, HG9
# on Android TV 9 is unaffected.
#
# Notes from this firmware:
# - USB debugging alone does NOT open network ADB; the TV needs its explicit
#   Network/Wireless debugging toggle too, plus a reboot before port 5555 opens.
# - The Beryl/GL.iNet "block client" toggle deauths the TV entirely (no join at
#   all), it is not a WAN-only block. Debloat over an isolated offline LAN instead.
# - com.google.android.tungsten.setupwraith re-enables the stock launcher, so it
#   is listed (per the FLauncher README method).
# - Play Store showed "Something went wrong" with AuthFailureError even after
#   re-signing in; `pm clear com.google.android.gsf` + reboot + fresh sign-in
#   fixed it. The tvrecommendations prefetch errors in Finsky logs are a red
#   herring (they persist with the services enabled and are non-fatal).
# - Kept deliberately: hitvinput + mtktvapi_agent + tvcenter (HDMI/tuner),
#   tv.settings/providers.tv, Play Store + Play Services, remote keys (kpad,
#   hotkey dispatcher, autopair), Bluetooth, latin IME, system UI, Alexa,
#   Chromecast, DLNA service, OTA updater, phone-remote service (lost-remote
#   fallback), and the MStar disclaimer customizer (first-boot legal text).
# - Netflix, Prime Video, YouTube, Apple TV, Pluto, Vudu, Hulu apps kept and
#   updated through the Play Store. Pandora, Peacock, Kids, Play Games, Max,
#   Paramount+, MediaCenter removed by owner choice (Apple TV is the streamer).
