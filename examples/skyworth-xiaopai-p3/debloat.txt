# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Lived on for a few days on a 2019 box with 2 GB RAM: the aim was a box that lands in a clean
# launcher and starts live TV by itself, for someone who only wants to press the power button.
#
# Two things about this firmware, worth knowing before you disable anything:
#   - Home is filtered by package-name PREFIX. logcat says "PackageManager: block home apk <pkg>"
#     or "allow home apk <pkg>"; the whitelist is prefix-matched and includes com.ktcp.launcher,
#     so a sideloaded launcher only becomes selectable when its applicationId starts with one of
#     those prefixes. `settings put global enable_launcher_components` and
#     `setprop sys.launcherlist.enable 0` are both reset on boot - do not spend time on them.
#   - Every third-party boot receiver is blocked: "BroadcastQueue: Block auto start app from
#     broadcast: <pkg>". BOOT_COMPLETED never reaches a sideloaded app, and neither does a
#     foreground-service self-restart. The only thing that worked was the launcher itself calling
#     startForegroundService for our own service on its first start after boot.
#   - The screensaver is rewritten to the Skyworth ad component on every boot, so setting it back
#     is not a one-off either.
#
# Miracast is off here because nobody casts to this box; comment it back in if you do.
# The stock launcher is last, and only because a replacement was confirmed as Home first.
