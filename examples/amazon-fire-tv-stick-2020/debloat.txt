# Amazon Fire TV Stick, 3rd gen 2020 (AFTSSS, codename sheldonp), Fire OS 7.7.1.7 (PS7717/5741, build PS7717.5741N), Android 9 (SDK 28), India
# Same Fire OS build and platform as amazon-fire-tv-stick-lite-2020/ (AFTSS, sheldon): every package on that list is
# present here and disabled the same way. Added: Spotify-for-Alexa; casting is commented out below (off on this stick by choice).
#
# FIRE OS: DEBLOAT ONLY. com.amazon.tv.launcher is a protected package and keeps Home; launcher/ does not apply.
#
# Apply:   TV_HOST=<stick ip> tools/disable.sh examples/amazon-fire-tv-stick-2020/debloat.txt
# Undo:    TV_HOST=<stick ip> tools/restore.sh examples/amazon-fire-tv-stick-2020/debloat.txt com.amazon.tv.launcher
# Everything is DISABLED for user 0, never uninstalled. Comment out any line you want to keep.
# ADB on Fire OS 7: Settings > My Fire TV > Developer Options > ADB Debugging. Port 5555, accept the prompt on the TV.
# Switch it off again afterwards (`settings put global adb_enabled 0` from the shell does it; 5555 then refuses).
#
# tools/disable.sh holds back three entries on this build, and says why:
#   com.amazon.tv.livetv (opens inputs and channels: a stick has no HDMI inputs, so HANDLERS_ALLOW=1 is safe here),
#   com.amazon.systemnotices and com.amazon.wha.mediabrowserservice (dumpsys shows no permission block, so the
#   input-driver check cannot read them: TVINPUT_ALLOW=1 once the stick has rebooted with the rest disabled).
# They were applied in a second run with those two overrides, as the Stick Lite list disables them on the same build.
#
# Rebooted twice after applying: all 55 (52 listed + the 3 casting lines) stayed disabled, Home, Prime Video, YouTube and Hotstar open, Wi-Fi works,
# Alexa voice search from the remote mic works in YouTube and Hotstar. com.android.nfc is disabled from the factory.
#
# Kept on purpose: com.amazon.tv.launcher, com.amazon.tv.settings.*, com.amazon.venezia (Appstore), com.amazon.tv.ime,
# remote/Bluetooth services, OTA updates, Alexa voice search (com.amazon.vizzini, aria, cardinal, ivona TTS, tcomm),
# Prime Video (com.amazon.firebat, com.amazon.tv.support), miniTV (com.amazon.minitv.android.app), YouTube
# (com.amazon.firetv.youtube), whisperplay/whisperlink (phone remote app; whisperlink is protected), profiles
# (com.amazon.prism.android.service), com.amazon.tv.oobe, screensaver, accessibility (com.amazon.logan).
# Protected on Fire OS 7 per the Stick Lite and other Fire TV lists (not retried here), so left out: com.amazon.minerva.client.api, com.amazon.device.logmanager,
# com.amazon.device.crashmanager, com.amazon.diode, com.fireos.usagestats.proxy, com.amazon.ftvads.deeplinking,
# com.amazon.device.metrics, com.amazon.tv.csapp.
#
# What the list cannot remove: the hero rotator ads and the Prime Video promo rows come from the launcher's own feed,
# and the Live icon stays in the top menu (its channel rows go). Privacy Settings and Featured Content autoplay
# toggles are by hand on the remote, as the Stick Lite list describes.
