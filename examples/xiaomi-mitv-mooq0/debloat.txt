# Xiaomi Mi TV (MiTV-MOOQ0, codename croods), Android TV 10, firmware QTG3.200305.006.3270
# MediaTek m7632 chassis, 1.8 GB RAM, Android low-RAM mode on.
#
# Also applied cleanly on firmware QTG3.200305.006.5135 (Vietnam retail unit, 2026-10): every package
# here disabled the same, and the "optional, by choice" mirroring/media apps below were additionally
# disabled (wfdsinkhelperservice, milinkservice, smartshare, mitvplus, videos, youtube.tvmusic,
# mediaexplorer, videoplayer) with Netflix/YouTube/VieON still playing afterwards. On that unit the
# remote's Input/Source button sends KEYCODE_MEDIA_RECORD (kernel KEY_RECORD), not KEYCODE_TV, so the
# launcher's InputKeyService must handle KEYCODE_MEDIA_RECORD for the Input button to open the menu.
#
# ---- Android TV 11 variant: Xiaomi Mi TV P1 43" (MiTV-MOOQ0, croods, EU) ----
# Firmware RTM4.220307.164.8835 (2026-10). The selected subset was applied and the TV remained
# usable after a reboot; this does not claim every Android TV 10 entry was tested on Android TV 11.
#
# Kept enabled by choice: Google Backdrop, Miracast, Mi Cast and USB media players. Playback and
# mirroring were not separately re-tested. com.xiaomi.floatingframe is installed and was left enabled.
# These entries from the Android TV 10 list are not installed on this build:
# com.google.android.tv.bugreportsender, com.aha.mitv, com.xiaomi.mitv.handbook,
# com.jio.web.androidtv, com.google.android.youtube.tvkids, com.duokan.factorytest,
# com.google.android.leanbacklauncher, com.google.android.leanbacklauncher.recommendations.
#
# Netflix returned after a reboot when disabled (the firmware turns it back on).
# NetflixObserver is inside the core com.mediatek.tv.service APK; keep that service enabled. Details:
# ../../docs/devices/xiaomi-mitv-mooq0-android11.md.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-mooq0/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-mooq0/debloat.txt
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
#
# Kept deliberately, despite names that look like bloat. Checked with `dumpsys package`:
#   com.xiaomi.android.tvsetup.partnercustomizer  holds BleRcActivity, the Bluetooth remote pairing
#   com.mediatek.hotkey.dispatcher                the remote's hotkey service, including Source
#   com.mediatek.tvinput                          serves HDMI 1-3, composite AV and the tuner
#   com.mediatek.wwtv.setupwizard                 the channel tuning wizard for Live TV
#   mitv.service, com.xiaomi.mitv.res             core TV service and framework resources
#
# Quirk: com.duokan.factorytest also declares the HOME intent, at priority 0, the same as a
# replacement launcher (the stock launcher sits at priority 2). Disable it and set the home
# activity explicitly BEFORE disabling com.google.android.tvlauncher, or Home can land on the
# factory test app. It is in the list below so restore.sh re-enables it.
#
# NOTE: com.google.android.tvlauncher is deliberately NOT in this list. launcher/build-and-install.sh
# disables it only after the replacement launcher is installed and verified as home.
#
# Tested on this firmware: HDMI 1-3, composite AV, the tuner, the Bluetooth remote, Gboard,
# Play Store, Chromecast, Miracast and USB video playback all still work.
#
# Notes from a second set on the same firmware (mirhnaz, PR #81):
# - Live TV (com.mediatek.wwtv.tvcenter) can't be disabled even if you never use the tuner: its
#   TurnkeyUiMainActivity is also the HDMI/AV window. Hide it in the launcher instead (hidden_apps).
# - Before disabling com.mitv.dream, point the screensaver elsewhere:
#   settings put secure screensaver_components com.gathin.tvhome/.ClockDream
# - After power-on the TV returns to the last source, not the launcher.
