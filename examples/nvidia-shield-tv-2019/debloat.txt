# NVIDIA SHIELD TV 2019 tube (model P3430, codename sif, Tegra X1+, 2 GB RAM), Android TV 11 (API 30)
# Tested on build RQ1A.210105.003.7825199_4387.0822 (SHIELD Experience 9.2.4), security patch 2026-01-05.
# Based on examples/nvidia-shield-tv-pro-2019/debloat.txt. Every active line below is disabled on the
# reporter's unit, with the items they already had disabled left commented out.
#
# Apply:   TV_HOST=<shield ip> tools/disable.sh examples/nvidia-shield-tv-2019/debloat.txt
# Undo:    TV_HOST=<shield ip> tools/restore.sh examples/nvidia-shield-tv-2019/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Connecting: Developer options -> "Network debugging" opens ADB on port 5555. The tube has no USB
# ports at all, so there is no cable route and nothing loses power while debugging is on.
#
# Launcher: run launcher/build-and-install.sh before this list; it installs the launcher and hands
# Home over by disabling com.google.android.tvlauncher, which is the last line here. As on the Pro,
# the stock launcher's Home filter has priority 2 and this repo's has 0, so `cmd package
# set-home-activity` does nothing while the stock launcher is still enabled. setupwraith is not a
# Home candidate here either. The unit this list came from runs Glass Launcher (au.busby.glasslauncher)
# rather than this repo's launcher; the stock launcher has to go for either of them to take over.
# A Shield has no HDMI inputs and no tuner, so the launcher's Inputs pill has nothing to list.
# On that unit location is on (location_mode=3) and the launcher holds ACCESS_FINE_LOCATION, so the
# network pill shows the network name; with location off it says "Wi-Fi".
#
# Differences from the Pro example, by the owner's choice:
# - Firmware updates are OFF (com.nvidia.ota, NvCPLUpdater and KeyComboOta disabled). The Pro example
#   keeps KeyComboOta; re-enable all three before contacting NVIDIA support or to get security patches.
# - Live Channels and Backdrop are off. The screensaver on that unit was already "Colors"
#   (com.android.dreams.basic), so disabling Backdrop left a screensaver set.
# - Kept: Prime Video, Chromecast built-in, Google Assistant and hotword, Alexa / Google Home control
#   (com.nvidia.shield.ask), the SHIELD TV phone-remote app (com.nvidia.shield.remote.server).
# - Not present on this unit: com.nvidia.nvgamecast, com.android.printspooler, com.nvidia.osc,
#   com.google.android.katniss, com.google.android.play.games.
#
# Leave alone (same as the Pro example): com.nvidia.blakepairing, com.nvidia.bluetooth.*,
# com.nvidia.shieldtech.accessoryui, com.nvidia.ControllerMapper, com.nvidia.remotelocator,
# com.nvidia.irtuner, com.nvidia.NvCPLSvc, com.nvidia.nvaudiosvc, com.nvidia.avsync,
# com.dolby.android.audio.service, com.nvidia.packagemanagerservice, com.android.tv.settings,
# com.android.providers.tv, com.google.android.tv.remote.service, com.google.android.tungsten.setupwraith,
# Play Services, keychain, com.android.se.
#
# Reported by @geekitup in issue #312, with a screenshot of the running setup.
# Notes from that firmware:
# - A SHIELD Experience update can re-enable packages; re-run this list afterwards.
# - The remote's Netflix button is handled in firmware; disabling Netflix does not free it.
