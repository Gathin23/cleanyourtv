# TCL Smart TV Pro, UK firmware (device G09, product G09_4K_GB, Amlogic T5M), used in Brazil
# Android 12 (Google TV), firmware STT2.230203.001 AS24, 2 GB RAM
# Same firmware family as examples/tcl-g10-google-tv.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-g09-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-g09-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV app: com.tcl.tv (also owns HDMI playback).
# Keep com.tcl.tvinput, com.tcl.suspension (Input/source menu), com.tcl.dashboard, com.tcl.autopair,
# com.tcl.systemserver (mic hotkeys) and com.tcl.providers.config. com.tcl.initsetup is in the list
# below (it also owns channel installation) - comment it out if you still need to scan channels.
# Firmware updates come through Play Services (gms SystemUpdatePanoActivity); there is no TCL OTA package.

# TCL telemetry and analytics
com.tcl.ttvs                           # TCL BI/awareness/identifier services; see the README on TvSettings without it

com.tcl.interactive                    # TCL TIAS background service
com.google.android.feedback
com.graymatrix.did                     # device analytics (data app; on the AS23 unit)
# com.mirakulo.astrotv.service is Ginga, the ISDB-Tb broadcast interactive-TV engine (AstroTVService,
# com.tcl.tv.ginga.PERMISSION), not analytics. TvSettings reads Enable_ginga=false on this set, so it
# frees nothing here; where Ginga is on, disabling it turns broadcasters' interactive apps off.
com.mirakulo.astrotv.service           # Ginga (ISDB-Tb broadcast apps), not analytics
