# Stock launcher: com.tianci.movieplatform. Leave it enabled: this firmware refuses
# set-home-activity ("cannot be home on user 0"), puts persist.service.homepage.pkg back from the
# read-only DEFAULT_HOMEPAGE at every boot and binds no third-party accessibility service, so the
# reference launcher cannot take Home here.
# Live TV / inputs: com.skyworth.tv (kept).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/skyworth-8n05-q30/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/skyworth-8n05-q30/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# THIS LIST DOES NOT SURVIVE A REBOOT. The firmware turned 17 of these 18 packages back on by itself
# at the next boot (only com.tianci.appstore stayed off), so treat it as a per-session cleanup or
# re-apply it after each boot, and do not plan a set whose only debloat is this one.
#
# From @linzhijie30618's 2026-11-04 session in #2337, one pm disable-user --user 0 call per package,
# read before the first reboot; the names arrived in the thread on 2026-11-26. Kept on the device, as
# the device note records: com.tianci.de, com.skyworthdigital.stb.dataprovider and com.coocaa.sky.ccapi
# carry the device-info page ADB is switched on from, and com.coocaa.factory, com.tianci.movieplatform,
# com.skyworth.tv and com.tianci.localmedia the home screen and the TV app.
