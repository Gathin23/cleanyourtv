# TCL Smart TV Pro (G08, G08_4K_GB, MediaTek), Europe/UK firmware, Android 12
# Model "Smart TV Pro", device G08, fingerprint TCL/G08_4K_GB/G08:12/STT2.221228.001/AS34:user/release-keys.
# Same G08 board family as the C755/QM6K/85RM7L/US lists, but this is the older Android 12 EU firmware:
# no Samba-ACR ttvs build, no AirplayAPK, no hotelmenu/channelplus/e-sticker/TV+/usercenter, no Android 14
# ad services. The US list (examples/tcl-g08-us-google-tv) applies only partially here; this list is the
# subset that exists on this build, applied by hand with `pm disable-user --user 0`.
#
# Tested 21 October 2026 on one set. All 24 packages below are disabled on that set and it boots, plays
# HDMI/Live TV and opens the source menu normally.
#
# Second unit: TCL 75Q7C (G08_4K_GB, same model "Smart TV Pro"), firmware STT2.221228.001 AS36, Spain, on
# Ethernet, 25 October 2026, with the Clean Your TV launcher as Home (README). The list below applied unchanged
# (com.tcl.browser is not on AS36). AS36 also has five TCL packages the first AS34 set did not: they are at the
# end, disabled on that set for one day only.
#
# Third unit: TCL 50C805X1 (G08_4K_GB, same model "Smart TV Pro"), firmware STT2.221228.001 AS34 like the first,
# France, on Wi-Fi, 23 to 26 October 2026 with the Clean Your TV launcher as Home (README); all disabled
# packages still disabled after two reboots. This AS34 set ships AirplayAPK and the five "AS36" packages too, so
# those preloads are not tied to the build. Four of them are now in the list; com.tcl.guard stays commented.

# DO NOT DISABLE - verified on this set, 21 Oct 2026:
# com.tcl.autopair   - Bluetooth remote pairing. Disable it and a remote that unpairs (battery
#   swap, reset) can never pair again. Found by review, kept enabled on the live set.
# com.tcl.suspension  - hosts the source-menu QuickPanel. The remote's Source key (KEYCODE_TV_INPUT, 178)
#   goes TclShortCutKeyManager -> startService com.tcl.suspension/.DismissService
#   (act=com.tcl.quickpanel.show.window). Disabling it makes the Source key silently dead
#   ("Unable to start service ... not found"). Restore: pm enable com.tcl.suspension.
# com.tcl.interactive - provides the tcl_tias_tbrowser service com.tcl.tv binds for the source/HbbTV
#   overlay. Disabled, vendor.tcl.tvinput.extend-service spams "Passing null binder object" plus
#   com.tcl.tbrowser NullPointerException at ~10 Hz forever.
# com.tcl.ttvs        - same TIAS chain (and the teletext soft-keyboard IME). Disable breaks the
#   live-TV source overlays like the two above.
