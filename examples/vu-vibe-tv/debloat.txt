# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (build-and-install.sh finds and disables it; do not
# list it here, it must go only after the new launcher is running). On this Google TV build the setup wizard
# com.google.android.tungsten.setupwraith also claims Home and takes it over once launcherx is disabled, so it
# must be disabled too for the new launcher to win Home (build-and-install.sh reports this; its saved Wi-Fi
# network is owned by the system, uid 1000, not by setupwraith, so disabling it does not drop Wi-Fi here).
# Live TV app: com.realtek.tv (set it as live_tv_package and hide it in launcher config.xml). HDMI 1-4 and AV
# come from com.realtek.tv.passthrough through the standard TvInputManager, so the launcher's Inputs menu lists
# them with no vendor workaround.
#
# APKs install fine over ADB (pm install -r), no verification block, SDK 34 >= the launcher's minSdk 26.
# Private DNS (ad-blocking resolver) works on Android 14; a Pi-hole on the LAN covers it too.
# Tested on 2026-10-24: two reboots, both normal and Home stayed the new launcher; HDMI switching from the
# Inputs menu; apps launch from the dock.
#
# Do NOT disable com.realtek.systemservice (it owns the Realtek FallbackHome) or the com.realtek.tv* input
# services, or the TV loses HDMI/AV/tuner. Factory apps left alone and never launched: com.toptech.tvfactory,
# com.toptech.factorytoolsgtv, com.realtek.secservice.
# Firmware updates left ON: com.google.android.tv.dfuservice, com.realsil.ota.
# Casting left ON by choice: Chromecast (com.google.android.apps.mediashell), Miracast (com.realtek.miracast).
