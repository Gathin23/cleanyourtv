# Unit-specific notes:
# - The active Wi-Fi network belongs to android.uid.system:1000, NOT setupwraith (verified with dumpsys wifi).
#   Setupwraith can be safely disabled without dropping Wi-Fi or ADB.
# - The stock screensaver (com.google.android.apps.tv.dreamx) is disabled in favor of ClockDream:
#   tools/tv.py 'settings put secure screensaver_components com.gathin.tvhome/.ClockDream'
#   Sleep timer set to 20 minutes (settings put system screen_off_timeout 1200000) to protect the panel.
# - Remote key helpers and volume repeat (TCL G08 Android 12 firmware limitation):
#   On this firmware, binding ANY key-filtering accessibility service causes the platform input dispatcher
#   to suppress continuous hardware auto-repeat when holding the volume buttons (steps once instead of ramping;
#   see docs/devices/tcl-55p71b-g09-key-repeat.md). Leaving accessibility helpers unbound
#   (enabled_accessibility_services '' and accessibility_enabled 0) preserves full volume ramping.
#   On Home, the launcher's Settings button (keycode 83) works directly without any helper.
#
