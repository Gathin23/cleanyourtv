# ⚠ CRITICAL FOR PROJECTORS:
# Do NOT disable com.hisense.screen! Unlike TVs, on Vidda laser projectors com.hisense.screen hosts the
# optical motor driver, electric focus, autofocus calibration, keystone correction, and lens shift/zoom.
# Disabling it breaks all focus buttons and autofocus mechanisms. See "Kept on purpose" at the bottom.
#
# Note on com.android.camera2 vs ToF autofocus:
# The ToF distance sensor and autofocus calibration loop rely on the Android framework API
# android.hardware.camera2 (inside framework.jar), cameraserver, and com.hisense.screen. The package
# com.android.camera2 is merely the vanilla AOSP camera app UI (/product/app/Camera2) and was already
# disabled at the factory by the vendor service (enabled=2); it is not in this list.
#
# Already disabled at factory and not in this list:
# com.android.camera2, com.android.contacts, com.android.calendar, com.android.music,
# com.android.providers.userdictionary, com.android.quicksearchbox, com.android.inputmethod.latin,
# com.android.deskclock, com.android.settings.
#
# ADB: ro.adb.secure=0 and service.adb.tcp.port=5555, so the USB debugging switch alone opens 5555 to
# every device on the LAN with no "Allow USB debugging?" prompt. Turn that switch off when the work is
# done and confirm the port refuses connections (tools/adb-closed.py <projector ip>).

# ============================================================================
# Kept on purpose
# ============================================================================
# - com.hisense.screen: ⚠ PROJECTOR OPTICAL MOTOR & FOCUS ENGINE. NEVER DISABLE!
#   Houses /system_ext/app/Screen/Screen.apk. Controls ElectricFocusingActivity (electric focus),
#   CalibrationFocusActivity (autofocus calibration), KeystoneActivity (keystone correction),
#   AutomaticEntryActivity (auto screen fit), LenPositionActivity/LenZoomActivity (lens shift/zoom),
#   and ProjectorSensorService (ToF distance & motion sensors). Disabling it breaks all focus keys.
# - com.hisense.vidaaassistant: Package installer and permissions manager. Sideloaded APK installs fail
#   without it. Do NOT disable.
# - com.sohu.inputmethod.sogou.tv: Virtual keyboard for remote control text input (Wi-Fi password, search).
# - com.hisense.tv.tiletransition: Signal source switcher (TileAnimationService). With it off, HDMI
#   switching fails.
# - com.hisense.tv.inputs: Vendor signal source panel.
# - com.jamdeo.updateservice, com.hisense.usbupgrade: OTA firmware update services (active in Mode U).
# - com.vt.permission.manager, com.hisense.tv.globalui, com.hisense.tv.baseservice, com.hisense.hiservice:
#   System settings and permission framework UI.
# - com.hisense.bluetoothpair, com.hisense.raycodereceiver: Bluetooth remote pairing and IR receiver.
