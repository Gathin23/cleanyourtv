# Amazon Fire TV Stick 4K, 1st gen 2018 (AFTMM, codename mantis), Fire OS 6.7.1.1 (NS6711/5908), Android 7.1.2 (SDK 25)
# Also a fair start for other Fire OS 6 sticks and boxes (Fire TV Stick 4K / Cube 1st gen). Fire OS 7 sets differ:
# see insignia-ns55f301na25/ and toshiba-fire-tv-aftha004/.
#
# FIRE OS: DEBLOAT ONLY. com.amazon.tv.launcher is a protected package and keeps Home; launcher/ does not apply.
# A custom home is still possible on top of the stock one: the community route is "Launcher Manager Mini" (XDA,
# SweenWolf), which watches the Home press in the system log and brings a sideloaded launcher such as Projectivy to the
# front. Both are third-party sideloads, and Amazon has broken earlier versions with OTA updates, so it is not part of
# this list.
#
# Apply:   TV_HOST=<stick ip> tools/disable.sh examples/amazon-fire-tv-stick-4k-2018/debloat.txt
# Undo:    TV_HOST=<stick ip> tools/restore.sh examples/amazon-fire-tv-stick-4k-2018/debloat.txt com.amazon.tv.launcher
# (restore.sh re-enables the stock launcher as a matter of routine; on Fire OS it was never disabled, which is harmless.)
# Everything is DISABLED for user 0, never uninstalled. Comment out any line you want to keep.
# ADB on Fire OS 6: Settings > My Fire TV > Developer options > ADB debugging. If Developer options is hidden,
# Settings > My Fire TV > About > highlight the first entry and press select 7 times. Port 5555, no pairing.
#
# Lived with since 2026-10-18 on one stick (the group dated 2026-10-19 for one day less). Nothing had to be re-enabled.
# Protected by Fire OS 6 (pm disable-user is refused without root), so commented out below: com.amazon.client.metrics,
# com.amazon.device.metrics, com.amazon.minerva.client.api, com.amazon.device.logmanager, com.amazon.device.crashmanager,
# com.amazon.diode, com.fireos.usagestats.proxy, com.amazon.ftvads.deeplinking, com.amazon.tv.csapp, com.amazon.tv.oobe.
# No com.amazon.tv.acr on a stick (ACR is a TV-set thing).
#
# Second unit, same model and build (AFTMM, NS6711/5908), Europe, 2026-10-22: the list above applied cleanly.
# Three more packages are protected on this build: com.amazon.tcomm, com.amazon.securitysyncclient and
# com.amazon.whisperlink.core.android ("Cannot disable a protected package"). With com.amazon.vizzini disabled, Fire OS
# re-enables it at every boot (all other disabled packages stay off), so dropping voice search means re-running
# disable.sh after each reboot. Disabling the casting group at the end closed ports 8009, 55442 and 60000 on the LAN.
# With Fire OS parental controls on ("PIN protect app launches"), any start of another app over Amazon's home,
# including a Home-watcher launcher from SHOWCASE.md, opens the Prime Video PIN prompt every time.
#
# Kept on purpose: com.amazon.tv.launcher, com.amazon.tv.settings.*, com.amazon.venezia (Appstore),
# com.amazon.tigris (Appstore UI), OTA updates, remote/Bluetooth services, com.amazon.tv.ime (keyboard),
# com.amazon.vizzini (Alexa voice search for the remote mic) with com.amazon.aria/cardinal (its screens),
# Prime Video (com.amazon.firebat, com.amazon.tv.support), display mirroring and DIAL casting
# (com.amazon.cast.sink, dialservice, ssdpservice, whisperlink/whisperplay, awvflingreceiver),
# screensaver, profile picker, accessibility (com.amazon.logan) and TTS. The streaming apps this owner uses
# (Netflix, Prime Video, Disney+, Apple TV, DirecTV, Crunchyroll, YouTube) are not listed; the rest are, by choice.
#
# What the list cannot remove: the "Sponsored" hero banner and sponsored app row are fetched by the launcher itself
# from amazon-adsystem.com. Private DNS needs Android 9, so on Fire OS 6 set an ad-blocking DNS (AdGuard 94.140.14.14 /
# 94.140.15.15) through a static IP in the Wi-Fi advanced settings, or block *.amazon-adsystem.com on the router.
# Also turn off Settings > Preferences > Featured Content autoplay and the three Privacy Settings toggles.
# Gotchas: a reboot resets the favourites bar to Amazon's defaults; OTA updates may re-enable packages, re-run
# disable.sh afterwards; Netflix is DRM-black in screenshots.
