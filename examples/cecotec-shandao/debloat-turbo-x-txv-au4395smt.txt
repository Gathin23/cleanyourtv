# KEEP, even though the names look like bloat (checked on this TV with dumpsys package):
# - fusion.android.tv.demo, which debloat.txt disables: on this unit the retail demo app
#   (/system_ext/priv-app/RetailDisplayVestel) declares a receiver for
#   com.mstar.android.intent.action.TV_INPUT_BUTTON, the remote's Input key on Vestel's menlo sets
#   (examples/turbo-x-40as60t, examples/jvc-android-tv-menlo). Kept as a precaution, not tested
#   without it: the Cecotec owner reports Input working with it disabled on this same build. With it
#   on, the Input button works here after the stock launcher is gone, with no key helper.
# - com.google.android.tungsten.setupwraith: owns the Wi-Fi network saved at first setup
#   (dumpsys wifi shows cname=com.google.android.tungsten.setupwraith); disabling it deletes that
#   network and takes the TV off Wi-Fi and ADB. It does not claim HOME on this firmware.
# - com.mediatek.android.leanbacklauncher.partnercustomizer, every other com.mediatek.*,
#   mediatek.factorymenu.ui and com.mediatek.tv.factory (never started), com.vestel.tv.service,
#   com.vestel.tv.keycontroller (remote keys), com.vestel.tv.backlight, com.vestel.overlay.*,
#   com.dolby.android.audio.service, Play Store, Play Services, Gboard, TTS.
# - com.mediatek.wwtv.mediaplayer (MMP, USB media player): kept by choice. tools/disable.sh skips it
#   anyway, as on the Cecotec (see debloat.txt).
# - Owner's choices kept: Netflix, YouTube, Cosmote TV (gr.cosmote.cosmotetv.androidtv, which now
#   calls itself MagentaTV), ANT1+ (gr.antenna.ant1.screen) and Chromecast built-in.
#
# Quirks on this firmware:
# - screencap works over ADB; Live TV comes back empty, as usual.
# - ro.adb.secure = 1. The set ran network ADB on 5555 and Wireless debugging side by side;
#   switching USB debugging on switches Wireless debugging on too, and switching Wireless
#   debugging off also closes 5555.
# - The TV registers only the tuner (HW0, HW1) and three HDMI ports (HW5 to HW7) with the TV input
#   framework: the launcher's Inputs menu shows HDMI 1 to 3 and Live TV, and no AV row.
# - Apps cannot read /proc/stat here, so the launcher's show_stats line carries memory and storage
#   and no CPU figure.
# - The remote's power button is a standby with no boot: boot_to_live_tv alone does not cover it,
#   open_on_start_on_wake does (see README.md here).
# - Private DNS (dns.adguard-dns.com) validates on this TV and YouTube keeps playing with it.
# - Reboot-checked: pm list packages -d unchanged after a reboot, nothing re-enabled by the firmware.
