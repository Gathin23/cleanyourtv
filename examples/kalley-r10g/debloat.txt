# Kalley R10G (device R10G, product ACER_FFM, made by MOKA), Google TV on Android 14, firmware UKR1.260612.001
# Realtek RTD2875P SoC, RTD6748 platform, 2 GB RAM. The remote reports as "RC860G Consumer Control".
# Same hardware family as examples/prismplus-q65-ultra-r10g/, but a different brand build
# (ACER_FFM) with its own preloads: Claro, Kick, JioTV, CBS, Apple TV and Prime Video.
# Second unit (#1807), Colombia: same device and firmware, but product KALLEY_FFM
# (fingerprint KALLEY/KALLEY_FFM/R10G:14/UKR1.260612.001); the boot loop and re-enable notes below are from it.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/kalley-r10g/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/kalley-r10g/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh).
# Live TV and inputs: keep com.realtek.dtv and com.realtek.tv.atv (HDMI and the other inputs use them).
# OTA: keep com.apps.ota and com.apps.authota. Keep com.realsil.ota too: it updates the remote.
#
# Input button: the RC860G remote sends KEYCODE_TV_INPUT (kernel scan code 225), not KEYCODE_TV.
# Enable the launcher's InputKeyService (INPUT_KEY_SERVICE=1) so the new launcher answers it.
# com.android.tv.action.VIEW_INPUTS resolves to com.realtek.tv/.SelectInputActivity.
#
# KEEP launcherx AND setupwraith ENABLED on this set (#1807). With both disabled, system_server crashed
# 35-75 s into every boot (sys.boot.reason watchdog; IllegalArgumentException: positionChildAt ... in
# Task.moveToBack) and the TV restarted in a loop until both were enabled again over ADB in the boot window.
# The setup that works here, from the #1807 report:
#   - set stock_home_redirect to com.google.android.apps.tv.launcherx (config.xml or a theme), so the
#     stock home is sent straight back to the new launcher;
#   - install with the key helpers and without disabling the stock launcher:
#       STOCK_LAUNCHER=none INPUT_KEY_SERVICE=1 HOME_KEY_SERVICE=1 launcher/build-and-install.sh
#       (Windows: launcher\build-and-install.ps1 -StockLauncher none -InputKeyService -HomeKeyService)
#     The installer stops at its Home check in this mode, since Home still resolves to launcherx: enable
#     HomeKeyService and InputKeyService by hand afterwards (Settings > Accessibility). Without the helpers
#     Home goes back to launcherx; set-home-activity does not hold on this build.
#   - With both helpers bound, holding volume steps once instead of ramping (the trade in
#     docs/devices/tcl-55p71b-g09-key-repeat.md).
#
# The firmware turns most preloads back on at boot, as on the MOKA Acer R4G (docs/devices/acer-r4g.md):
# after one reboot only com.cbs.ca, com.seraphic.media.tv.interactive.app, com.realtek.kara and
# com.realtek.karaoke.userguide stayed disabled on the #1807 set.
#
# Tested on one set on 2026-10-19/20 with the reference launcher: the apps kept (Netflix, Disney+,
# Max, Spotify, YouTube, Twitch, GeForce NOW, Stremio) still launch, and HDMI input, Home and the
# Input button work. This list is fresh, not yet lived with for days; update it if something breaks.
