# Kalley R10G (device R10G, product ACER_FFM, made by MOKA), Google TV on Android 14, firmware UKR1.260612.001
# Realtek RTD2875P SoC, RTD6748 platform, 2 GB RAM. The remote reports as "RC860G Consumer Control".
# Same hardware family as examples/prismplus-q65-ultra-r10g/, but a different brand build
# (ACER_FFM) with its own preloads: Claro, Kick, JioTV, CBS, Apple TV and Prime Video.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/kalley-r10g/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/kalley-r10g/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh).
# Live TV and inputs: keep com.realtek.dtv and com.realtek.tv.atv (HDMI and the other inputs use them).
# OTA: keep com.apps.ota and com.apps.authota. Keep com.realsil.ota too: it updates the remote.
#
# Input button: the RC860G remote sends KEYCODE_TV_INPUT (kernel scan code 225), not KEYCODE_TV.
# With the stock launcher gone nothing handles it, so enable the launcher's InputKeyService
# (INPUT_KEY_SERVICE=1). com.android.tv.action.VIEW_INPUTS resolves to com.realtek.tv/.SelectInputActivity.
#
# Tested on one set on 2026-10-19/20 with the reference launcher: the apps kept (Netflix, Disney+,
# Max, Spotify, YouTube, Twitch, GeForce NOW, Stremio) still launch, and HDMI input, Home and the
# Input button work. This list is fresh, not yet lived with for days; update it if something breaks.
