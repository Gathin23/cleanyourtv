# Amazon Fire TV Stick 4K Max, 2nd gen 2023 (AFTKRT, codename karat), Fire OS 8.1.8.5 (RS8185.3891N, build 0033018557316),
# Android 11 (SDK 30), Indonesia. Same build as amazon-fire-tv-stick-4k-2023/ (AFTKM).
#
# FIRE OS: DEBLOAT ONLY. Home is com.amazon.tv.launcher/.ui.HomeActivity_vNext (priority 950); launcher/ does not apply:
# com.amazon.tv.launcher is a protected package on this build — pm disable-user is refused
# (SecurityException) and pm uninstall -k --user 0 fails (DELETE_FAILED_INTERNAL_ERROR);
# cmd package set-home-activity is ignored. A third-party launcher can be installed and started,
# but it cannot be made the default Home.
#
# Apply:   HANDLERS_ALLOW=1 TV_HOST=<stick ip> tools/disable.sh examples/amazon-fire-tv-stick-4k-max-2023/debloat.txt
# Undo:    TV_HOST=<stick ip> tools/restore.sh examples/amazon-fire-tv-stick-4k-max-2023/debloat.txt com.amazon.tv.launcher
# Everything is DISABLED for user 0, never uninstalled. Comment out any line you want to keep.
# ADB on Fire OS 8: Settings > My Fire TV > About > press select 7 times on the device name, back > Developer Options >
# ADB Debugging. Port 5555, accept the prompt on the TV (ro.adb.secure=1).
#
# Applied 2026-10-31 in three batches, Home verified rendering after each (Prime hero + app rows paint,
# not just resumed). Rebooted once the same day: all 91 stayed disabled (nothing came back, including the
# Alexa entries, even though the voice engine com.amazon.vizzini is left enabled — the Fire OS 7
# come-back-at-boot behavior did not reproduce on this build). Home renders after the reboot, and
# Jellyfin, Plex and Netflix all open. Multi-day lived-with testing is still pending at contribution time.
# Protected on this build (pm disable-user: "Cannot disable a protected package"), so commented out below:
# com.amazon.device.metrics, com.amazon.device.logmanager, com.amazon.device.crashmanager,
# com.fireos.usagestats.proxy, com.amazon.ftvads.deeplinking, com.amazon.tv.oobe,
# com.amazon.whisperlink.core.android, com.amazon.tcomm, com.amazon.tcomm.client.
# (com.amazon.diode and com.amazon.tv.csapp, protected on the AFTKM list, were not attempted here.)
#
# Kept on purpose: com.amazon.tv.launcher, com.amazon.tv.settings.*, com.amazon.venezia and
# com.amazon.tigris (Appstore), com.amazon.tv.ime, remote/Bluetooth services, OTA updates
# (device.software.ota*, tv.forcedotaupdater.v2), voice engine (com.amazon.vizzini), Prime Video
# (com.amazon.firebat), com.amazon.imp (load-bearing for Home rendering — disabling it together with
# shoptv, media.recommendations, sneakpeek, systemnotices, tv.earlyaccess and tv.acr left the stock Home
# resumed but painting nothing on a second AFTKRT unit), screensaver (com.amazon.bueller.photos),
# Amazon Music (com.amazon.bueller.music), Silk (com.amazon.cloud9), Kids (com.amazon.tahoe),
# Ambient (com.amazon.tv.ftvambient), accessibility (com.amazon.logan), notification center.
#
# What the list cannot remove: the hero banner and sponsored rows come from the launcher's own feed.
# Point the stick's DNS at a blocker for those (Pi-hole, or Private DNS dns.adguard-dns.com on Android 11).
# Also turn off Settings > Preferences > Privacy Settings (Device Usage Data, Collect App Usage Data,
# Interest-based Ads) and Featured Content autoplay in the menus: those values sync with the Amazon
# account, so the menu is the place to change them, not `settings put`.
# Leave the animation scales at 1.0 on this build (see the AFTKM list: at 0.5 the side menu opens nothing).
