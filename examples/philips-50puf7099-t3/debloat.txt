# QUIRKS ON THIS FIRMWARE:
#
# 1. The three upgraders all hold INSTALL_PACKAGES, and tv.fun.tvupgrade is the
#    installerPackageName of com.bestv.ott itself: while it lives it can put the BestV
#    launcher back and wipe this list. Disabling it gives up system OTA, and firmware
#    updates have to be sideloaded by hand from then on.
# 2. The screensaver shipped pointing at com.google.android.deskclock, which is not
#    installed, and pm query-services -a android.service.dreams.DreamService answers
#    "No services found": this set had no screensaver at all. After the launcher install,
#    point it at the launcher's own clock:
#      settings put secure screensaver_components com.gathin.tvhome/.ClockDream
#      settings put secure screensaver_default_component com.gathin.tvhome/.ClockDream
# 3. org.droidtv.usagelogger asks for android.permission.TV_INPUT_HARDWARE, so
#    tools/disable.sh skips it by default. It is a false positive here:
#    pm query-services --components -a android.media.tv.TvInputService lists only
#    com.tpv.tvinput's six services, usagelogger is not among them. Disabling it needs
#    TVINPUT_ALLOW=1. Same as examples/cecotec-shandao.
# 4. The screen is 60 Hz 4K on a 2 GB set, so lowmemorykiller is active at idle.
#    Every background service removed is a net gain.
# 5. default_input_method is com.android.inputmethod.pinyin/.PinyinIME, which is
#    installed — not the Xiaomi quirk where it points at a missing com.baidu.input.
