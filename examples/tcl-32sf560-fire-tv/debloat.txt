# TCL 32SF560 (TCL Fire TV, AFTSHN02, codename shine), Fire OS 7.7.1.7 / Android 9 (SDK 28),
# build PS7717.5741N.0036408028416 - the same build as examples/toshiba-fire-tv-aftha004, whose list plus
# amazon-fire-tv-afttiff43, amazon-fire-tv-stick-lite-2020, insignia-ns55f301na25 and amazon-fire-tv-afteu014
# were the starting point, filtered to the packages this set actually ships.
#
# FIRE OS: DEBLOAT ONLY. Fire OS will not let a third-party launcher take over Home: com.amazon.tv.launcher
# claims HOME at priority 950 (com.amazon.firehomestarter at 1), both are protected packages, and
# `cmd package set-home-activity` prints Success but changes nothing. This list removes Amazon's telemetry,
# ads, preloads and voice assistant around the stock home screen. Live TV app: com.amazon.tv.livetv.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-32sf560-fire-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-32sf560-fire-tv/debloat.txt com.amazon.tv.launcher
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
#
# Applied on 2026-10-24 in four batches with a screenshot after each, then rebooted: all 83 stayed disabled
# across that reboot, and HDMI, Live TV, Settings and the sideloaded streaming apps were confirmed on the set
# afterwards. Lived with since that day; re-check after a firmware update, Fire OS resets some packages.
#
# Not listed because pm disable-user refuses it ("Cannot disable a protected package") on this build:
# com.amazon.device.software.ota, com.amazon.device.software.ota.override (firmware and security updates keep
# running - Amazon enforces them here), com.amazon.device.sync, com.amazon.device.sync.sdk.internal,
# com.amazon.sync.service, com.amazon.diode, com.amazon.platform.fdrw, com.amazon.securitysyncclient,
# com.amazon.tcomm, com.amazon.tcomm.client. Also not listed: com.amazon.vizzini (Alexa voice), which Fire OS
# re-enables at every boot on 7 and 8, so the microphone button comes and goes; com.amazon.vizzini.ftvcds below
# does stay off.
#
# Kept on purpose: the stock launcher, Live TV and the whole tuner and input stack (channelscan,
# conditionalaccess, franktvinput, com.vewd.*, com.droidlogic.*, inputpreference.service), Settings and Quick
# Settings, the on-screen keyboard, remote and Bluetooth pairing, profiles and parental controls, the Appstore,
# Prime Video, AirPlay, the screensaver, OTA, and every app the owner sideloaded (Netflix, Disney+, Prime,
# HBO Max, Apple TV, YouTube, Kodi, ZDF, ARD, MagentaTV, 7TV, JustWatch, Downloader). Miracast and DIAL
# receivers are off by choice - casting *to* this TV is not used; nothing here touches casting *from* it.
