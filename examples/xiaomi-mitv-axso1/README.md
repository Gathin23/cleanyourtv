# Xiaomi MiTV-AXSO1 (dangalFHD) notes

## The Mi TV button after PatchWall is disabled

With `com.mitv.tvhome.atv` disabled the remote's Mi TV button does nothing, and the launcher's key helper that can
bring it back breaks held volume on this set. A keyboard-layout overlay maps the button to Home with no
helper: see [the device note](../../docs/devices/xiaomi-mitv-axso1-mi-button.md).

Other notes for this model are in the header of `examples/xiaomi-mitv-axso1/debloat.txt`.
