# Panasonic 4KTV-JUP: Taiwan unit notes

One additional Jupiter_PA unit running Android TV 11 (build 4.501) was tested in a single session on 28 October 2026. This is not a several-day validation of every entry in the existing debloat list. Confirm what you use before disabling anything, retain the firmware updater and MediaTek input and TV services, and make a recovery record first.

CleanYourTV Home, HDMI inputs and the remote worked after the change and a reboot. On this firmware, an enabled accessibility service that filters keys interfered with held volume keys even though directional-key repeat worked. A device-specific keyboard-layout bridge was tested as an alternative; the bridge source is not included in this report.

Panasonic eHelp and the recording and schedule list apps were disabled on this unit, but the result is only a short observation, not a recommendation for other owners who use those features.
