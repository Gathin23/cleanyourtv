#   ro.adb.secure            = 0     <- no "Allow USB debugging?" prompt, see below
#   service.adb.tcp.port     = 5555
#
# Same platform and build as examples/vidda-mt9653/ and examples/hisense-e5q-pro/ (device MT9653,
# build RP1A.200720.011, package namespace com.jamdeo.* / com.hisense.*). This list was derived from
# theirs and re-checked package by package against this set's own `pm list packages` (131 packages).
# Packages those lists name that are NOT installed here are left out rather than copied over.
#
# ADB: turning USB debugging on opens port 5555 directly. ro.adb.secure=0 means the TV does not show
# the "Allow USB debugging?" dialog: ANY device on the LAN gets a shell with no prompt. Close the
# debugging switches when you are done and check the port really refuses connections
# (tools/adb-closed.py <tv ip>).
#
# State at the time this list was written (2026-10-22):
#   pm list packages -d        -> empty: nothing is disabled at the factory on this build, so the
#                                 AOSP leftovers in BATCH 5 below are all running here.
#   dumpsys tv_input           -> empty: no TvInputManager inputs at all. The launcher's Inputs pill
#                                 therefore has nothing to list and must use the vendor source panel
#                                 (config.json in this folder: source_panel_service =
#                                 com.hisense.tv.inputs/com.hisense.tv.InputsUIService,
#                                 source_panel_action = com.hisense.tv.start_inputs).
#
# Applied on the real set on 2026-10-22: five batches, each followed by a cold reboot, with the input
# panel switching HDMI, the remote, Wi-Fi, Bluetooth pairing and the IME checked after every one.
# 26 packages stick. com.android.calendar / .deskclock / .music do not: the firmware re-enables them
# at every boot (see BATCH 5). Nothing else came back.
#
# Read before applying:
#   * This list does NOT change how Home looks. The sponsored rows, the VIP banner and the promo
#     tiles are fetched by com.jamdeo.tv.vod itself, not by the ad sidecars below. Only swapping the
#     launcher removes them. What this list buys is the telemetry, the push channel, the persistent
#     network poller, the ad SDK processes and the leftover preloads.
#   * Everything is DISABLED (pm disable-user --user 0), never uninstalled. tools\disable.ps1 records
#     each package's original state under %USERPROFILE%\.cleanyourtv\ before touching it, so
#     tools\restore.ps1 with this same file puts it all back.
#   * Apply in batches, reboot after each one, and confirm the TV boots, the remote works, the input
#     panel switches to HDMI and Wi-Fi is still up. A batch can take something load-bearing with it
#     and you cannot tell which without the reboot.
#
# Apply:   tools\disable.ps1 -TvHost <tv ip> examples\hisense-65d62qh\debloat.txt
# Undo:    tools\restore.ps1 -TvHost <tv ip> examples\hisense-65d62qh\debloat.txt
# Reboot:  & tools\venv\Scripts\python.exe -I tools\tv.py 'reboot'
# Compare: & tools\venv\Scripts\python.exe -I tools\tv.py 'pm list packages -d'
# Comment out any line you want to keep.

# VOICE ASSISTANT — decided by you, not by this list. The whole stack is:
#   com.keylab.speech.view.vidaa (UI shell), com.keylab.speech.core.vidaa, com.hisense.vidaaassistant,
#   com.hisense.tv.aivirtualassistant, com.hisense.msvoicetome, com.iflytek.xiri,
#   com.intelligent.speech, com.hispeech.ai.area, com.speech.enchatroom
# com.keylab.speech.view.vidaa can only be disabled as a whole package (component-level disable is
# refused with SecurityException on this platform). That also removes the remote's mic key and
# com.ju.secondscreen.HomeActivity, which this package starts at boot and which takes the foreground
# on top of your launcher. So it is required for a clean launcher swap, and it costs voice.
#
# com.jamdeo.tv.vod — KEEP ENABLED. This list is debloat only; the stock Home stays.
#   Disabled, this firmware starts no Home at all at boot: display on and awake, mCurrentFocus and
#   mFocusedApp both null, no launcher process, until the remote wakes the TV and HOME resolves again.
#   The remote's Home button goes the same way: the physical key is Linux scancode 102, which this
#   keylayout maps to KEYCODE_F12 for the vendor SysUIMerge app to switch to the previous app — the
#   stock launcher, until it is disabled.
#   Replacing Home on this set is possible but needs more than this list; what it looked like and
#   what it took is recorded in docs/devices/hisense-65d62qh.md. Do not disable this package unless
#   you have read that first.
