# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/artel-a55lu8500/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/artel-a55lu8500/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.

# Stock launcher: com.google.android.apps.tv.launcherx. Live TV: com.realtek.tv, with the tuner and HDMI/AV
# inputs in com.realtek.dtv, com.realtek.tv.atv and com.realtek.tv.passthrough.
#
# Do not disable launcherx or com.google.android.tungsten.setupwraith on this TV. This firmware's modified
# com.android.tv.settings has the .system.FallbackHome that turns packages back on at every boot
# (docs/devices/acer-r4g.md), so setupwraith returns and, with launcherx off, its RecoveryActivity takes Home:
# the Kalley 43G200 on the same platform boot-looped that way and needed a USB reflash. setupwraith also owns
# the Wi-Fi network saved at setup (dumpsys wifi | grep -o 'cname=[^ ]*'), so disabling it takes the TV off
# Wi-Fi and ADB, and on Google TV casting stops without it. The launcher takes the Home button with
# HomeKeyService and stock_home_redirect instead (README.md, config.json).
#
# These disable fine but come back enabled at every boot, so they are not listed; config.json hides the
# tiles of those that have one:
# com.netflix.ninja, com.netflix.tokenmanager, com.google.android.youtube.tvmusic, com.google.android.play.games,
# com.google.android.apps.tv.dreamx, com.apps.scast, com.creative.fastscreen.tv, com.apps.esticker3,
# com.apps.biz.ds (M Sign, digital signage), com.apps.function.audiolink (Audio Connect).
#
