# Kept on purpose:
# - Inputs: com.softwinner.vis (HdmiInputService, CvbsInputService), com.softwinner.awtvinputservice,
#   com.softwinner.awsource, com.softwinner.awlivetv.
# - Remote and Bluetooth: com.htc.htcbluetoothremotecontrol, com.htc.htcsetup_wizard_d55 (its only
#   activity is the Bluetooth pairing screen), com.htc.closedialog (the power menu).
# - Projector: com.hysd.vafocus (autofocus), com.htc.htcsettings (settings, keystone),
#   com.softwinner.tv.factorymenu (never opened).
# - com.softwinner.theme.color: an enabled overlay here ([x] in `cmd overlay list`).
# - com.softwinner.provision, com.softwinner.settingssetup: used by a factory reset.
# - Firmware updaters: com.htc.htcotaupdate, com.softwinner.update, android.rockchip.update.service

#   with no side effect and are enabled again.
#
# Disabled from the factory, not in this list: com.mphotool.usbcastserver, com.toofifi.lineserver.
#
# Firmware notes:
# - Port 5555 is Wireless debugging (TLS) and this firmware shows no pairing screen for it; the first
#   connection was made over a USB cable (the A port, USB VID 1f3a).
# - The firmware answers no android.settings.SETTINGS intent. With launcher/, add
#   com.htc.htcsettings/com.htc.activity.HomeActivity to settings_fallback_components in
#   launcher/app/src/main/res/values/config.xml, and com.htc.htcsettings to the <queries> in
#   launcher/app/src/main/AndroidManifest.xml (a <package> line), as examples/portronics-beem-470 does.
# - The only Netflix that signs in here is the phone app (com.netflix.mediaclient), which declares no
#   leanback entry: name it in library_apps in config.xml and it shows on Home and can sit in the dock.
#   Netflix for TV (com.netflix.ninja) installs but refuses the device at sign-in.
# - launcher/build-and-install.sh does not know this stock launcher: run it with STOCK_LAUNCHER=none,
#   and set-home-activity takes Home. With five columns the date is cut beside the clock at this
#   density; date_below_clock in config.xml fixes it.
# - com.softwinner.tv.factorymenu shows up as a launcher tile: add it to hidden_apps.
