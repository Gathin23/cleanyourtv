# CHiQ "AI PONT" (DVB93CQ, built by Changhong, codename samseong), Android TV 11 (API 30),
# firmware RTO2.250508.001, 1.3 GB RAM, MStar/MediaTek m7322.
# The vendor layer is Homwee (com.homwee.*); content recognition and FAST channels come from Anoki
# (tv.anoki.acr.controller, com.cltv.fast). Same platform family as the BenQ, realme and RCA "AI PONT" sets.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/chiq-ai-pont/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/chiq-ai-pont/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher (the scripts' default). Live TV: com.mediatek.wwtv.tvcenter.
# Same-firmware second unit: OK. ODL 43951UC-TAB / DVB93KO. See README.md for the
# subset actually applied there, power-on behavior and the explicit test limits.
#
# KEEP, even though the names look like bloat:
# - com.google.android.leanbacklauncher.partnercustomizer: provides the tvlauncher.widget content provider.
#   Without it com.mediatek.tv.service crash-loops after the next reboot ("Failed to find provider
#   tvlauncher.widget") and the Input key and other remote hotkeys stop working. Nothing shows up until
#   the TV reboots, so test any change with a reboot.
# - com.homwee.dmt.upgrade (firmware updates), com.homwee.synckey (remote key service),
#   com.mediatek.* (Live TV, inputs, remote pairing), com.homwee.factory.
#
# Notes from this firmware:
# - Live TV reopens the last source; if that was an empty HDMI port it shows a black screen.
# - HDMI and Live TV screenshots come out black (protected video layer).
# - The HbbTV browser (teatro_tv_browser, about 30 MB) is a native vendor process, not a package;
#   switch HbbTV off in the Live TV menu instead.
# - The Wi-Fi pill shows the network name only when Location is on (Android 11).
# - The power button only suspends the TV; restart it now and then (long-press power, Restart).
