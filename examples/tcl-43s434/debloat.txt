# HARDWARE / INPUT NOTES:
# DO NOT DISABLE: com.tcl.tv, com.tcl.tvinput, com.tcl.settings, com.tcl.systemserver,
# com.tcl.gallery, com.tcl.ui_mediaCenter.
# On RTD2851 / AR05, com.tcl.gallery and ui_mediaCenter are wired to the TV_INPUT_HARDWARE
# layer; disabling them causes black screens on HDMI inputs.
#
# VOICE & REMOTE NOTES:
# Voice search using the remote mic is preserved via com.google.android.katniss.
# To prevent Katniss's background hotword listener from using 25-50% CPU listening for "Hey Google":
#   cmd appops set com.google.android.katniss RUN_IN_BACKGROUND ignore
#   cmd appops set com.google.android.katniss RUN_ANY_IN_BACKGROUND ignore
#
# CHROMACAST:
# Kept active via com.google.android.apps.mediashell.
#
# STREAMING PERFORMANCE TUNING:
# 1. Limit background processes to 1 on 2GB RAM sets:
#    settings put global standard_background_process_limit 1
# 2. Ahead-of-time compile heavy streaming apps:
#    cmd package compile -m speed -f com.sling
