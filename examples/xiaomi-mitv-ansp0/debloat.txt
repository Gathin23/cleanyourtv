# Xiaomi MiTV-ANSP0 (codename jobs; 小米电视5 Pro 65", China-market firmware), Android 9 (SDK 28),
# firmware 23.6.5.3226, Amlogic, 4 GB RAM, 1080p UI (320 dpi), 54 GB /data.
# Stock launcher: com.mitv.tvhome (PatchWall, HOME activity .MainActivityUserMode) - KEEP IT ENABLED,
# see "Home" below. Install with: STOCK_LAUNCHER=com.mitv.tvhome launcher/build-and-install.sh
# (build-and-install.sh already knows com.mitv.tvhome, so the argument is optional).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-ansp0/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-ansp0/debloat.txt com.mitv.tvhome
# More notes (settings intents, inputs, ADB, install blacklist): docs/devices/xiaomi-mitv-ansp0-jobs.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Notes from this firmware:
# - Home: disabling com.mitv.tvhome drops HOME to com.android.tv.settings/.system.FallbackHome
#   (priority -1000 in the manifest, but it still wins once nothing else is left), which shows a
#   black screen. Keeping PatchWall enabled and setting the new launcher as the preferred home
#   works, and survives a reboot; PatchWall is then never shown. Verified with
#   `cmd package set-home-activity --user 0 com.gathin.tvhome/.MainActivity`.
# - Standard settings intents DO resolve here: android.settings.SETTINGS ->
#   com.android.tv.settings/.MainSettings, android.settings.WIFI_SETTINGS ->
#   com.android.tv.settings/.connectivity.NetworkActivity. The launcher's pills need no fallback keys.
# - Inputs: com.droidlogic.tvinput registers the ports (Hdmi1InputService/HW5,
#   Hdmi2/HW6, Hdmi3/HW7, AV1InputService/HW1), but nothing answers ACTION_VIEW on the standard
#   TvContract passthrough URI, so the launcher lists the ports without being able to switch them.
#   The TV app switches with EXTSRC_PLAY and an integer extra instead; see
#   docs/devices/xiaomi-mitv-ansp0-jobs.txt.
# - Network ADB (port 5555) closes on every reboot; re-enable it in
#   Settings -> 账号与安全 (Account & Security) -> ADB 调试 after each power cycle.
# - `pm disable-user` is accepted for the shell user on this build (unlike MiTV-ANTL0, which needs
#   `pm hide`).
# - mitv.service is the core MiTV service: do not touch it. It registers TvService, which Xiaomi's own
#   Settings reads the hardware configuration through; with it disabled, Settings freezes for 20-30 s and
#   then crashes the Sound page (#1310). Why:
#   docs/TROUBLESHOOTING.md#xiaomi-cn-firmware-settings-freezes-or-crashes-after-the-debloat
# - Voice: disabling voicecontrol, wakeupservice, the Mico MQTT service and the two Mi Home
#   packages also stops an external Xiao Ai speaker from controlling the TV (its "turn the TV
#   off" command). Verified both ways on this set; see the Voice group below.
# - com.xiaomi.mitv.settings is the vendor settings UI; the standard com.android.tv.settings app is
#   also present and answers the plain settings actions.
# - No Google apps at all. Content comes from CN streaming apps; casting (smartshare / miplay /
#   wfdsinkhelperservice / duokan.airkan.tvbox / upnp) and the app store are deliberately kept.
# - com.mitv.care is disabled by the factory already.
#
# Owner's-choice removals NOT listed below (disabled here, re-enable in Settings > Apps if needed):
# com.douyu.xl.douyutv (Douyu), net.cibntv.ott.sk (CIBN 4K), com.lutongnet.nldmxXiaomiChildren
