# Applied on 2026-10-21 with verification screenshots after each batch:
# - CleanYourTV launcher boots as default Home screen.
# - YouTube, Vidio, Jellyfin, and Netflix open and play cleanly.
# - HDMI 1, HDMI 2, AV, and Live TV switch properly via launcher's Inputs menu.
# - Free RAM increased from ~100 MB to ~328 MB.
#
# Known quirks on this firmware:
# - Stock tvlauncher declares HOME priority 2, so cmd package set-home-activity alone does not
#   take Home while it is enabled. Disabling it (as build-and-install.sh does) is required.
# - com.tcl.ttvs is the firmware updater, not text-to-speech. Kept for OTA updates.
# - com.tcl.usercenter is re-enabled by the system at boot (remains idle).
# - Photo screensaver (com.google.android.backdrop) uses ~105 MB RAM. Switch to ClockDream before disabling:
#   tools/tv.py 'settings put secure screensaver_components com.gathin.tvhome/.ClockDream'
#
