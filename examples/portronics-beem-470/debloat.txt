# Portronics Beem 470 Smart LED Projector (Allwinner H713, sun50iw12p1), Android 11 (SDK 30)
# Firmware UI_Veng.projector.20250922.160824, 1 GB RAM, 1920x1080 panel.
# The firmware reports the generic Allwinner "ADT-3" / "adt3" identity, so match on the build
# string rather than ro.product.model.
#
# Apply:   TV_HOST=<projector ip> tools/disable.sh examples/portronics-beem-470/debloat.txt
# Undo:    TV_HOST=<projector ip> tools/restore.sh examples/portronics-beem-470/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out anything you use.
#
# Tested on a retail unit: Wi-Fi, HDMI input switching, Netflix, JioHotstar, Prime Video, VLC,
# SmartTube, Apple TV and the replacement launcher keep working. Re-enable the OTA packages before
# checking for firmware updates. Casting/EShare packages (com.ecloud.*, com.eshare.*,
# com.allshare.*) are deliberately left enabled.
#
# Firmware quirks worth knowing before you start:
# - The remote's HOME key is ignored until both setup flags are set; otherwise the firmware keeps
#   reporting "user setup is in progress":
#       settings put secure user_setup_complete 1
#       settings put global device_provisioned 1
# - This firmware answers no ACTION_SETTINGS intent. With launcher/, set
#   settings_component=com.htc.htcsettings/com.htc.activity.HomeActivity in config.xml.
# - The stock launcher is com.htc.htclauncherhighenglishd08; re-enable it if you remove launcher/.
