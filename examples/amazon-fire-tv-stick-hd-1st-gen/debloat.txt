# Amazon Fire TV Stick HD, 1st gen (AFTSS, codename sheldon, mt8695), Fire OS 7.7.1.7 (build PS7717.5746N), Android 9 (SDK 28), Spain
# Same AFTSS / sheldon platform as amazon-fire-tv-stick-lite-2020/ on newer build PS7717.5746N.
#
# Stock launcher: com.amazon.tv.launcher (.ui.HomeActivity_vNext, protected on Fire OS 7; keeps Home/Settings).
# Live TV / tuner: none (stick has no hardware tuner or HDMI-in; com.amazon.tv.livetv is the Live tab).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/amazon-fire-tv-stick-hd-1st-gen/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/amazon-fire-tv-stick-hd-1st-gen/debloat.txt com.amazon.tv.launcher
# Everything is DISABLED for user 0 (`pm disable-user`), never uninstalled. Comment out any line you want to keep.
#
# Note: on Fire OS 7, tools/disable.sh may hold back com.amazon.tv.livetv (HANDLERS_ALLOW=1),
# com.amazon.systemnotices and com.amazon.wha.mediabrowserservice (TVINPUT_ALLOW=1); safe on a stick with no tuner/HDMI-in.
#
# Kept on purpose: com.amazon.tv.launcher, com.amazon.tv.settings.*, com.amazon.venezia (Appstore),
# com.amazon.tv.ime, OTA updates, com.amazon.firebat (Prime Video), com.amazon.tv.oobe,
# com.amazon.logan (accessibility), com.amazon.vizzini, remote/Bluetooth, casting/whisperlink,
# and com.android.nfc (already disabled from factory).
