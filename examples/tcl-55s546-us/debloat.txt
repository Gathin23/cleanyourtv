# build RP1A.200622.001 GTV93. Fingerprint: TCL/G03_4K_US/BeyondTV4:11/RP1A.200622.001/GTV93:user/release-keys
# Same G03 platform as examples/tcl-g03-google-tv; that list was the starting point. This US build lacks
# com.tcl.logkit, overseasappshow, tclhome_passive, browser, gamebar, micmanager, miracast and
# MultiScreenInteraction_TV, and adds com.tcl.tv.plus (TCL+) and com.tcl.tv.tclchannel (TCL Channel), both kept.
# Nothing was disabled at the factory.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-55s546-us/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-55s546-us/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled.
#
# Tested 2026-10-21 on a real unit, applied in the six batches below with a screenshot after each, plus the stock
# launcher com.google.android.apps.tv.launcherx (24 packages), then rebooted: every package stayed disabled (this
# build re-enables nothing at boot), Home came up on launcher/ (mFocusedApp checked), Wi-Fi stayed up.
# - The saved Wi-Fi belonged to android.uid.system, not setupwraith, so setupwraith was disabled without
#   forgetting the network.
# - With launcherx off, the real remote's Netflix, YouTube, Prime Video, Input (TCL source panel) and gear buttons
#   all kept working, and volume kept auto-repeating: no InputKeyService / HomeKeyService needed.
# - Mic / Google voice worked with com.tcl.assistant disabled.
# - The first `pm install` of the launcher hung past tv.py's 120 s timeout with no dialog on screen; a retry of
#   `pm install -r` on the already-pushed APK answered Success in a second.
# - Wi-Fi pill shows "Wi-Fi" instead of the SSID because Location is off (location_mode 0); left off by choice.
#
# Kept by choice on this unit: Netflix, Prime Video, YouTube, YouTube Music, Google TV app, TCL Channel, TCL+,
# USB media player, Google voice search / Assistant, Chromecast, TCL firmware updates.
#
# DO NOT DISABLE: com.tcl.tv, com.tcl.tvinput (Live TV, tuner, HDMI/AV), com.tcl.suspension (Input key's source
# panel), com.tcl.settings, com.tcl.system.server, com.tcl.providers.config, com.tcl.initsetup,
