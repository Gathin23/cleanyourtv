# TCL 75" T7 Series 4K 144Hz QLED Google TV (75T7, device G08, model "Smart TV Pro", MediaTek tcl9618 / mt5896), US
# Android 14 (Google TV), firmware UTT2.250416.001 AU16, product G08_4K_US. About 2.4 GB RAM.
# Same G08 board as examples/tcl-c755-google-tv, tcl-qm6k-google-tv and tcl-85rm7l-google-tv, on the US
# firmware build. Those lists were the starting point; this one adds what the US set ships on top (streaming
# preloads and a few TCL extras) and the Android 14 ad and privacy services.
# Second unit: TCL 55Q77K (55", model "Smart TV Pro", G08_4K_US, client type TCL-NA-MT9653-S1, MediaTek MT9653),
# same firmware UTT2.250416.001 AU16, on Ethernet. That owner applied this list on 23 October 2026 except AirPlay,
# the TCL browser and the streaming apps, kept by choice, and the set came through a reboot the same day.
# README.md has that unit's remote button codes and notes. No package changes from it: a few more it disabled
# have one day of use, not a few.
#
# Tested 20-21 October 2026 on one set, 37 packages in all. The first 35 were disabled, the TV was rebooted and
# all 35 were still disabled afterwards. The last two (launcherx and setupwraith) were added later for a custom
# launcher and the TV has not been rebooted since. That is about one day of use, not weeks. Everything was
# disabled by hand with `pm disable-user --user 0` (one call each, in batches of ten or fewer), not with
# tools/disable.sh.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-g08-us-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-g08-us-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.tcl.tv.
# Left enabled on purpose: com.tcl.tv, com.tcl.tvinput, com.tcl.suspension (the input menu), com.tcl.autopair,
# com.tcl.systemserver, com.tcl.providers.config, com.tcl.initsetup, com.tcl.useragreement,
# com.tcl.globalkeyoverlay, com.tcl.systemui.plugin, com.tcl.factory.view, com.tcl.gamebar (the game bar on
# this 144 Hz gaming set), com.google.android.katniss (voice), Netflix, YouTube, Play Services and all
# com.mediatek.* and com.dolby.* except the AirPlay ones.
# Also left enabled, not tried: com.tcl.ttvs (analytics; the C755 list disables it as Samba TV ACR, and on
# some TCL sets it is also the firmware updater), com.tcl.partnercustomizer, com.tcl.interactive,
# com.tcl.smartlink.core, com.tcl.UpdatePeripheral, com.google.android.partnersetup.
#
# Differences from the C755 list: com.tcl.dashboard, com.tcl.hearaid and com.tcl.t_solo are disabled here
# (the C755 list keeps them); everything under "Streaming preloads" is the US set's own.
