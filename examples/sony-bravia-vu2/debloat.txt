# Network ADB: no Network/ADB or Wireless debugging toggle. USB debugging alone opens port 5555, and

# Found before cleanup: Play Movies & TV and Play Games disabled by hand (state 3), BRAVIA chat
# (com.sony.dtv.braviachat) by the system (state 2), so none of them is listed. The Play Store

# update without it.

# Chromecast (com.google.android.apps.mediashell) and setupwraith (casting reads its credentials from

# tvlauncher was disabled), the streaming apps, Play Store and Play Services (also the system updater:
# com.google.android.gms/.update.SystemUpdatePanoActivity).
# Kept, owner unsure: com.sony.dtv.smarthelp (the remote's HELP button opens it; it also receives
# GLOBAL_BUTTON), com.sony.dtv.helpguidecontents, com.sony.dtv.m2.seeds.* (TV control with smart
# speakers; com.sony.dtv.applicationdisabler sets these enabled).
# Left alone: inputs and tuner (com.android.tv, com.realtek.dtv, com.realtek.tv.atv,
# com.realtek.tv.passthrough), com.sony.dtv.smartui, remotecontrolsettings, ipcontrol, timers,
# sonysystemservice, applicationdisabler, com.realtek.tvmediaplay (USB media), com.realtek.usbupdate
# and the service menu (com.realtek.servicemenu, never opened).
# android.autoinstalls.config.Sony.BRAVIA_VU2 and com.android.htmlviewer are skipped by tools/disable.sh
# (their dumpsys shows no permission block), so both stay enabled.
#
# Remote: with this list and launcher/ as Home, Input, YouTube, Netflix, YouTube Music, Prime Video,
# the Settings gear, mic, HELP, APPS, TV, GUIDE and Home all work with no key helper, and a held
# Volume + still ramps.
#
# Status: applied 2026-10-30 on one TV in four batches with a screenshot after each (the last after

# re-enabling nothing; Home and every remote button checked the same day. Not yet lived with for
# several days.
