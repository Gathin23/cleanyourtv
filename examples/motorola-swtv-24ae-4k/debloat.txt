# Live TV / tuner:  com.cltv.hybrid (iWedia CanaliTV), with com.cltv.mal

# Remote:           the Settings (gear) button sends keycode 83 (KEYCODE_NOTIFICATION); it needs HomeKeyService
#                   (settings_key_keycodes 83). With the helper on, a held volume key steps only once.
#
# Quirks on this firmware, all seen on the TV:
# - com.netflix.ninja is turned back on by the firmware at every boot. Disabling it only lasts until the
#   next restart; block it from running in the background instead if you never use it:
#   `cmd appops set com.netflix.ninja RUN_ANY_IN_BACKGROUND ignore`, the same for RUN_IN_BACKGROUND, then
#   `cmd appops write-settings` (undo: set both back to `default`). That freed about 50 MB of RAM.
# - Wi-Fi joined in the first-run wizard belongs to setupwraith, and Android forgets it the moment setupwraith
#   is disabled. Check `dumpsys wifi | grep -o 'cname=[^ ]*'`: if it is not android.uid.system, forget the
#   network and join it again in Settings before setupwraith goes.
# - The ambient glow costs about 22 ms a frame on this GPU (~45 fps). reduced_motion true with
#   focus_overshoot false keeps the glow at 11 ms a frame (60 fps).
#
# Disabled from the factory on this unit, so NOT listed here (restore.sh would turn them ON):
#   com.mediatek.tv.oneworld.tvcenter, com.mediatek.tv.retaildemo, com.mediatek.opapp,
#   com.mediatek.dtv.tvinput.atsctuner, com.mediatek.dtv.tvinput.isdbtuner and five jp.co.sharp.* demo apps.
