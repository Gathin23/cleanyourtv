# TCL 43S5K and 32V5C, India (device G13, product G13_2K_GB, model "Smart TV"), Google TV 14 (SDK 34),
# build UKN2.241110.001 AU10, security patch 2025-12-01. The 43S5K reports MediaTek MT9221 and the
# 32V5C reports MT5867 (both ro.board.platform mt5867); about 1 GB RAM (954 MB, low_ram=true), 32-bit
# only (armeabi-v7a).
# Unlike the G08 TCL Google TVs, Live TV and HDMI are MediaTek's com.mediatek.wwtv.tvcenter, not com.tcl.tv.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-43s5k/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-43s5k/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.mediatek.wwtv.tvcenter.
# Keep: com.mediatek.wwtv.tvcenter, com.mediatek.tvinput, com.mediatek.tv.service, com.tcl.suspension
# (source panel / Input button), com.tcl.keyhelp (virtual keys), com.tcl.useragreement, com.tcl.factory.view,
# mediatek.factorymenu.ui, com.mediatek.wwtv.setupwizard, com.google.android.tv.remote.service.
# Live TV/HDMI safety (both models): keep com.mediatek.wwtv.tvcenter; it also plays HDMI, so disabling it
# breaks both. Keep com.mediatek.tvinput, com.mediatek.tv.service and com.tcl.suspension as well.
#
# com.tcl.ttvs on this firmware is BOTH TCL's analytics (bi.core.BIService, identifier, trackdata) AND
# TCL's firmware/app updater (versionUpdateApp.core.SystemUpdateService). Disabling it stops TCL
# firmware updates until it is enabled again, so it is commented out below; uncomment it to trade
# updates for less tracking.
#
# The saved Wi-Fi network was created by com.google.android.tungsten.setupwraith on the 43S5K (cname= in
# dumpsys wifi), so forget and re-join it in Settings before setupwraith is disabled there. On the 32V5C
# the saved network survived disabling setupwraith without forgetting and re-joining; check dumpsys wifi /
# the network owner on another unit before copying that step.
#
# Applied in four batches on 2026-10-20 with a screenshot after each and lived with for an afternoon so far
# (shorter than CONTRIBUTING.md asks; I'll report back if anything breaks). Since then: two power cuts and a
# reboot, Home came back on launcher/ each time; Wi-Fi, the remote's Input key (TCL's source panel), the
# launcher's Inputs menu (HDMI 1, HDMI 2, Composite, Live TV), YouTube, Netflix and JioHotstar (with AdGuard
# Private DNS) all fine. launcherx was disabled by launcher/build-and-install.sh after the new Home ran.
#
# 32V5C variant (32-inch V5C, MT5867, 954 MB): applied and reboot-checked; package state was re-checked on
# 2026-10-22, and the owner reports several days of use. Home and ClockDream survived a reboot. The nine
# entries verified on this unit (exact match with pm list packages -d) are:
#   com.tcl.messagebox
#   com.tcl.logkit
#   android.autoinstalls.config.google.gtvpai
#   com.google.android.partnersetup
#   com.tcl.browser
#   com.google.android.feedback
#   com.android.tv.feedbackconsent
#   com.google.android.tungsten.setupwraith
#   com.google.android.apps.tv.dreamx
# The three entries marked [43S5K ONLY] below were not disabled on the 32V5C. Comment them out before
# applying this file to a 32V5C; they remain part of the tested 43S5K set.
#
# Known quirks on this firmware:
# - The remote's gear button sends keycode 83 (KEYCODE_NOTIFICATION, scancode 561), which only launcherx
#   handled: set settings_key_keycodes to [83] (config.xml or a theme) so it opens Settings again.
# - On both models, launcherx is disabled only after CleanYourTV owns Home; build-and-install does it,
#   and restore.sh needs launcherx as its argument.
# - HomeKeyService, used for the gear button, can stop volume long-press from repeating on some TCL
#   Google TV builds: holding volume then steps once. Set key_filter=false to restore the repeat and
#   lose the remapped keys, or leave HomeKeyService off. Not measured on the 32V5C; see
#   docs/TROUBLESHOOTING.md.
# - With katniss off the mic button does nothing; leave it enabled if you use voice.
# - Usage statistics restart empty after a power cut (they are written to disk only now and then).

# Batch 1: TCL tracking, ads and auto-installs

com.tcl.partnercustomizer              # TCL promo rows on the Google TV home; [43S5K ONLY]
android.autoinstalls.config.google.gtvpai   # silently installs partner apps
com.google.android.partnersetup        # partner attribution (RLZ pings)

com.google.android.feedback
com.android.tv.feedbackconsent

# re-joined in Settings so that it belongs to android.uid.system instead of setupwraith.
# 32V5C: the saved network survived disabling setupwraith without that step here; verify the owner on
# another unit before copying.
com.google.android.tungsten.setupwraith
