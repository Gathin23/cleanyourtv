# Stock launcher is com.google.android.tvlauncher and it has HOME priority 2 on this firmware: it
# must be disabled, or set-home-activity reports Success and HOME still lands on it. Install the
# replacement launcher first, otherwise disable.sh will skip that line for its own HOME guard.
# Live TV is com.tcl.tv, the tuner input is com.tcl.tvinput, HDMI and AV are com.tcl.tvpassthrough.
#
# Factory menu from the remote, no software needed:
#   Settings > Picture > Advanced Settings > Brightness, highlight Contrast, type 1 9 5 0
#   then Other > ADB. Developer options > USB debugging must be on as well, or the RSA dialog never
#   appears and adb says "unauthorized". service.adb.tcp.port is preset to 5555 by the vendor, so
#   ADB comes up on the network, not USB.
#
# WARNING - 1-Factory menu > NVM reset wipes the Wi-Fi MAC, the Widevine keybox and the Netflix
# ESN. It is not a one-step operation: after the NVM reset do a factory data reset AND reflash the
# full firmware over USB. Only the reflash re-provisions the vendor data; stopping earlier leaves a
# 02:00:00:00:00:00 Wi-Fi MAC and Netflix error -121 for good.
#

# Two quirks worth knowing when the list does less than it says:
#
# 1. com.google.android.speech.pumpkin accepted disable-user and came back as enabled=0 after the
#    next boot. Disabling it a second time stuck (enabled=3). If a Google component reappears,
#    re-apply and check: dumpsys package <pkg> | grep enabled=
#
# 2. com.tcl.smartalexa, com.tcl.versionUpdateApp and com.example.copydatatotv are PERSISTENT and
#    signed with android.uid.system. disable-user records them as disabled (enabled=3) but the
#    processes start at boot anyway, and am force-stop is followed by an immediate restart, so
#    roughly 88 MB stays resident until the TV is rooted. pm disable is refused to the shell:
#    SecurityException: Shell cannot change component state.
