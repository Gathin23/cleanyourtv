# Xiaomi TV A Pro 32" (MiTV-AXFU0, codename arctictale, Amlogic AMLT950D5), Google TV / Android 14 (SDK 34),
# firmware UKG3.241124.001.V816.0.9.0.UXFAATV. 1 GB usable RAM, 720p/tvdpi (213 dpi) display.
# Live TV app: com.mitv.livetv (set it as live_tv_package in launcher config.xml).
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh and build-and-install.sh:
#   STOCK_LAUNCHER=com.google.android.apps.tv.launcherx launcher/build-and-install.sh).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-axfu0/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-axfu0/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Keep (TV needs them): mitv.service, com.mi.bluetooth, com.mitv.setup, and com.mitv.overseaservice
# (critical: required for Xiaomi Bluetooth remote re-pairing and button stability; if disabled, remote
# unpairs after standby), com.droidlogic.tvinput (Amlogic hardware input provider, required for DVB
# tuner and HDMI input switching), com.mitv.livetv (native DVB live TV app).
# Keep (apps): com.google.android.apps.mediashell (Chromecast built-in; Stremio and other streaming apps
# play through it).
# Default IME is Gboard, no keyboard quirk. ~970 MB RAM available to Android OS.
# Keep com.mitv.gallery and com.mitv.videoplayer if you play USB drives: com.xiaomi.mitv.mediaexplorer
# opens media through them.
#
# Google TV 14 quirk: HOME is resolved by intent priority on this set. launcherx has priority 2,
# the setup wizard's RecoveryActivity priority 1, and any third-party launcher priority 0.
# Disabling launcherx alone causes Home presses to land on RecoveryActivity, which crash-loops
# system_server (soft reboots every ~60 s, Wi-Fi drops). Disabling com.google.android.tungsten.setupwraith
# allows CleanYourTV to take over Home cleanly, but it can cost casting (re-enable it if Cast stops working).
# IMPORTANT: com.google.android.tungsten.setupwraith owns the Wi-Fi network credentials if the TV was
# configured via the Google Home app. Ensure Ethernet is connected or verify credentials before
# disabling setupwraith, and re-enable it before a factory reset (restore.sh does this).
