# Alwtniet HY320 Mini projector (device adt3, Askey; Allwinner/HTC firmware), Android 11 (SDK 30)
# Firmware UI_Veng.projector.20250117.194417, 1280x720 panel, ~1 GB RAM (ro.config.low_ram=true).
# Same firmware family as examples/portronics-beem-470/ and examples/magcubic-hy300-pro/, older build.
# The firmware reports the generic "ADT-3" / "adt3" / askey identity: match on the build string,
# or on ro.product.model=HY320Mini.
#
# Apply:   TV_HOST=<projector ip> tools/disable.sh examples/alwtniet-hy320-mini/debloat.txt
# Undo:    TV_HOST=<projector ip> tools/restore.sh examples/alwtniet-hy320-mini/debloat.txt
# Everything is DISABLED, not uninstalled. Applied 2026-10-21 and lived with since: Wi-Fi, the
# remote, YouTube and Spotify keep working, and the launcher (STOCK_LAUNCHER=none) owns Home.
#
# Getting ADB: Settings > About > press OK on "Build number" seven times. This firmware says
# "Setup mode turned on" rather than "You are now a developer". Developer options is then under
# System; USB debugging opens port 5555. ro.adb.secure=1 (the Allow prompt appears).
#
# Kept on purpose:
# - com.htc.htcsettings: the projector's own settings (keystone, focus, picture).
# - com.htc.closedialog: the power-button menu (it holds REBOOT and SYSTEM_ALERT_WINDOW).
# - com.hotack.writesn: factory serial/MAC writer that starts at boot. Left alone here, as
#   disabling it while connected over Wi-Fi risks losing the connection.
# - com.android.nfx (NFXAccessibility, v1.1.3, updated in /data): left on here; the Portronics list
#   disables it without issues.
# - com.htc.htclauncherhighenglishd08: the stock Home. build-and-install.sh does not recognise it, so
#   run it with STOCK_LAUNCHER=none; set-home-activity takes Home and the stock one stays as fallback.
#
# Firmware notes:
# - The panel is 1280x720 but ships at density 240, which gives apps an 853x480dp screen. TV apps and
#   the launcher are laid out for 960x540dp: `wm density 213` (undo: `wm density reset`) fixes the
#   cramped layout.
# - Low-RAM device (about 30 MB free with apps running), yet Android still allowed a notification
#   listener (`cmd notification allow_listener`).
# - The unit arrived with unofficial streaming apps in the user partition, not the system image
#   (HDO Box, a "Cinema HD" build as com.yoku.marumovie.analytics, Sports Zone, UKTurks, StreamFire,
#   Drama Player). A factory reset removes them; they are not listed here because this list only
#   disables. com.hotack.silentsdk (the dropper on some H713 units) is not present on this build.

# HTC ad overlay, telemetry and app store
com.htc.expandsdk                      # starts at boot, draws over apps (SYSTEM_ALERT_WINDOW) and uses the internet
com.htc.eventuploadservice             # usage/event uploader
com.htc.storeos                        # HTC app store

# for firmware updates.
