# Not the Android 12 G08 board in examples/tcl-g08-eu-android12, and not the Android 12 C755/QM6K lists:
# this is the Android 14 G08 build, which ships more preloads. This list is a subset of the packages on
# that build — every line below was disabled on one set (75T8C, Härnösand, Sweden) and left in place for
# five days and a reboot before it was written down.

# DO NOT DISABLE on this build — each was checked on this set:
# com.tcl.interactive  - provides the TIAS service com.tcl.tv binds for the source/HbbTV overlay. Disabled
#   (it is in Free My TV's DEBLOAT list), com.tcl.tv's embedded tbrowser client logged
#   "vendor.tcl.tvinput.extend-service: Passing null binder object as non-@nullable AIDL IBinder" plus a
#   Tbrowser NullPointerException at Tbrowser.java:600 roughly ten times a second, indefinitely. Re-enabled,
#   the flood stopped. Cost of the flood is small (com.tcl.tv sat at ~1% CPU) but it never ends.
# com.tcl.suspension   - hosts the source-menu QuickPanel. Disabling it makes the remote's Source key
#   (KEYCODE_TV_INPUT, 178) silently dead. Source key verified working on this set.
# com.tcl.ttvs         - same TIAS chain; also the teletext soft-keyboard IME.
# com.tcl.autopair     - Bluetooth remote pairing. Disabled, a remote that unpairs can never pair again.
# com.tcl.t_solo       - Bluetooth speaker output ("listen alone"). Kept: the owner plays TV audio over a
#   Bluetooth speaker.
# com.tcl.guard        - TCL permission shield in system_ext. Disabled, the system retried
#   com.tcl.guard/.memorymanager.TGuardService every 5 seconds.
# com.tcl.UpdatePeripheral - remote firmware updates; kept on purpose.
# com.tcl.miracast     - screen mirroring. Kept: Chromecast (com.google.android.apps.mediashell) is a
#   separate package and is untouched, but Miracast is the only "cast screen" route on this set.
# com.tcl.hearaid      - hearing aids, wireless speakers, sound field.
# com.tcl.gamebar      - runs under android.uid.system; has a SourceReceiver on the input path.
# com.tpa.kb           - runs under android.uid.system; purpose unknown.
# com.tcl.dashboard is disabled above, but note it is in Free My TV's PROTECTED list — that project
#   guards it for other TCL boards, where it hosts home-screen pushes.
