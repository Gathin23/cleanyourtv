# Skyworth 4K Google TV Stick (HP4609-Skyworth, device YYT, board HP46B, Amlogic),
# Google TV 14 (API 34), firmware UKG3.260128.001.C3.3.5_20260723 (2026-07-23),
# armeabi-v7a, about 1.9 GB RAM. Sold in South-East Asia as "4K Google TV Stick".
# Stock home: com.google.android.apps.tv.launcherx. No Live TV app on this firmware.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/skyworth-4k-google-tv-stick/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/skyworth-4k-google-tv-stick/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Tested 2026-11-02 on one unit: home, HDMI input switching, Wi-Fi, Bluetooth remote,
# Playback from YouTube and a third-party player all still work. No re-enables so far.
# The vendor packages here are com.sdt.* / com.mft.* (Skyworth Digital), not the
# com.smartdevice.* family the other Skyworth folders list.
#
# Known quirk: com.google.android.tungsten.setupwraith was already disabled when this
# list was written, so the Wi-Fi network had been saved before that. Check
# docs/TROUBLESHOOTING.md before disabling it on a set still running the setup wizard.
