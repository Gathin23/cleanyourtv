# Acer AR32HDIGU2841AT 32" HD (device R3_GTV, MOKA, Realtek RTD2841A), India, Google TV 14, firmware UKR1.260612
# Build UKR1.260612, incremental 2624, fingerprint ACER/ACER/R3_GTV:14/UKR1.260612/2624:user/release-keys
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/acer-ar32hdigu2841at/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/acer-ar32hdigu2841at/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV and inputs: com.apps.passthrough.
#
# DO NOT disable launcherx or com.google.android.tungsten.setupwraith on this TV. The firmware re-enables
# setupwraith early in every boot, so with launcherx off its RecoveryActivity loops and takes Home on the
# next cold boot (see docs/devices/acer-r4g.md and examples/kalley-43g200).
# Also, setupwraith owns the saved Wi-Fi network (dumpsys wifi | grep -o 'cname=[^ ]*').
# Keep launcherx enabled and use HOME_KEY_SERVICE with stock_home_redirect=com.google.android.apps.tv.launcherx
# to redirect Home to the new launcher without triggering RecoveryActivity loops.
#
# Cold boot behavior: Acer/Realtek's modified settings runs SetPmodServiceJob at cold boot which re-enables
# packages from a hard-coded list (see docs/devices/acer-r4g.md). On this firmware, 7 packages stay permanently
# disabled across cold boots (com.apps.usbmediaplayer, com.apps.mk.wd, android.autoinstalls.config.scbc.device,
# com.android.tv.feedbackconsent, com.realtek.leanbacklauncher.partnercustomizer, com.mxtech.videoplayer.television,
# com.apps.wifihotspot). The remaining packages stay disabled across warm reboots and sleep/wake, but are
# re-enabled by the firmware if the TV undergoes a full cold boot.
#
# Kept on purpose: com.google.android.apps.tv.launcherx (stock home, needed for boot safety),
#   com.google.android.tungsten.setupwraith (owns Wi-Fi network), com.apps.passthrough (HDMI / inputs),
#   com.apps.smartmenu (picture/display menu), key handlers (com.apps.smartkey, com.apps.virtualkey,
#   com.mk.tv.fivekey, com.realtek.keyinterceptserver, com.apps.bluetoothremote), com.apps.sys,
#   com.mk.service.tvmidware, Google Assistant (com.google.android.katniss), and user streaming apps
#   (YouTube, Netflix, Prime Video, Hotstar, Aha, Crunchyroll, Zee5, Airtel Xstream).
#
# Firmware updaters: com.apps.ota, com.apps.authota, com.realsil.ota, and com.google.android.tv.dfuservice
#   were disabled by user preference. Comment them out if you wish to receive firmware or remote updates.
