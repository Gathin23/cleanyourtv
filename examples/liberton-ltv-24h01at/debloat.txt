# Liberton LTV 24H01AT (Liberton, built by Changhong, device redwood, Android 11 API 30,
# firmware RTM6.230109.263, security patch 2023-01). Stock launcher: com.google.android.tvlauncher.
# The vendor layer is Homwee (com.homwee.*). Adapted from examples/rca-ai-pont (same redwood board)
# and examples/chiq-ai-pont (same Android 11 Homwee family). Verified against this TV's 122 packages.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/liberton-ltv-24h01at/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/liberton-ltv-24h01at/debloat.txt com.google.android.tvlauncher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# KEEP, even though the names look like bloat (from the redwood-family notes):
# - com.google.android.leanbacklauncher.partnercustomizer: provides the tvlauncher.widget content
#   provider. Without it com.mediatek.tv.service crash-loops after the next reboot and the Input
#   key and other remote hotkeys stop working.
# - com.homwee.factory, com.homwee.synckey (remote key service), com.mediatek.wwtv.setupwizard
#   (Live TV channel scan), all com.mediatek.* (Live TV, inputs, remote pairing).
#
# Owner's choices (2026-10-23): keep the voice assistant, keep Chromecast casting, disable the
# vendor updaters (commented out below, since shared lists keep updates), apps suggested by probe (Kyivstar TV, Netflix, YouTube, Prime Video, Spotify).
# No Anoki/FAST-channel packages on this firmware; no com.android.tv.feedbackconsent.
