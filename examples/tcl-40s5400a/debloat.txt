# TCL 40S5400A (40" FHD, S5400 series), EU unit: device C06, product C06_2K_GB, model "Smart TV".
# Android TV 11 (SDK 30), build AR2101, TCL software V8-T221T05-LF1V325, security patch 2025-03-05.
# MediaTek MT9221 (ro.board.platform mt5867), 4x Cortex-A55, about 1 GB RAM (low_ram=true).
# Likely a good starting point for other TCL S-series Android TV 11 sets on MT9221.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-40s5400a/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-40s5400a/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher (the restore.sh / build-and-install.sh default).
# Live TV app: com.tcl.tv. It also plays HDMI: it is the only handler of the passthrough-input
# VIEW intent the Inputs menu sends, and the remote's Input key opens its source picker.
# Inputs come from com.tcl.tvinput (2x HDMI, AV, tuner).
#
# Applied in three rounds on 2026-10-18 and lived with for one day so far (shorter than
# CONTRIBUTING.md asks; I'll report back if anything breaks). Rebooted after each round.
# Checked after the full list: launcher/ comes up as Home after a reboot, YouTube and Netflix open,
# switching to HDMI 2 (PS5) works, the remote's Input key opens the source picker.
# Checked after the first two rounds: Disney+, picture settings, the firmware update check.
# Not tested: casting from a phone (the Cast receiver is kept).
# Memory, PSS: stock tvlauncher 64 MB + 15 MB swapped vs 41 to 46 MB for my build of launcher/
# (a few local changes); tvrecommendations about 20 MB, katniss about 52 MB (two processes).
#
# Second unit: Asia-Pacific (persist.tcl.client_type TCL-AP-MT9221-01), same product C06_2K_GB and
# build AR2101, security patch 2024-02-05. The firmware update check reports "up to date" on this
# region's server, so AP units may stay behind the EU unit above. Remote: BT_RC833_M4 (Bluetooth LE,
# with mic). Applied on 2026-10-23 with the list below, except where noted; lived with until 2026-10-26.
# - Voice from the Bluetooth remote needs com.google.android.tv.remote.service as well as katniss.
#   With remote.service disabled the mic button does nothing and logs nothing. Both re-enabled here.
# - After katniss is re-enabled, the mic first opens the Assistant setup screen once; "Use
#   Assistant without signing in" is enough for voice search in YouTube.
# - Here the saved Wi-Fi network belonged to setupwraith (dumpsys wifi | grep cname=), so it was
#   left enabled; disabling it would have dropped Wi-Fi and ADB.
#
# Known quirks on this firmware:
# - The stock launcher declares HOME priority 2, so `cmd package set-home-activity` alone does not
#   take Home while it is enabled (Home still opens it). Disabling it, as build-and-install.sh
#   does, is required.
# - com.tcl.usercenter (TCL account) is switched back on by the system at every boot. It stays
#   idle, so it is left in the list.
# - com.tcl.ttvs is NOT text-to-speech: its activities are versionUpdateApp SystemUpdateActivity and
#   NetworkUpdateActivity, i.e. the firmware updater. Keep it for OTA updates.
# - After a reboot the system can switch to the last HDMI source on its own (com.tcl.tv started by
#   uid 1000 about 2 s after Home). Seen once; a PS5 on HDMI-CEC may be the trigger. Home brings
#   the launcher back.
# - The photo screensaver (com.google.android.backdrop) used about 105 MB while running. Before
#   disabling it, switch to the AOSP one:
#   tools/tv.py 'settings put secure screensaver_components com.android.dreams.basic/.Colors'
#   (restore: com.google.android.backdrop/com.google.android.backdrop.Backdrop)
# - screencap writes an empty file while an HDMI input is on screen. Press Home first.
#
