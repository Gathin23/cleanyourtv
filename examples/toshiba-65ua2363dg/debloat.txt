# Status: disabled in four batches on one TV on 2026-10-27, the last two lines after launcher/ took Home.
# Reboot-checked twice: nothing came back enabled, the new launcher was on screen at power-on (the firmware
# does not open Live TV by itself), Live TV and every HDMI input were listed. Then checked on the real remote
# by the owner: Home, Input, the app buttons, Back and volume all work. Hours of real use, not days: treat it
# as a starting point.

# KEEP, even though the names look like bloat (checked on this TV):
# - fusion.android.tv.demo: unlike the Cecotec and Toshiba Cosmos lists, it must stay. Its activities are
#   the only handler of com.mstar.android.intent.action.TV_INPUT_BUTTON (the remote's Input key), as on
#   examples/jvc-android-tv-menlo.
# - com.mediatek.android.leanbacklauncher.partnercustomizer: crash-loops com.mediatek.tv.service after a
#   reboot on MediaTek sets (see examples/cecotec-shandao).
# - com.mediatek.tvinput and com.mediatek.tv.service: the only hardware TvInputService implementations
#   (tuner, HDMI, VGA, composite, component, SCART). com.mediatek.wwtv.tvcenter (Live TV and the source
#   menu), com.mediatek.autopair (remote pairing), com.vestel.tv.service / keycontroller / backlight / eib.
# - mediatek.factorymenu.ui and com.mediatek.tv.factory: never started, never disabled.
# - android.autoinstalls.config.vestel.malin: tools/disable.sh skips it (dumpsys shows no permission block,
#   so its input check cannot read it), and it only acts during first setup. Left enabled.
# - Owner's choices: YouTube, YouTube Music, Netflix, Prime Video, Play Movies, Play Games, Chromecast
#   built-in (mediashell), Google Assistant (katniss) and the USB media player (MMP) all stay, and so does
#   Google TTS, which the Assistant speaks with. TalkBack ships disabled; not listed, so restore leaves it off.
#
# Quirks on this firmware:
