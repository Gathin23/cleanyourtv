# Sankey SMART2KTVSE (Whale OS)
# Model: SMART2KTVSE
# Brand: SiliconPlayer
# Device: am30bm
# Android: 13
# Product: WhaleTV
# Firmware: (not captured - TV went to sleep)
#
# Bloatware/Telemetry packages disabled with pm disable-user
# Tested and working for several days. Nothing broken.
#
# IMPORTANT: How to enable ADB on Whale OS (SMART2KTVSE)
# - MENU+1147 does NOT work on this model (tested, nothing appears)
# - To enable ADB: Install "Activity Launcher" app (de.szalkowski.activitylauncher)
#   via USB, open it, navigate to Settings -> Developer options, enable USB debugging
# - ADB over WiFi works on port 5555 after enabling
#

# - com.zeasn.livetv was NOT disabled because it provides the software layer

#   by hand on that unit. It is a system app, so pm disable-user works while
#   pm uninstall fails with DELETE_FAILED_INTERNAL_ERROR; the commented-out line
#   above lets the list do it.
# - MENU+1147 does NOT work on SMART2KTVSE model (tested, nothing appears)
