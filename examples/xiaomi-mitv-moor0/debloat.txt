# Xiaomi MiTV-MOOR0 (codename venom), Google TV / Android 11, firmware RTM5.220609.003.1246
# MediaTek chipset, 1.8 GB RAM.
#
# Package names that differ from the repo defaults on this firmware:
#   stock launcher   com.google.android.apps.tv.launcherx   (NOT com.google.android.tvlauncher)
#   Live TV app      com.mitv.livetv                        (NOT com.mediatek.wwtv.tvcenter), so set
#                                                           live_tv_package in config.xml or config.json
# Both are arguments: launcher/build-and-install.sh takes STOCK_LAUNCHER, tools/restore.sh takes the
# stock launcher as its second argument.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-moor0/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-moor0/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
#
# Kept deliberately, checked with `dumpsys package`:
#   com.mitv.livetv                              owns .input.SelectInputActivity and .tv.MainActivity (HDMI/AV/tuner switcher)
#   mitv.service                                 PERSISTENT; core TV service and remote key handling
#   com.mediatek.network                         PERSISTENT network monitor
#   com.mitv.overseaservice                      PERSISTENT; hosts .netflixService (Netflix key on the remote)
#   com.mediatek.tvinput, com.mediatek.tv.service   HDMI / tuner input framework
#   com.mi.bluetooth                             remote + Bluetooth pairing
#   com.google.android.tv.remote.service         phone-as-remote pairing
#   com.xiaomi.android.tvsetup.partnercustomizer holds BleRcActivity (Bluetooth remote pairing) and global key receiver
#   com.xiaomi.gtv.settings                      provides MainSliceProvider for Settings
#   com.xiaomi.mitv.scenemode                    MiTVSceneMode picture/sound scene settings
#   com.google.android.apps.mediashell           Chromecast built-in (kept by owner's choice)
#   com.xiaomi.mitv.updateservice, com.mitv.upgrader, com.mitv.ABUpdateStatus   firmware updaters (kept by owner's choice)
#
# Quirk: com.duokan.factorytest declares the HOME intent at priority 0, the same priority as a third-party
# launcher. Disable it before disabling launcherx so Home can never fall back to the factory test app.
