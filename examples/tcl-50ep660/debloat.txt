# TCL 50EP660, France (ro.product.model BeyondTV, board RTD2851 / rtd285o, client TCL-EU-RT2851-S1, software AP06),
# Android TV 9 (API 28), build PPR1.180610.011, security patch 2020-09-05.
# Same platform as examples/tcl-43ep660/ (AP04 software there); that list's notes apply too.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-50ep660/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-50ep660/debloat.txt
# Stock launcher: com.google.android.tvlauncher (restore.sh default); launcher/build-and-install.sh
# disables it once com.gathin.tvhome resolves as Home. Live TV app: com.tcl.tv. HDMI/AV: com.tcl.tvpassthrough.
#
# Tested 2026-11-21 on a real unit on Ethernet, in four batches with a screenshot after each, then two
# reboots: all disabled packages stayed disabled (the TCL user center did not come back on AP06), the TV
# booted to the new Home (no Live TV takeover), TCL's source menu and the launcher's Sources menu
# (HDMI1-3, AV) worked, and the real remote's Home, Input, app and Settings buttons all worked with no key
# helper enabled; holding volume up still ramps. Not yet lived with for days.
# Quirks: screencap works on Home; network ADB on 5555 closed after Network debugging was switched off and
# the TV restarted, with USB debugging left on.
#
# Already disabled at the factory, left alone: the 14 uk.co.freeview.* apps, com.tcl.bootadservice,
# com.tcl.common.terminalmanagerplus, com.tcl.gallery, Stan, ZEE5, Eros Now, LINE TV.
# Not touched (name says factory, never started): com.tcl.factory.view
