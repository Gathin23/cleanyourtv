# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.

# Applied in small batches on 2026-10-24 with a screenshot after each, then a custom launcher installed
# and the Home key checked the same day. NOT YET checked after a full power cycle: on other MOKA Google TV
# firmware (docs/devices/acer-r4g.md, examples/kalley-43g200) FallbackHome re-enables setupwraith at boot
# and its RecoveryActivity takes Home back. If that happens here, re-enable launcherx and please report it.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh / as STOCK_LAUNCHER).
# Home claimants with launcherx and setupwraith off: com.realtek.keyintercept FallbackHome and
# com.android.tv.settings FallbackHome; setupwraith's RecoveryActivity took Home when only launcherx was off.
# Inputs: HDMI and DisplayPort through com.realtek.tv.passthrough (HDMITvInputService, DPTvInputService).
# Disabled from the factory, so not listed (restore.sh would turn them ON): com.aiconnx.app.stream.tv001,
# com.google.android.youtube.tvmusic.
#
# Quirks on this firmware, all checked on the TV:
# - Port 5555 answered after turning on network debugging; tools/tv.py works directly.
# - The Wi-Fi network saved during first setup belonged to setupwraith (`dumpsys wifi | grep cname=`).
#   Forgetting and rejoining it in Settings made com.android.tv.settings the owner; only then was
#   setupwraith disabled, and Wi-Fi stayed up.
# - The TV has a second user profile (user 10). Settings > Install unknown apps saved its switch for
#   that profile; `appops set <package> REQUEST_INSTALL_PACKAGES allow` sets it for the main one.
# - `dumpsys audio | grep Muted:` shows the first stream, not music; read the STREAM_MUSIC block.
# - No com.realtek.power.ILedManager service, so the standby-light call in docs/devices/philips-r8g.md
#   doesn't apply.
#
# Kept on purpose: com.realtek.tv, com.realtek.tv.passthrough (inputs), com.realtek.menu (input/source
# menu), com.realtek.keyintercept and com.realtek.mousekeyintercept (key handling, FallbackHome),
# com.google.android.tv.remote.service (phone remote), com.realtek.rtkvirtualkeyboard and
# com.google.android.inputmethod.latin (keyboards), com.realtek.hid.agent, Play Store, Play Services,
# com.google.android.apps.mediashell (Chromecast), com.realsil.ota (firmware updates).
# Left alone because their purpose is unclear from their components: com.apps.factory.ui,
# com.realtek.display.monitor, com.realtek.ddcci, com.realtek.slices, com.aiconnx.service.stream.
