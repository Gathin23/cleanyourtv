# Skyworth SWTV-22AE-FHD (device umeda, MediaTek)
# Android 11 (SDK 30), build RTM7.230903.221, manufacturer skyworth. Google TV home.
# Stock launcher: com.google.android.apps.tv.launcherx
# The Android 14 list for this model is examples/skyworth-swtv-22ae-fhd/debloat.txt; this one is
# the Android 11 variant, filtered to packages that exist on this firmware.
# Setup wizard: com.google.android.tungsten.setupwraith (its RecoveryActivity claims HOME;
#   launcher/build-and-install.sh fails its Home check until this is disabled)
# Saved Wi-Fi network was owned by android.uid.system, so disabling setupwraith kept Wi-Fi.
# Disabling setupwraith gives Home back but costs casting (Chromecast built-in) on Google TV.
#   Check yours first: dumpsys wifi | grep -o 'cname=[^ ]*'
# HDMI and tuner inputs: com.mediatek.tvinput (left on)
# Remote: all buttons worked after the launcher install.
# Remote app button: worked. The Android 14 entry found it needs
#   dailymanage, dailyshortcut and myapp, so they are left enabled here.
# In use for about a month (as of 2026-11-21): nothing broke.
#
# Apply: TV_HOST=<tv ip> tools/disable.sh examples/skyworth-swtv-22ae-fhd-android11/debloat.txt
# Undo:  TV_HOST=<tv ip> tools/restore.sh examples/skyworth-swtv-22ae-fhd-android11/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# This firmware is Android 11, so the Android 14 components that other Skyworth lists
# disable (adservices, ondevicepersonalization, federatedcompute, Health Connect) are not
# installed here and are not listed.
#

# pairing), com.skyworth.backligthadjust (backlight), com.smartdevice.dailymanage,
