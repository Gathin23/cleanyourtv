# TCL 32S5400A (2023, 32" FHD), unit with SonyLIV/YuppTV preloads: device C06, product C06_2K_GB,
# model "Smart TV". Android TV 11 (SDK 30), build AR2101 / AR14, TCL software V8-T221T05-LF1V005,
# security patch 2022-01-05. MediaTek MT9221 (ro.board.platform mt5867), 1 GB RAM (low_ram=true).
# Same C06_2K_GB platform as the tested tcl-40s5400a list, on older firmware; that list is the
# fuller reference for this platform and explains the HOME-priority and TGuard behaviour.
#
# Apply:  TV_HOST=<tv ip> tools/disable.sh examples/tcl-32s5400a/debloat.txt
# Undo:   TV_HOST=<tv ip> tools/restore.sh examples/tcl-32s5400a/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher (the default; launcher/build-and-install.sh disables
# it after Home has moved). Live TV app: com.tcl.tv. Inputs: com.tcl.tvinput (2x HDMI, AV, tuner).
#
# Do not disable on this platform (kept; see tcl-40s5400a for the details):
# com.tcl.tv (Live TV + HDMI), com.tcl.tvinput (HDMI/AV/tuner), com.tcl.tcl_bt_rcu_service
# (Bluetooth remote), com.tcl.system.server (remote-key plumbing), com.tcl.autopair (Bluetooth
# remote pairing), com.tcl.settings (picture/sound), com.tcl.dashboard (TCL HOME tile),
# com.tcl.messagebox (carries the ttvs receiver), com.tcl.suspension (Quick Panel).
#
# Applied on 2026-10-20 and checked the same day (shorter than CONTRIBUTING.md asks; I will report
# back if anything breaks). The first pass also disabled com.tcl.system.server, com.tcl.autopair,
# com.tcl.settings, com.tcl.messagebox and com.tcl.dashboard; after comparing with tcl-40s5400a they
# are not in this list, because the first three are remote/pairing/picture-sound plumbing. If an
# earlier guide disabled them on your set, re-enable them:
#   for p in com.tcl.system.server com.tcl.autopair com.tcl.settings com.tcl.messagebox com.tcl.dashboard; do
#     TV_HOST=<tv ip> tools/tv.py "pm enable $p"; done
# (pm enable takes one package at a time.)
# Checked after the full list: a custom HOME app comes up after a reboot, YouTube opens, HDMI 1/2,
# AV and Live TV switch, Wi-Fi and Settings open, Play Store and Play Services stay enabled.
# Not tested: casting from a phone (the Cast receiver is kept), the physical remote's Input key,
# TCL picture/sound settings and Bluetooth re-pairing.
#
# Quirks on this firmware:
# - Stock tvlauncher declares HOME priority 2, so `cmd package set-home-activity` alone does not
#   take Home while it is enabled. Disable it after the replacement is running.
# - com.tcl.ttvs is the firmware updater, not text-to-speech. It is disabled below to stay on
#   V8-T221T05-LF1V005; comment it out if you want OTA updates.
# - screencap writes an empty file while an HDMI input is on screen. Press Home first.
# - com.tcl.usercenter can be switched back on by the system at boot on some C06 units; it stays
#   idle, so it is left in the list. Re-check `pm list packages -d` after a reboot.
