# Notes from this unit:
# - setupwraith holds the Cast receiver's credentials here too (CastInfoProvider in `dumpsys package`), so with
#   it disabled, casting from a phone fails (docs/TROUBLESHOOTING.md, "Untrusted device"). This owner uses
#   AirPlay instead (native on this set: com.mediatek.partner.airplay_sys, com.mediatek.AirplayAPK,
#   com.mediatek.airplaydaemon, all kept). If you cast from phones, leave setupwraith and launcherx on.
# - tools/disable.sh skipped setupwraith ("could not check which app owns the saved Wi-Fi networks"): the set
#   had no saved network at all and is on Ethernet, the case its message names, so it went with
#   FORCE_SETUPWRAITH=1.
# - Remote: the Sources key keeps working (org.droidtv.GlobalKey). The gear key sends KEY_SETUP (scancode 141)
#   and GlobalKey hands it to launcherx, so it does nothing once launcherx is off. HomeKeyService with
#   settings_key_scancodes 141 in config.xml brings it back, but with it bound, holding volume up or down moves
#   one step per press (as in docs/devices/tcl-55p71b-g09-key-repeat.md and the TA5 notes in
#   examples/philips-google-tv-ta1/README.md). This owner kept the gear key.
# - org.droidtv.demome is refused by tools/disable.sh (TV_INPUT_HARDWARE, #321); hide its tile with hidden_apps.
# - The Inputs menu also lists Component (HW6) and Composite (HW8); input_sources "HW6=-" "HW8=-" hides them.
#
