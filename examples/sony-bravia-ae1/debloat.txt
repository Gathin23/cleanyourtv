# Sony BRAVIA XR-55A95L (A95L, 2023 QD-OLED, MediaTek MT5838), EU firmware
# Android reports it as model "BRAVIA 4K AE1", device BRAVIA_AE_M6L; the retail model is in ro.boot.product.hardware.sku.
# Android 12 (Google TV, API 31), build BRAVIA_AE1_EU-user 12 STT2.231117.001 634040
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-bravia-ae1/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/sony-bravia-ae1/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (Google TV). Install the launcher first
# (launcher/build-and-install.sh): tools/disable.sh refuses to disable launcherx while it still owns Home.
# Live TV / input player: com.sony.dtv.tvlin. It also plays the HDMI inputs, so keep it even if you never
# watch broadcast TV; set it as live_tv_package and in hidden_apps (config.json here). The Inputs menu
# lists HDMI 1-4 and Live TV, and picking an HDMI port opens tvlin on that input.
# Keep com.sony.dtv.tvlin, com.sony.dtv.tvinput.dvbtuner, com.sony.dtv.sonysystemservice, imeproxy,
# settingsprovider, the Sony settings apps, update/update.agent.* (firmware) and all com.mediatek.*:
# they drive HDMI, the tuner, the remote and updates.
# Kept by owner's choice: Netflix, YouTube, Prime Video, UEI QuickSet (IR blaster), Sony IoT/smart-speaker
# control (seeds.iot), Sony IP control (webapi), firmware updates. Left alone because their components
# don't say enough: fingerprinterserver, crashlogcollector, lastaccess, interactivetvutil.
# This set has no Chromecast (mediashell) and no Google Assistant (katniss) package.
# Already disabled at the factory: the my5, sounds, iplayer, itv and all4 launchers, com.youview.poa,
# de.hdplus.tvapp.androidtv. Not in this list, so restore.sh leaves them as they are.
#
# Quirks on this firmware, all checked on the TV:
# - setupwraith claims HOME with priority 1; on this unit it did not own the saved Wi-Fi network
#   (`dumpsys wifi | grep -o 'cname=[^ ]*'` showed android.uid.system only). Check yours first.
# - The remote's Input key opens Sony's own source panel (tvlin's GlobalKeyReceiver): no helper needed.
# - With launcherx disabled the Settings, Netflix, YouTube and Prime Video buttons do nothing. They come
#   back with HOME_KEY_SERVICE=1 and scancodes (getevent, decimal): Settings 646 (settings_key_scancodes,
#   config.xml only), Netflix 583, YouTube 485, Prime Video 490 (app_keys, in config.json here).
# - With that helper bound, a held Volume key moves one step instead of ramping, the same trade as
#   docs/devices/tcl-55p71b-g09-key-repeat.md (checked on the real remote, before and after).
#
# Applied 22 October 2026 on one unit and reboot-checked: everything below stayed disabled and Home came
# back on the new launcher. Not yet lived with for days; if something breaks, re-enable it with
# `pm enable <package>` and please report it.
