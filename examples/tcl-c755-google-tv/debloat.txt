# TCL 75" C755 QD-Mini LED Google TV, 2024, Australia (device G08, model "Smart TV Pro", MediaTek tcl9618 / mt5896)
# Android 14 (Google TV), firmware UTT2.250416.001 AU02, product G08_4K_GB. About 2.4 GB RAM.
# Same G08 board as examples/tcl-qm6k-google-tv; that list was the starting point.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-c755-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-c755-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.tcl.tv.
# Keep: com.tcl.tv, com.tcl.tvinput, com.tcl.dashboard, com.tcl.suspension, com.tcl.autopair,
# com.tcl.systemserver, com.tcl.providers.config, com.tcl.initsetup, com.tcl.useragreement,
# com.tcl.globalkeyoverlay, com.tcl.systemui.plugin, com.tcl.factory.view, com.tcl.inputmethod.international
# (the keyboard), com.tcl.eva, com.tcl.hearaid (sound/accessibility + TCL wireless speakers),
# com.tcl.t_solo, tv.mopa.ginga (broadcast middleware) and all com.mediatek.* except AirPlay.
# Firmware updates arrive through Google Play Services (no separate TCL updater on this set).
# Also keep com.google.android.tv.remote.service: despite the name ("phone-app remote") it holds
# AtvSearchAssistantService, which carries the Bluetooth remote's mic button. Disabled, the mic did nothing.
# Keep com.tcl.suspension too: it IS the source panel the remote's Input button opens.
#
# Applied and verified on a real unit on 2026-10-20: Wi-Fi, HDMI switching (Inputs menu), Assistant,
# Disney+/Netflix playback with AdGuard Private DNS, and the launcher's clock screensaver all worked.
#
# Known quirks on this firmware:
# - The remote (BT_RC833_A1) sends KEYCODE_TV_INPUT for Input, and TCL's input policy hands it to
#   com.tcl.suspension before accessibility services see it, so INPUT_KEY_SERVICE=1 can't redirect it.
#   The Input button keeps opening TCL's source panel; the launcher's Inputs pill opens the glass menu.
# - With com.tcl.interactive disabled, com.tcl.tv logs "tias_sdk getService failure" ~10x/s for a few
#   seconds when the TV player starts, then stops. CPU on HDMI measured the same (~23%) with it on or off.
# - Disabling dreamx: set screensaver_components to com.gathin.tvhome/.ClockDream first.
