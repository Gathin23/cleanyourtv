# TCL 55C805 (device G08, product G08_4K_GB, model "Smart TV Pro", MediaTek tcl9618), EU firmware (region FR).
# The C805 is the C755 under its European name: in other markets this set is the 55C755.
# Google TV 14 (SDK 34), build UTT2.250416.001 AU04, software V8-T653T01-LF1V670. The third unit of this
# folder, with a list of its own: README.md in this folder has its notes. Applied on 2026-11-13 and lived with
# since, through restarts and standby, with this repo's launcher as Home.
# Starting points: this folder's debloat.txt and the EU unit in
# examples/tcl-65c7k-google-tv/debloat-75t8c-eu.txt (same firmware family), whose DO NOT DISABLE list

# com.tcl.waterfall.overseas, com.tcl.guard, com.tcl.dashboard) were tested on this unit and are off there:
# Batch 7. ttvs, which holds the firmware updater, is a comment in this list (see Firmware updaters).
# Also kept: com.tcl.tv, com.tcl.tvinput, keyboards, Play Store/Services, com.google.android.tv.remote.service
# (the remote's mic), com.tcl.webview (not in any tested list).
#
# Kept on here, though this folder's debloat.txt turns them off:
#   com.tcl.interactive    TCL's TIAS. Switched off on this unit for a test: on Live TV, the TV app and
#                          vendor.tcl.tvinput.extend-service then logged a failed lookup of tcl_tias_tbrowser
#                          about 35 times a second, without end (about 1-3% of one core), as on the EU 75T8C.
#                          This folder's AU02 unit saw only a few seconds of it each time the TV player started.
#   com.tcl.gamebar        Game mode for consoles, kept by the owner (a PS5 on HDMI). With Batch 7 off, Game Master
#                          still turned on for the PS5 (ALLM) and the game bar opened over it.
#
# Owner keeps: Chromecast, AirPlay, Miracast, Google Assistant, YouTube, Stremio, Nuvio. So these, off in
# debloat.txt by its first owner's choice, stay on here: com.google.android.apps.mediashell (Chromecast),
# com.tcl.airplay2, com.mediatek.AirplayAPK and com.mediatek.airplaydaemon (AirPlay), and com.tcl.miracast.
# Samsung's Smart View mirrors through com.tcl.miracast (its SinkActivity,
# over Wi-Fi Direct): switched off for a test, the TV was gone from Smart View, and Google Home's "Cast my screen"
# did not mirror instead.
# Already off on this unit before the list, and not in it: com.netflix.ninja (Netflix),
# com.amazon.amazonvideo.livingroom (Prime Video), com.tcl.magiconnectfree, com.tcl.ocean.instructions.
# Not installed on this unit: com.tcl.hotelmenu, au.com.stan.and (Stan).
# The other way round, com.tcl.t_solo (Bluetooth "listen alone"), which debloat.txt keeps, is off here by the
# owner's choice.
#
# Firmware updaters: com.tcl.ttvs (Batch 7) is the TV's own, and com.tcl.UpdatePeripheral (Batch 4) updates the
# remote's and TCL soundbars' firmware. This set has both off, by the owner's choice (ttvs also carries TCL's
# analytics and tracking), but they are comments here, so the list keeps updates working; uncomment them to match
# this set. With ttvs off, Settings > System > About > System update does nothing, for an update from a USB stick
# too, and Settings > Apps, where ttvs is called "TCSCore", offers no Enable for it: switch it on over ADB
# (pm enable com.tcl.ttvs) before an update, then re-apply the list.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-c755-google-tv/debloat-55c805.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-c755-google-tv/debloat-55c805.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled.
