# Quirks on this firmware, checked on the TV:
# - USB debugging alone opens port 5555; there is no Wireless debugging toggle.
# - HOME candidates: launcherx (priority 2), setupwraith/.RecoveryActivity (priority 1), so disable
#   setupwraith first, then run launcher/build-and-install.sh.
# - The default screensaver is dreamx's Backdrop (ambient mode). Point it at the launcher's clock
#   before disabling dreamx:
#   settings put secure screensaver_components com.gathin.tvhome/.ClockDream
#   settings put secure screensaver_default_component com.gathin.tvhome/.ClockDream
#   restore.sh does not undo either; the stock value of both is com.google.android.apps.tv.dreamx/.service.Backdrop
