# TCL 55C7K-UK QD-Mini LED Google TV, 2025, UK (device G08, model "Smart TV Pro", MediaTek tcl9618)
# Android 14 (Google TV), firmware UTT2.250416.001 AU02. About 2.4 GB RAM.
# Same G08 board and firmware build as examples/tcl-c755-google-tv; that list was the starting point.
# Second unit: TCL 50C7K, Poland, EU firmware (product G08_4K_GB, MediaTek mt5896, same UTT2.250416.001 AU02),
# on its built-in Ethernet port. Its choices and notes are in README.md in this folder.
#
# com.tcl.ttvs below is also the firmware updater on this build (its SystemUpdateActivity answers the manual
# update action): with it disabled there are no system updates. Both units disabled it for the Samba TV ACR
# tracking it carries. Enable it to check for an update (pm enable com.tcl.ttvs), then disable it again.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-55c7k-uk/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-55c7k-uk/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.tcl.tv.
# Keep (as on the C755): com.tcl.tv, com.tcl.tvinput, com.tcl.dashboard, com.tcl.suspension, com.tcl.autopair,
# com.tcl.systemserver, com.tcl.providers.config, com.tcl.initsetup, com.tcl.useragreement,
# com.tcl.globalkeyoverlay, com.tcl.systemui.plugin, com.tcl.factory.view, com.tcl.inputmethod.international,
# com.tcl.eva, com.tcl.hearaid, all com.mediatek.*, and com.google.android.tv.remote.service
# (it carries the Bluetooth remote's mic button).
# Left alone, purpose unclear: com.tpa.kb (holds TCL Live TV / Channel+ / Samba permissions), com.tvos.
# UK catch-up apps (BBC iPlayer, ITVX, Channel 4, BBC Sounds) are kept.
#
# Applied on a real unit on 2026-10-21 (not yet lived with for days): Wi-Fi stayed up, the launcher took
# Home, the Inputs menu listed HDMI 1-4 and Live TV, the Clock screensaver ran, and after a reboot Home,
# Wi-Fi and the screensaver setting came back with no system_server crashes.
#
# Known quirks on this firmware:
# - The Wi-Fi network saved during first setup belonged to setupwraith (cname=...setupwraith); forget and
#   re-join it in Settings before the list goes on, or disable.sh skips setupwraith.
# - `cmd dreams` is refused to the shell; to test the screensaver, drop screen_off_timeout to 15000 for a
#   moment and put the old value (600000 here) back.
