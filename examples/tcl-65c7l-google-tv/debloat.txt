# Same board and firmware build as examples/tcl-c755-google-tv; that list was the starting point, and its
# Keep list holds here unchanged.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-65c7l-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-65c7l-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# ADB: Developer options > Wireless debugging was enough; port 5555 answered too, without pairing.
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.tcl.tv.
# Left alone: com.tpa.kb (system uid, no running services, purpose unclear) and com.tvos (framework res).
# Kept on purpose by this owner: Chromecast, AirPlay, Miracast, Google Assistant (katniss and
# com.google.android.tv.remote.service, which carries the mic button), the game bar, the USB media
# player and gallery, Netflix, Prime Video, YouTube and YouTube Music.
#
# Tested 2026-10-22 on a real unit, applied in six batches with screenshots between them: Home, the Input
# button's source panel (com.tcl.suspension), Live TV (com.tcl.tv/com.tcl.player.TVActivity), all four
# HDMI inputs in tv_input, YouTube with AdGuard Private DNS, Play Store app updates and every remote button
# (gear, app buttons, Input, mic) kept working with launcherx disabled, so no key helper was enabled. All
# 27 packages stayed disabled after a reboot; nothing is re-enabled at boot on this firmware.
#
# Known quirks on this firmware:
# - The saved Wi-Fi network belonged to setupwraith (dumpsys wifi: cname=...setupwraith). Forget it and
#   join it again in Settings before setupwraith is disabled, or the TV drops off Wi-Fi.
