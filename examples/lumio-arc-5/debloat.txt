# Lumio Arc 5 Projector (SDMC himalaya, MediaTek MT9630), Google TV on Android 14 (SDK 34)
# Tested on: Lumio Arc 5 on Android 14 (firmware build UKNV.260904.001); all 16 disabled packages survived cold reboot with zero drift.
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/lumio-arc-5/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/lumio-arc-5/debloat.txt
# Everything is DISABLED for user 0, never uninstalled. Comment out any line you want to keep.
#
# Hardware & Projector Safeguards:
# DO NOT DISABLE projector hardware packages, ToF autofocus, STR8 auto-keystone
# correction, obstacle avoidance, screen fit, or optical/picture settings.
# All official Lumio apps (including TLDR), system OTA update services, and
# user-installed / sideloaded apps (pm list packages -3) are kept enabled.
#
# USB Storage & Media Playback:
# Keep all USB storage, OTG, and media indexing packages enabled
# (com.android.externalstorage, com.android.documentsui, com.android.providers.media,
# com.android.providers.downloads, and MediaTek/OEM USB or file managers) so external
# flash drives function for video playback.
#
# Stock launcher handover: com.google.android.apps.tv.launcherx and setup wizard
# com.google.android.tungsten.setupwraith remain enabled; com.gathin.tvhome handles Home.
