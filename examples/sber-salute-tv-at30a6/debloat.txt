# Stock launcher: ru.sberdevices.starlauncher (pass STOCK_LAUNCHER=ru.sberdevices.starlauncher to the install
# script). Developer options are locked on this firmware; how ADB was turned on is in README.md.
#
# Sber's platform service (ru.sberdevices.services, system uid) reinstalls its "mandatory" apps after every
# uninstall, usually at the next boot: parental control, SberPrime, beta, SberPlay, surveys, kids room, its
# YouTube and smart home all came back. Disabled, they stay put. Do not uninstall anything here.
# The platform service itself cannot be disabled (ru.sberdevices.services.core re-enables it within a
# second) and it hosts the Salute voice assistant. Leave it and ru.sberdevices.assistant alone.
#
# Keep: ru.sberdevices.tvinputs (HDMI/AV playback, it also answers the launcher's Inputs menu),
# ru.sberdevices.app.starkeyboard (the only IME), ru.sberdevices.webview (WebView provider),
# ru.sberdevices.systemui, com.android.systemui (Sber build), ru.sberdevices.SberDevicesServiceSystem,
# ru.sberdevices.location.provider, ru.sberdevices.app.setup, ru.sberdevices.settings, com.sberbank.settings,
# the ru.sberdevices.* overlays and resources, every com.droidlogic.* package and every com.cvte.* package
# (factory and TV API apps: do not open them, see README).
