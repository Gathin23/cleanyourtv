# Apply:    tools/disable.sh examples/dcolor-gd2/debloat.txt
# Restore:  tools/restore.sh examples/dcolor-gd2/debloat.txt com.google.android.apps.tv.launcherx
# Launcher: INPUT_KEY_SERVICE=1 launcher/build-and-install.sh
#
# Stock launcher: com.google.android.apps.tv.launcherx. Disable it only after the new launcher is Home;
# disable.sh skips it until another app answers HOME, so run this list again once the launcher is installed.
# setupwraith: the first-run wizard also claims HOME on Google TV. disable.sh skips it while it owns the
# saved Wi-Fi network (`dumpsys wifi | grep -o 'cname=[^ ]*'`): forget the network the box is on and join it
# again in Settings, then run this list again. FORCE_SETUPWRAITH=1 only on Ethernet, or if disable.sh still
# skips it after that re-join. Re-enable it before a factory reset; restore.sh does.
# Disabling setupwraith gives Home back but costs casting (Chromecast built-in); re-enable it to cast.
#
# Left on on purpose: com.android.vending (Play Store), com.google.android.gms, com.google.android.youtube.tv,
# com.netflix.ninja, com.google.android.tv.dfuservice (system updates), com.google.android.tv.remote.service
# (phone remote), com.android.tv.settings and the com.droidlogic.* / com.onn.* vendor packages.
#
# Remote: the YouTube button sends HID usage 0x0c0077, which Vendor_0957_Product_0005.kl maps to BUTTON_3
# (keycode 190). It does nothing once launcherx is off. Bring it back with app_keys
# "190:com.google.android.youtube.tv" (config.xml or a theme) and INPUT_KEY_SERVICE=1.
# Screensaver: Google TV's ambient mode (dreamx) is disabled below, so settings still points at it until
# you select the launcher's Clock:
#   settings put secure screensaver_components com.gathin.tvhome/.ClockDream
#   settings put secure screensaver_enabled 1
# Sleep: the TV's own idle timers are system screen_off_timeout (screensaver start) and secure sleep_timeout.
