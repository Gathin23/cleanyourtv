# Quirks on this firmware, all verified on the TV:
# - Only Wireless debugging: port 5555 stays closed. Pair once with the stock adb:
#     adb pair <tv ip>:<pairing port> <code>
#     adb connect <tv ip>:<connect port>
#     adb -s <tv ip>:<connect port> tcpip 5555
#   Port 5555 closes on every reboot; repeat `adb connect` + `adb tcpip 5555` each session.
# - Android switches Wireless debugging off on every reboot; turn it back on in Developer options.
# - All Wi-Fi networks owned by android.uid.system (not setupwraith) on this unit - safe to disable.
# - Chromecast (mediashell) verified NOT using setupwraith's CastInfoProvider on this build;
#   disabling setupwraith does not break casting.
# - All disables survived a full reboot (firmware does not auto-re-enable on this build).
# - Display: 3840x2160 physical, 1920x1080 override (normal for this SoC), density 320, no forced override.
