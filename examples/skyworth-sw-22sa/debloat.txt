#
# Quirks on this firmware, checked on the TV 2026-10-21:
# - Port 5555 goes flaky: opens when USB debugging is switched, may close again on its own, and
#   the adb client can go "offline" mid-session; reconnect with `adb connect <ip>:5555`.
#   The stock adb client (platform-tools 37.0.1) authenticates reliably; delete tools/adbkey to let
#   tools/tv.py fall back to ~/.android/adbkey when the TV already trusts that key.
# - Forget + re-join Wi-Fi changes the TV's DHCP address; rediscover it (Google Cast port 8008
#   answers before ADB does).
# - `adb exec-out screencap -p` is corrupted by an adbd stdout wrapper ("Init wrapper sys mutex
#   successful", LF->CRLF). Screenshots must go screencap to a file + `adb pull`.
# - No dedicated updater package; com.smartdevice.aftersale can push APKs on boot, so it is disabled.
#
