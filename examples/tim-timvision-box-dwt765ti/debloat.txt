# TIM TIMVISION Box (Technicolor DWT765TI, codename dwt765ti, board skipper_tim, Marvell Berlin), Android TV 8.0, firmware OTT1.201231.001 (6.0.5.0421), Italy
# Operator streaming box with no HDMI inputs, on Wi-Fi. Same board and firmware line as
# examples/tim-timvision-box-uzw4010tim, but another model; see README.md in this folder.
# Tested on one unit in one session with one checked reboot, not yet over several days.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tim-timvision-box-dwt765ti/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tim-timvision-box-dwt765ti/debloat.txt timvision.launcher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: timvision.launcher (com.canal.box.ui.boot.BoxMainActivity) is the TIMVISION app itself,
# with HOME priority 2. The new launcher takes Home with it disabled:
#   STOCK_LAUNCHER=timvision.launcher TV_HOST=<tv ip> launcher/build-and-install.sh
# which disables it after the launcher has started. No other app claims HOME (only
# com.android.tv.settings/.system.FallbackHome, priority -1000). Disabling timvision.launcher removes TIMVISION:
# a subscriber keeps the stock launcher and comments out the TIMVISION service group below.
#
# Kept: remote and pairing (com.technicolor.android.remotecontrolservice, com.technicolor.tv.remotepairing,
# com.technicolor.globalkey, com.google.android.tv.remote.service), the com.marvell.* HDMI-CEC/power/overscan
# services, the Technicolor hardware services (LED, HDMI resolution, CAS, hardware properties),
# Play Store and Play Services, Gboard, Chromecast (com.google.android.apps.mediashell) and
# com.technicolor.ota, which despite its name is WakeoncastEnabler (Chromecast wake), not an updater.
# The DVB-T tuner input (com.technicolor.android.dtvinput, dtvscan.project) was left enabled although unused.
# it.telecomitalia.digitalsupport stays enabled: tools/disable.sh skips it because it requests
# TV_INPUT_HARDWARE. com.technicolor.factorycert was not touched and not opened.
#
# The updaters are commented out below, as this repo recommends. The tested unit has them disabled by its
# owner's choice (no TIMVISION, and com.technicolor.app.ota is also what pushes TIM's preloaded apps,
# FIGC VivoAzzurro arrived the day this was tested); with them off the box gets no firmware fixes.
#
# After a reboot this box starts in standby (mWakefulness=Asleep, black screenshots); the remote's power
# button or `input keyevent WAKEUP` brings up Home. Nothing in this list was re-enabled by the firmware at boot.
# Private DNS does not exist on Android 8.0.
