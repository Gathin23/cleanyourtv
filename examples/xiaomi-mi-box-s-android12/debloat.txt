# Notes from this box (in daily family use since 2026-10-22 with a custom launcher as Home):
# - Every active line below is disabled on this unit except the two telemetry apps, which were removed for
#   user 0 on 2026-10-22 before this list existed; disabling them is the reversible way to get the same result.
# - The remote's mic button is ASSIST and goes to Google Assistant through the TV remote service; no app can
#   intercept it unless it holds the Assistant role.
# - Xiaomi's own volume pill (SystemUI VolumeVerticalUIManager) cannot be hidden without root on Android 12.
# - With PatchWall, the recommendations and Xiaomi's screensaver off, the box idles noticeably cooler and the
#   launcher scrolls without stutter; nothing else changed in two days of Netflix, Prime Video and YouTube.
