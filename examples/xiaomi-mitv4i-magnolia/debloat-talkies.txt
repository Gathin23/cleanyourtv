# Xiaomi Mi TV 4I (MiTV4I, codename magnolia), Android 9 / API 28
# Firmware: Xiaomi/magnolia/magnolia:9/PI/3698 (build 3698, 2022-03-24)
# SoC: Amlogic txl (armeabi-v7a), 1 GB RAM, 1280x720 @ 213 dpi
# Second unit: Home launcher replaced with Talkies (com.techpp.glass/.HomeActivity).
#
# Apply:  TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv4i-magnolia/debloat-talkies.txt
# Undo:   TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv4i-magnolia/debloat-talkies.txt com.techpp.glass
#
# Everything is disabled with `pm disable-user`, never uninstalled. Verified on
# a real TV on 2026-11-22.
#
# KEPT ON PURPOSE (do not disable):
#   com.droidlogic.tvinput, com.droidlogic, com.droidlogic.tv.settings,
#   com.droidlogic.droidlivetv, com.droidlogic.overlay, com.droidlogic.ble,
#   com.droidlogic.SubTitleService, com.droidlogic.tv.soundeffectsettings
#       -> TV tuner, HDMI/AV inputs, picture/sound settings. Disabling these
#          breaks the source menu and input switching.
#   com.android.tv, com.android.tv.settings
#       -> Live Channels and the system TV settings / FallbackHome.
#   mitv.service, xiaomi.tvservice, com.xiaomi.mitv.res, com.xiaomi.android.TV.audio
#       -> core MiTV services and shared resources still used by the remote,
#          IR, audio routing and Droidlogic settings.
#   com.google.android.katniss, com.google.android.speech.pumpkin,
#   com.google.android.tts, com.google.android.inputmethod.latin
#       -> Google TV search, voice search, TTS and the on-screen keyboard.
#   com.google.android.tv.remote.service
#       -> Android TV phone remote.
#   com.google.android.gms, com.google.android.gsf, com.android.vending
#       -> Play services / Play Store.
#   com.android.bluetooth
#       -> Bluetooth remotes and audio.
#   com.xiaomi.mitv.updateservice
#       -> OTA firmware updates. Enable it temporarily to check for updates.
#   com.mitv.tvlock
#       -> parental lock. Disable only if you never use it.
#   com.google.android.tungsten.setupwraith
#       -> first-run setup wizard. Safe to disable after setup, but kept so a factory
#          reset still completes.
