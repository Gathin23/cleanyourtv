# Xiaomi MiTV4I (codename magnolia), Android TV 9 (SDK 28), firmware PI.3698 release-keys, Amlogic SoC.
# Stock launcher: com.google.android.tvlauncher (disabled only after launcher takeover).
# Live TV app: com.droidlogic.droidlivetv (preserved for tuner & HDMI).
# TV input service: com.droidlogic.tvinput (HDMI 1, HDMI 2, HDMI 3, AV).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv4i-magnolia/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv4i-magnolia/debloat.txt
# PowerShell:
#   tools\disable.ps1 -TvHost <tv ip> examples\xiaomi-mitv4i-magnolia\debloat.txt
#   tools\restore.ps1 -TvHost <tv ip> examples\xiaomi-mitv4i-magnolia\debloat.txt
# Everything is DISABLED with `pm disable-user --user 0`, never uninstalled.
#
# Notes:
# - Live TV & HDMI inputs are handled by com.droidlogic.droidlivetv and com.droidlogic.tvinput.
#   Never disable them.
# - Xiaomi audio services (com.xiaomi.android.TV.audio, mitv.service) are kept.
# - Chromecast built-in (com.google.android.apps.mediashell) is kept.
# - Firmware updater (com.xiaomi.mitv.updateservice) is commented out below so updates work;
#   uncomment to disable if desired.
# - Voice search, screensaver, and optional streaming apps are commented out below by default.
# - RAM impact: available memory increases from ~336 MB to ~426 MB (+90 MB free); swap usage
#   drops from 143 MB (56%) down to 40 MB (15%).
