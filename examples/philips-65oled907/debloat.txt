# What this list deliberately does NOT do, and why:
#   * com.google.android.tvlauncher is NOT listed. launcher/build-and-install.sh disabled the stock
#     launcher as part of the Home handover, and recorded its own restore snippet
#     (~/cleanyourtv-handover-<host>.txt). Adding it here would make tools/restore.sh record it as
#     "already disabled" and refuse to bring it back.
#   * The streaming apps stay: com.netflix.ninja, com.amazon.amazonvideo.livingroom,
#     com.google.android.youtube.tv and com.google.android.youtube.tvmusic. The 50PUS8517 and 65OLED706
#     lists disable Netflix and Prime Video because those owners did not use them. That is taste, not bloat.
#   * com.google.android.tungsten.setupwraith is NOT listed. This TV is on Wi-Fi, and the 55OLED707 file
#     says to keep it on a Wi-Fi set. Checked on this unit anyway: the saved network cname= is
#     android.uid.system:1000, not setupwraith, so disabling it would be safe here -- it is simply not
#     worth the risk for 24 MB. tools/disable.sh re-checks this at runtime regardless.
#   * Kept on purpose, all user-visible: org.droidtv.ambiair/ambihuecommon/calmancalibrator (Ambilight),
#     org.droidtv.xtv (the SOURCES drawer and the JointSpace API on 1925/1926), org.droidtv.eum,
#     org.droidtv.aurora, org.droidtv.playtv, hdmiservice, GlobalKey, tvsystemui, org.droidtv.oad,
#     com.phorus.playfi.softap (DTS Play-Fi), io.mimi.* (Mimi sound personalisation),
#     com.google.android.marvin.talkback (screen reader), org.droidtv.dlna (Media source),
#     org.droidtv.amazonalexa, com.cybercat.adbappcontrol.tv, com.spocky.projengmenu (Projectivy).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/philips-65oled907/debloat.txt

# Quirks that apply, from examples/philips-50pus8517 (same board, same firmware):
#   * pm disable-user persists to package-restrictions.xml with a ~10 s delay. Confirm with

#   * `adb reboot` over TCP hangs holding the dropped connection.
#   * The Android 11 shell cannot disable individual components of another app, and cannot `pm hide`.
