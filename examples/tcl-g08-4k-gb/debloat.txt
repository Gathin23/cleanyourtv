# The stock Google TV launcher.

#
# ALSO REQUIRED: com.google.android.tungsten.setupwraith
#   Its RecoveryActivity declares CATEGORY_HOME with priority=1, deliberately just above the
#   default (0), so it beats any third-party launcher. On this firmware none of the normal
#   routes work: `cmd package set-home-activity` returns Success but is a no-op, the manifest's
#   android:priority is ignored for third-party apps (PM still reports 0 even with 1000 in the
#   APK), and `cmd role add-role-holder android.app.role.HOME` succeeds without affecting HOME
#   resolution. Disabling only the RecoveryActivity component is refused by the shell
#   (SecurityException). Disabling the whole package is the only way, and it makes the custom
#   launcher the sole HOME candidate.
#   Re-enable it with `pm enable com.google.android.tungsten.setupwraith` before a factory
#   reset or before re-running the Google TV setup wizard.
com.google.android.tungsten.setupwraith
