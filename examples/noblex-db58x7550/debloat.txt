# Noblex DB58X7550 (58", Android model "AI PONT", product ISDB93CH, built by Changhong, codename sindorim),
# Android TV 11 (API 30), firmware RTO2.231030.002, about 1.3 GB RAM, MediaTek m7322. Argentina (ISDB-T).
# The vendor layer is Homwee (com.homwee.*). Started from examples/chiq-ai-pont (same Changhong/Homwee
# family, different board and firmware). This firmware ships no Anoki ACR, no FAST channel app and no
# Alexa control, so those lines are not here. Not the same set as examples/noblex-shinjuku (Skyworth).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/noblex-db58x7550/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/noblex-db58x7550/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher (the scripts' default). Live TV: com.mediatek.wwtv.tvcenter.
# Power-on settings and the held-volume note: see README.md in this folder.
#
# KEEP, even though the names look like bloat:
# - com.google.android.leanbacklauncher.partnercustomizer: on this family the Input key and other remote
#   hotkeys stop working after the next reboot without it (see examples/chiq-ai-pont/debloat.txt).
# - com.homwee.dmt.upgrade (firmware updates; it crashes once at every boot, with or without this list),
#   com.homwee.synckey (remote key service), com.homwee.factory, com.homwee.overlay.tvservice,
#   com.mediatek.* (Live TV, inputs, remote pairing).
#
# Notes from this firmware:
# - HDMI and Live TV screenshots come out black (protected video layer).
# - Wi-Fi goes down in standby: if ADB does not answer, turn the TV on with the remote first.
