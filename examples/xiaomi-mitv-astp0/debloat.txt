# Xiaomi MiTV-ASTP0 (codename mulan; China-market firmware, sold as L55M7-EA), Android 9 (SDK 28),
# firmware 22.12.2.1630, Amlogic/droidlogic, 1.5 GB RAM, 1080p panel. Used in Vietnam.
# Stock launcher: com.mitv.tvhome (HOME activity .MainActivityUserMode). It is not in
# KNOWN_STOCK_LAUNCHERS, so install with: STOCK_LAUNCHER=com.mitv.tvhome launcher/build-and-install.sh
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-astp0/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-astp0/debloat.txt com.mitv.tvhome
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Notes from this firmware:
# - Same family as xiaomi-mitv-astp1; this list starts from that one, minus what this build lacks
#   (com.gitvdemo.video, com.duokan.videodaily, com.xiaomi.tv.gallery, com.newtv.cboxtv).
# - No CN streaming apps preinstalled; no Google apps besides the YouTube and katniss the owner sideloaded.
# - Network ADB (port 5555) closes on every reboot; re-enable it in
#   Settings -> Account & Security -> ADB debugging after each power cycle. Wi-Fi also sleeps in
#   standby, so the TV drops off the network until it is woken.
# - mitv.service is the core MiTV service: do not touch it. The owner chose to drop payment, Mi Home,
#   Mi Video, the voice assistant and every casting receiver but AirPlay (in com.xiaomi.mitv.smartshare).
#   The app store and com.mitv.videoplayer (USB files) stay.
# - com.xiaomi.mitv.remotecontroller.service looped at 100-190% CPU and flooded logd (~490 MB in
#   30 min): its relay host is gone, so it is disabled below. ES File Explorer ran DLNA and a WebView
#   in the background; it is replaced by Material Files (F-Droid, me.zhanghai.android.files).
# - Home stays com.mitv.tvhome: set-home-activity succeeds but resolution ignores it, and with
#   com.mitv.tvhome disabled Home falls to com.android.tv.settings/.system.FallbackHome. Keep it
#   enabled; an accessibility service that answers the Home key (HOME_KEY_SERVICE=1) brings the new
#   launcher up instead.
# - The firmware has no night mode setting: cmd uimode night yes|no|auto. Auto needs a location for
#   sunset and the TV has none, so it stays in day mode.
# - The remote has no Input button; its Menu key (three lines) is KEYCODE_MENU, scancode 127. Inputs
#   switch only through Xiaomi's player: am start -a com.xiaomi.mitv.tvplayer.EXTSRC_PLAY
#   -n com.xiaomi.mitv.tvplayer/.ExternalSourceActivity --ei input N (HDMI1-3 = 23-25, AV = 2).
#   Starting the HDMI channel URI with a plain VIEW lets any app that claims every VIEW catch it.
# - The time zone ships as Asia/Shanghai, an hour ahead in Vietnam. Set the one the IP locates
#   (get.geojs.io/v1/ip/geo.json "timezone"): service call alarm 3 s16 Asia/Ho_Chi_Minh
# - Picture: Settings -> Image settings -> Display model is kept per source; "Picture" is the vivid
#   one (contrast 55, saturation 60, cold), "Standard" is flat.
