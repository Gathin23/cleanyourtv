# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.

# Stock launcher: com.google.android.apps.tv.launcherx. HOME claimants on stock: launcherx,
# com.google.android.tungsten.setupwraith/.RecoveryActivity and com.android.tv.settings/.system.FallbackHome.
#
# KEEP, even though some names look like bloat (roles as on the BenQ GV32, same board):
# - com.sdmc.kt: auto focus, keystone, zoom, rotation.
# - com.sdmc.btservice: Bluetooth remote pairing. com.sdmc.remotecontrolservice: the remote's input method.
#   com.sdmc.service: power events and global buttons.
# - fusion.android.tv.demo ("retail display"): handles the remote's Input key.
# - com.mediatek.wwtv.setupwizard, com.mediatek.tvinput, com.mediatek.tv.service, com.google.android.tv.inputplayer.
# - com.sdmc.implayer (USB media player): asks for TV_INPUT_HARDWARE, so disable.sh skips it.
# - Factory/test packages: com.dangs.factorytest, com.sdmc.sdmcfactory, com.sdmc.keyburn, mediatek.factorymenu.ui.
#   Never launch them, not even to look.
# - com.epson.projector.update: Epson's firmware updater, left enabled.
# - com.ref.devicedataexport: shares the system uid; one activity (launcher entry and the TV Settings action
#   com.android.tv.settings.action.DEVICE_DATA_EXPORT), no service, no boot receiver, found stopped.
#   An on-demand export tool, left alone.
#
# Notes from this unit:
# - Network ADB on port 5555 opened with USB debugging alone; no pairing needed.
# - Launcher: HOME takeover works once setupwraith is disabled; power-on lands on com.gathin.tvhome.
# - Remote: Home, Back, volume, D-pad, Input and the Prime Video button keep working without launcherx.
#   The Settings (gear) button goes dead with launcherx; Settings stays reachable from the launcher's
#   Settings pill. HOME_KEY_SERVICE was left off to keep held-key repeat (see examples/benq-gv32).
#   docs/devices/epson-ef21-settings-key.md brings the gear back without a key helper.
#   The YouTube and Netflix buttons do nothing if you uncomment those apps below.
# - Reboot-checked: everything listed stays disabled, Home survives, Wi-Fi stays connected.
