# Haier HRA962X2_2G_ALI6G_A (Ali6G board), Android TV 9 (SDK 28), firmware PPR1.180610.011.20220314 test-keys
# A China-market set on the Aliyun YunOS stack: the stock Home is Youku's launcher, and the
# firmware's own packages are com.yunos.* / com.haier.*. Works as a starting point for other
# Haier sets on Ali6G with the same package set.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/haier-hra962x2/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/haier-hra962x2/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# The updater is disabled here on purpose: on this set com.yunos.osupdate pushed a new preload
# (com.haier.aitv, an Aligenie content app) to /data/app while it was enabled. Re-enable it to
# check for firmware updates (remove the whole line to let check.py --fix re-disable it).
# Firmware updates arrive only while it is enabled.
#
# See README.md in this folder before installing the launcher: this firmware intercepts the
# remote's Home key in YunOSTVPolicy and sends a private intent instead of the standard HOME
# broadcast, so a stock launcher build does not receive the Home key without a manifest filter.
