# BPL 32H-E5341 (80 cm / 32", 1280x720), Android TV 11 (API 30), firmware RTMA.250416.061, India.
# Built by Changhong on its "AI PONT" platform: model AI PONT, product DVB86BL, device osaka,
# MediaTek mt5867, about 1.4 GB RAM (MemTotal 1442956 kB). Same osaka board as examples/aiwa-ai-pont-sa
# (Google TV 14 there); this unit runs Android TV 11 with the Google TV home (launcherx).
#
# Status: applied 2026-11-28 on one set, in three batches, each followed by a reboot. After every reboot
# the packages below stayed disabled, Home came back on its own (launcherx before the new launcher,
# com.gathin.tvhome after), Wi-Fi reconnected by itself, and logcat's crash buffer was empty.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/bpl-32h-e5341/debloat.txt
# Then:    TV_HOST=<tv ip> launcher/build-and-install.sh   (makes the new launcher Home, then disables launcherx)
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/bpl-32h-e5341/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh; this firmware has no
# com.google.android.tvlauncher). Live TV: com.mediatek.wwtv.tvcenter.
#
# ADB on this set: there is no Network or Wireless debugging toggle. USB debugging alone opens network ADB
# on port 5555, and the port stays open across reboots while that toggle is on. When you are done, switch
# USB debugging off (Settings > Device Preferences > Developer options) and check with
# tools/adb-closed.py <tv ip>.
#
# KEEP, even though some names look like bloat:
# - com.mediatek.android.leanbacklauncher.partnercustomizer: on the Android 11 CHiQ list (same platform),
#   disabling it crash-loops com.mediatek.tv.service after a reboot and the Input key stops working.
# - com.homwee.dmt.upgrade (firmware updates), com.homwee.synckey (remote keys), com.homwee.dynamicbacklight
#   (picture), com.homwee.factory and com.mediatek.tv.factorykey (never open these).
# - com.homwee.mmp.fileexplorer and com.homwee.mmp.imageplayer: the "Media Player" tile, which plays USB drives.
# - Every com.mediatek.* package not listed below (Live TV, HDMI inputs, tuner, remote pairing).
# - com.google.android.tv.remote.service, the keyboard, Play Store, Play services, WebView.
#
# Notes from this firmware:
# - TalkBack (com.google.android.marvin.talkback) shipped disabled.
# - The stock screensaver is com.google.android.apps.tv.dreamx/.service.Backdrop. Before disabling dreamx,
#   switch it: settings put secure screensaver_components com.android.dreams.basic/.Colors
# - Home claimants: launcherx/.home.HomeActivity (priority 2), setupwraith/.RecoveryActivity (priority 1),
#   then com.android.tv.settings/.system.FallbackHome. Disable setupwraith before launcherx goes, or Home
#   lands on the setup wizard; launcher/build-and-install.sh disables launcherx only after the new Home is set.
# - The remote's Input key keeps opening com.mediatek.wwtv.tvcenter/.nav.inputpanel.InputsPanelActivity with
#   the new launcher as Home. The launcher's Inputs menu lists HDMI 1-3, AV (composite) and Live TV.
# - The remote's power button suspends to RAM (ro.vendor.mstar.str.enable=user_mode): the set wakes in a
#   few seconds. Switching off at the wall means a full boot of about 30 s behind the BPL logo.
