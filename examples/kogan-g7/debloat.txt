# Known quirks on this firmware:
# - With launcherx disabled, setupwraith's RecoveryActivity claims HOME at priority 1, so it goes too.
#   Disabling it did not drop the TV off Wi-Fi here.
# - The remote's app buttons die with launcherx. Netflix (IR keycode 3001), YouTube (IR 3003) and Prime Video
#   (Bluetooth usage 0x0c0076) are consumed by Realtek's key service (com.realtek.keyintercept) before Android
#   sees them. Because the TV has the com.google.android.feature.AMATI_EXPERIENCE feature, it only hands them
#   to launcherx/.globalbutton.GlobalButtonLaunch_Receiver as an explicit broadcast, so they cannot be
#   remapped (same as the IR keys on inclo-google-tv-4k). Disney+ arrives as KEYCODE_BUTTON_6 (193) through
#   Google's GlobalKeyReceiver, and app_keys "193:com.disney.disneyplus" with InputKeyService brings it back
#   (checked with the real remote). Shell cannot disable launcherx's HomeActivity on its own
#   (SecurityException), and with launcherx enabled it takes HOME back, so the other three stay dead.
# - Disabling dreamx leaves screensaver_components pointing at it. Point it at the launcher's clock:
#   settings put secure screensaver_components com.gathin.tvhome/.ClockDream
