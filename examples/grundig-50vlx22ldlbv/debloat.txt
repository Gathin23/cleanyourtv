# Grundig 50VLX22LDLBV 50" Android TV (Arcelik-built, board CO3Plus, device "sinchon", MediaTek m7322), Netherlands

# ro.product.manufacturer = ARCELIK, ro.adb.secure = 1. USB debugging alone opens port 5555 (tested over Wi-Fi).

# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/grundig-50vlx22ldlbv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/grundig-50vlx22ldlbv/debloat.txt
# Windows: tools\disable.ps1 -TvHost <tv ip> examples\grundig-50vlx22ldlbv\debloat.txt (restore.ps1 to undo)

# Same Arcelik "sinchon" platform as examples/beko-b43b880b, older build. This firmware has no Anoki ACR,
# FAST channels or brand channel app, so those Beko entries are absent here.

# com.google.android.tungsten.setupwraith claims no HOME but owns the saved Wi-Fi network: left enabled.

# - fusion.android.tv.demo, com.arcelik.smartremoteservice: Input key and remote keys, as on the Beko.
# - com.arcelik.tv.arcelikbacklight, com.arcelik.ChannelEditor, com.google.android.leanbacklauncher.partnercustomizer.
# - com.mediatek.tv.service, com.mediatek.tvinput, com.mediatek.wwtv.tvcenter: Live TV, HDMI, source menu.

#   mediatek.factorymenu.ui, com.arcelik.tv.rctest.
# No separate firmware-updater package on this build.
#
# Reboot-checked: pm list packages -d identical before and after; nothing is re-enabled at boot.
# Launcher works: installs over pm install, owns Home (mFocusedApp) also after a reboot; every remote button
# (Home, Input, Settings, app keys) works without the key services, pressed on the real remote.
