# Launcher config used: live_tv_package org.droidtv.playtv; hidden_apps org.droidtv.eum, org.droidtv.demome,

# (org.droidtv.contentexplorer) pinned.

# Tested on: one session on 2026-11-15, wired Ethernet (built-in port), a USB stick plugged in. Applied from
# Windows with the PowerShell twin of tools/disable.sh, in six batches with a screenshot after each. After one reboot `pm list packages -d`
# was identical, Home resolved to com.gathin.tvhome and the real remote's Home key opened it. Live TV,
# Jellyfin and the ARD web app opened, the JointSpace API on 1926 still answered and the USB stick stayed
# mounted with USB debugging on. Not yet lived with for days; no HDMI, standby/wake or Ambilight+Hue check.
#
# Notes from this unit:
# 1. Keep the NetTV store packages if the NetTV web apps are used. org.droidtv.nettvapp3093 (ARD Mediathek,
#    a "Lieblings-App" tile on German sets) and nettvapp1814 (ARTE) start, then hand off an
#    android.intent.action.VIEW of type application/vnd.droidtv.nettv. Only org.droidtv.nettv_launcherapp
#    handles that type, so with it disabled the app logs "No activity found for intent" and nothing opens.
#    Re-enabling nettv_launcherapp alone was not enough here; with nettv.market, nettvapps, nettv_launcherapp
#    and nettvregistration all enabled again and one reboot, ARD worked. This folder's debloat.txt disables
#    all four together with every NetTV web app, so it never hit this.
# 2. Do not `am force-stop org.droidtv.nettvbrowser` while testing: afterwards the web apps opened to a black
#    screen until the next reboot, which reads as damage from the debloat when it is not.
# 3. tools/disable.sh skips org.droidtv.usagelogger and org.droidtv.demome (both ask for TV_INPUT_HARDWARE).
#    They were left on rather than forced with TVINPUT_ALLOW=1, so they are not listed below.
# 4. ADB: the RSA prompt never showed for tools/tv.py, after revoking authorisations, toggling USB debugging
#    and a mains power cycle. `adb connect <tv ip>:5555` with Google's platform-tools raised it at once;
#    afterwards tools/tv.py ran through that transport with TV_ADB_BINARY set (tools/native-adb.md).
# 5. Load average reads 18-29 on this board even straight after boot; with no crash or ANR in logcat, that is
#    the board, not the debloat.
# 6. The scenes theme bands in the night skies at the launcher's default RGB_565 decode; wallpaper_true_color
#    fixed it, and the set had memory to spare at 1.9 GB.
# 7. With the new Home the TV still powers on to Live TV by itself; the owner kept it that way.
