# Notes from this firmware:
# - The standby/screensaver ads come from com.xiaomi.mitv.hyper.screensaver: a plain
#   Activity with its own downloaded carousel, so screensaver_enabled=0 does not touch it.
# - Keep com.xiaomi.mitv.smartpanel enabled (Menu-button panel); disabling it kills the
#   Menu key. Do NOT add it here.
# - OS3.0.119's periodic cleaner re-enables packages at boot unless it is off:
#   `cmd periodic enable false` (this unit was set that way before the verifying reboot).
# - Firmware updater com.xiaomi.mitv.upgrade: off on this unit at the owner's request.
#   Its line below is commented out, so applying this list leaves OTA on for other sets;
#   re-enable it before checking for updates.
# - ADB over TCP closes on every boot: Settings -> 账号与安全 -> ADB 调试.
# - No idle clock screensaver is possible: the idle timeout path is a hard panel-off.
#   Keep screen_off_timeout at 2147483647.
