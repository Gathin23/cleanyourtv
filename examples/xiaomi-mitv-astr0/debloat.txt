# Notes from this firmware:
# - The standby/screensaver ads come from com.xiaomi.mitv.hyper.screensaver: a plain
#   Activity with its own downloaded carousel, not a DreamService, so screensaver_enabled=0
#   does not touch it. com.mitv.screensaver / com.xiaomi.mitv.advertise do not exist here.
# - Keep com.xiaomi.mitv.smartpanel enabled (Menu-button panel: source switcher +
#   wireless tiles). Do NOT add it here; disabling it kills the Menu key.
# - ADB over TCP closes on every boot: Settings -> 账号与安全 -> ADB 调试.
# - No idle clock screensaver is possible: the idle timeout path is a hard panel-off
#   (suspend), the AOSP dream never renders. Keep screen_off_timeout at 2147483647.
