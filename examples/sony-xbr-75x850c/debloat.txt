# Sony BRAVIA XBR-75X850C (2015, SVP-DTV15 "BRAVIA 4K 2015" platform, MediaTek), US firmware
# Android TV 8.0 (API 26), build SVP4KDTV15_UC-user 8.0.0 OPR2.170623.027.S16 6.827, 1.5 GB RAM
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-xbr-75x850c/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/sony-xbr-75x850c/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Second unit of the same build as examples/sony-xbr-55x850c (and sony-kd-65x9300d), taken further for a TV
# used only as a display for an Apple TV on HDMI: no Google account, no streaming apps, no casting, no voice,
# nothing network-facing beyond what HDMI, the inputs, Settings and firmware updates need. Start from the
# 55-inch list if you want to keep Netflix, YouTube or Chromecast; this one is the "dumb display" cut.
# Stock launcher: com.google.android.tvlauncher (restore.sh's default). The only other HOME handler is
# com.android.tv.settings/.system.FallbackHome; setupwraith has no HOME activity and is left alone.
# Live TV / input app: com.sony.dtv.tvx. Keep it: it also plays every HDMI input. Hide it in config.xml and
# set live_tv_package to it; the Inputs menu then lists HDMI 1, HDMI 2/MHL, HDMI 3, HDMI 4/ARC (with the CEC
# device's name), Video 1, Video 2/Component and Live TV.
# Keep: com.sony.dtv.tvinput.*, tvplayer*, braviasync* (HDMI-CEC: the Apple TV remote's power and volume),
# remotepairing, remotecontrolsettings, uinputservice, braviabluetoothservice, imeproxy, settingsprovider,
# systemupdate, duid.generator, enclave.service, timers, homenetwork (holds the power settings),
# all com.mediatek.* and mtktvapi.agent, Play Store and Play Services.
# Left alone on purpose: the rest of com.sony.dtv.b2b.* (hotel/pro mode plumbing), webapi.core, remoteaccess and
# netproxyservice (Sony IP control, uid 1000), privacypolicy, sonyselect.overlay (a /vendor/overlay RRO).
# Nothing was disabled at the factory. Eight streaming apps in the 55-inch list (Disney+, HBO, Pandora, Tubi,
# Pluto, Twitch, PBS Kids, AccuWeather) were not on this unit after a factory reset with no Google account.
#
# New in this list, checked with `dumpsys package` on this firmware:
# - com.sony.dtv.interactivetvplatform carries Kantar, Kuyun and ShopTv audience-measurement services over the
#   audio and video shared-memory buffers; interactivetvutil carries the action and application log collectors.
#   Other Sony lists keep them as "voice plumbing"; with voice off nothing was lost here.
# - com.sony.dtv.servermgr is a Firebase Cloud Messaging listener (Sony push messages).
# - DLNA, DIAL, Miracast, Chromecast and the Android TV phone-remote service are network listeners (ports
#   6466/6467 for the remote service) and go together; the IR remote is unaffected.
#
# Applied 30 Oct 2026 in eight batches with a screenshot and Home check after each; no crash loops
# (com.sony.dtv.systembootmonitor crashes once at boot on this firmware, as on the 55-inch; it is not listed).
# Launcher installed with build-and-install.sh and no key services; Home handed over cleanly. Reboot-checked once:
# Home came back on the new launcher, nothing re-enabled itself. Not yet lived with for weeks; if something breaks,
# re-enable it with `pm enable <package>` and please report it.
