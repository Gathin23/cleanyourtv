# Notes from this firmware:
# - The same set after its Android 11 update; the Android 9 list is examples/xiaomi-mitv-mssp2. Four of its
#   packages are not on this build (tv.bugreportsender, leanbacklauncher, leanbacklauncher.recommendations,
#   music), and nothing was disabled before this list.
# - The Xiaomi updater (com.xiaomi.mitv.updateservice, kept) installed new versions of PatchWall
#   (com.mitv.tvhome.atv) and Mi TV+ (com.mitv.tvhome.mitvplus) in the first hour, and an update puts a
#   package back to enabled. dumpsys package names the updater as lastDisabledCaller. Re-disable with
#     tools/venv/bin/python -I tools/check.py --fix examples/xiaomi-mitv-mssp2-android11/debloat.txt com.gathin.tvhome
# - Applied in three batches (telemetry, content rows, preloads) with a screenshot after each; one
#   screenshot of the stock home came back all black while it reloaded after the content providers went,
#   and was normal five seconds later.
# - Wireless debugging is off by default; network ADB on 5555 opens with USB debugging alone, and closed
#   again (connection refused) after switching it off and rebooting.
# - Left alone on purpose: com.mediatek.wwtv.tvcenter / com.mediatek.tvinput (HDMI + tuner), mitv.service,
#   com.mediatek.tv.agent, com.mi.bluetooth, com.mediatek.hotkey.dispatcher, com.mstar.netflixobserver and
#   com.xiaomi.android.tvsetup.partnercustomizer (remote hotkeys, Netflix button),
#   com.google.android.tv.remote.service (phone remote), com.xiaomi.mitv.mediaexplorer (USB Media Player),
#   com.xiaomi.mitv.updateservice (firmware updates), Play Store, Play Services, Google Assistant (katniss),
#   Chromecast (mediashell), the Mi screensaver (com.mitv.dream), Ambient mode (backdrop) and the keyboard.
#   Never start com.mediatek.tv.factory or mediatek.factorymenu.ui.
