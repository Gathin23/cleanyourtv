# Stock Home and Live TV app: com.vivensis.launcher (Skyworth Digital).
# IMPORTANT: Do NOT disable com.vivensis.launcher or com.vivensis.dtvsetup. They run the satellite DTV
# tuner (com.skyworthdigital.tv.TvActivity) and antenna/channel search. Instead, keep com.vivensis.launcher
# enabled and run launcher/build-and-install.sh with STOCK_LAUNCHER=none, HOME_KEY_SERVICE=1 and
# RESTORE_KEY_SERVICES=1, plus "stock_home_redirect": "com.vivensis.launcher" in config.json (see README.md).
#
# USB expandable storage warning: if a USB drive is formatted as internal storage (/mnt/expand/<uuid>),
# Android mounts it ~13 s after PackageManagerService starts at boot, which drops the preferred Home activity
# and unbinds HomeKeyService on every reboot. Always move the launcher to internal flash storage after install:
#   TV_HOST=<tv ip> tools/venv/bin/python -I tools/tv.py 'pm move-package com.gathin.tvhome internal'
#
