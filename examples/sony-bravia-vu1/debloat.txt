# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# History: the same set was first removed with `pm uninstall --user 0` on 2026-10-18 and lived with for seven
# days (several reboots; Home, Inputs, Settings, Netflix and YouTube fine; no crashes seen apart from the one below).
# On 2026-10-25 the packages were re-enabled and this file was applied with tools/disable.sh:
# all 19 stayed disabled after a reboot, `tools/check.py` reported "nothing drifted", Home, Settings and the
# 21 HDMI/AV input entries were fine. One boot earlier in the run logged a crash in two Realtek vendor
# services (exTv HAL, com.realtek.tv.atv); both respawned and nothing was visibly wrong.
#
# Stock launcher: com.google.android.tvlauncher (classic Android TV; recommendations rows with sponsored
# tiles). cmd package set-home-activity printed Success and changed nothing: the stock launcher outranks any
# other HOME app, so it has to be disabled for a new launcher to get Home (FLauncher, me.efesser.flauncher, was
# used). It is the last line below, commented out, because the run above removed it with uninstall rather than
# disable-user: disable it last, after the new launcher answers HOME.
# Tuner / inputs on this Realtek set are com.realtek.dtv, com.realtek.tv.atv and com.android.tv (Live
# Channels): keep them, plus the com.sony.dtv.* services (sonysystemservice, smartui = Input menu, ipcontrol,
# remotecontrolsettings, timers) and all com.realtek.* overlays.
#
# Kept on purpose: Chromecast built-in (com.google.android.apps.mediashell). Measured on this set after a fresh
# boot and 2 minutes idle: about 31 MB PSS (109 MB RSS, mostly shared pages), +16 MB used RAM, and
# `am force-stop` leaves it stopped (no respawn after 65 s) until the next boot.
#
# Gotchas from the run:
# - Wait at least 15 s after the last `pm` command, and run `adb shell sync`, before rebooting. Eight changes
#   made right before a reboot were lost (package state is written lazily).
# - Before disabling setupwraith check `dumpsys wifi | grep -o 'cname=[^ ]*'`. Here the saved networks belong
#   to android.uid.system and com.google.uid.shared, so Wi-Fi and ADB stayed up.
# - While setupwraith is enabled its .MainActivity answers HOME; it takes Home from a third-party launcher
#   until it is disabled.
# - Not tested: the remote's mic button after katniss goes (it also needs com.google.android.tv.remote.service,
#   kept), and Google Home Mini voice control of the TV.
