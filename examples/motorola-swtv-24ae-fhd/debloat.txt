# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.

# WARNING: If Wi-Fi was set up during the first-run wizard, the saved network belongs to setupwraith
# and Android DELETES it the moment setupwraith is disabled; the TV drops off the network and ADB with it.
# Check first: `dumpsys wifi | grep -o 'cname=[^ ]*'`. If it is not android.uid.system, forget the network
# and re-join it in Settings > Network BEFORE disabling setupwraith.
# On the Telefunken unit the network already belonged to android.uid.system, and the TV stayed online.
#
# Home hand-over (Telefunken unit): with launcherx enabled, `cmd package set-home-activity` to the new launcher
# answered Success but Home kept resolving to launcherx (install with STOCK_LAUNCHER=none), so the last two lines
# are what hands Home over. Install the new launcher first; disable.sh's Home guard keeps launcherx until then.
# Free memory (MemAvailable) went from about 205 MB to about 290 MB after the lines above Home and a reboot.
