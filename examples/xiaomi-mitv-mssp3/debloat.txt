# Xiaomi MiTV-MSSP3 (codename machuca), Android TV 11 (SDK 30), firmware RTT2.211214.001.1065, MediaTek.
# Live TV app: com.mediatek.wwtv.tvcenter (already the live_tv_package in launcher config.xml).
# Stock launcher: com.google.android.tvlauncher (the default, disabled by build-and-install.sh).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-mssp3/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-mssp3/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Notes from this firmware:
# - Default IME is already Gboard, so the Mi TV 4A missing-keyboard quirk doesn't apply.
# - Left alone on purpose: com.mediatek.wwtv.tvcenter / tvinput* (HDMI + tuner), mitv.service,
#   com.mi.bluetooth, com.mediatek.hotkey.dispatcher, com.google.android.tv.remote.service.
# - Netflix and Prime Video come back at every reboot even when disabled. The cause is
#   com.mstar.netflixobserver: it is a PERSISTENT app with the system uid, so Android starts it at boot even
#   when it is disabled, and it re-enables both (it even re-installed them after pm uninstall --user 0).
#   Disabling it is not enough. This list only disables it, like everything else in this repo.
#   Beyond what this repo does, and your own call: removing it for user 0 worked here across a reboot
#     pm uninstall --user 0 com.mstar.netflixobserver
#   and is undone with
#     cmd package install-existing com.mstar.netflixobserver   (the remote's Netflix button needs it)
# - Device admin is not supported on this firmware (no android.software.device_admin).
# - Remote's Input button: once the stock launcher is disabled it does nothing until handle_view_inputs is
#   true in the launcher's config.xml; no INPUT_KEY_SERVICE needed. README.md in this folder has why (second unit).
