# TCL C635 (reports as "Smart TV Pro", device BeyondTV4, product BeyondTV6, board rtd288o),
# Android TV 11 (API 30), sold in Brazil. Same platform family as the TCL 43P725 / 50C725K.
# Second unit: TCL 55C635i, build RP1A.200622.001 release-keys / AR11 (BeyondTV4-user 11).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-c635/debloat.txt
#          (or on Windows: tools\disable.ps1 -TvHost <tv ip> examples\tcl-c635\debloat.txt)
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-c635/debloat.txt
#          (or on Windows: tools\restore.ps1 -TvHost <tv ip> examples\tcl-c635\debloat.txt)
#
# Everything is DISABLED with `pm disable-user --user 0`, never uninstalled.
#
# Stock launcher: com.google.android.apps.tv.launcherx (Google TV launcher), kept enabled as
#   fallback. Installing this repo's launcher works; the Google TV default-home switch remains
#   a manual pick in Settings (set-home-activity did not stick on this C635 unit; the second unit's
#   notes below are where it persisted across reboots, with setupwraith disabled alongside launcherx).
# Live TV app: com.tcl.tv, with com.tcl.tvinput for the tuner and the HDMI inputs; keep both.
#
# Tested and verified on a real TCL C635 unit (Brazil):
# - Screenshots, HDMI inputs, Live TV, Wi-Fi, audio and the BT remote remain 100% operational.
# - 15 packages are disabled in total: the 13 below, and au.com.stan.and and tv.wuaki.apptv, which
#   arrived pre-disabled at factory.
# - Reboot-checked: the disabled set persists across restart.
#
# Second unit (TCL 55C635i, build RP1A.200622.001 / AR11):
# - Verified Home persistence: cmd package set-home-activity persists across reboots on this
#   build once com.google.android.tungsten.setupwraith is disabled alongside launcherx (both
#   commented out below; uncomment once this repo's launcher is installed).
# - Disabling voice assistants (katniss, assistant) is safe if you don't use voice search
#   (commented out below as optional choices).
# - 12 additional candidate packages tested on this unit are commented out at the bottom
#   (ttvs is the updater on some TCL sets, so left commented out for second-unit users).
# - Remote key helpers (such as HOME_KEY_SERVICE=1): the TV firmware applies the volume key before
#   the accessibility filter. With consume_volume_keys=false (the default), the key helper passes
#   the key back unconsumed and Android processes it a second time (double volume step on every tap).
#   Setting "consume_volume_keys": true in config.xml or a theme's config.json resolves this by
#   swallowing the duplicate event while preserving smooth held repeat.
#
