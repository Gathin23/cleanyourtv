# Stock launcher:  com.google.android.tvlauncher (classic Android TV, not Google TV)
# HOME claimers:   tvlauncher, dk.yousee.tv.leanback (YouSee's app registers as a home screen), FallbackHome.
# Live TV app:     com.mediatek.wwtv.tvcenter
# Inputs:          com.mediatek.tvinput and com.mediatek.tv.service (pm query-services TvInputService).
#
# KEEP, even though the names look like bloat (checked on this TV):
# - fusion.android.tv.demo: receives com.mstar.android.intent.action.TV_INPUT_BUTTON, the remote's
#   Input key, as on examples/jvc-android-tv-menlo.
# - com.mediatek.android.leanbacklauncher.partnercustomizer: crash-loops com.mediatek.tv.service after
#   a reboot on MediaTek sets (examples/chiq-ai-pont).
# - com.google.android.tungsten.setupwraith: does not own the saved Wi-Fi here (cname is GMS, uid
#   10044), but nothing is gained by disabling it while tvlauncher is Home.
# - com.vestel.tv.service, com.vestel.tv.keycontroller, com.vestel.tv.backlight, com.vestel.tv.eib,
#   com.mediatek.* (inputs, Live TV, Bluetooth remote pairing), com.dolby.android.audio.service.
# - Never opened: com.mediatek.tv.factory, mediatek.factorymenu.ui (factory menus).
#
# Owner's choices: Viu, Crunchyroll, YouTube and TV Bro stay. Chromecast built-in stays.
#
# Also disabled by hand on this set, after the launcher took Home: com.google.android.tvlauncher (set-home-activity
# said Success but Home stayed with it until it was disabled) and com.google.android.tvrecommendations.
#
# Netflix and Prime buttons: MediaTek's hotkey service (com.mediatek.tv.service) receives both as global buttons and
# starts Netflix / Prime Video itself, so the launcher's app_keys never see them; with both apps disabled the
# start fails quietly ("result code=-91" / "-92" in the log).
#
# Held volume: with a key-filtering accessibility helper on (the launcher's key_filter), a held volume key stops
# ramping, and filtered volume keys never reach the helper, so consume_volume_keys cannot bring it back. Leave
# key_filter off on this set.
#
# Backlight: Settings.Global picture_backlight (0 to 100) is the picture settings' Backlight slider, and
# com.mediatek.tv.service (TVMenuSettingsService) pushes every change of it to the panel at once.
