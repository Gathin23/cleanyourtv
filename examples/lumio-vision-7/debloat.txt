# Stock launcher: com.google.android.apps.tv.launcherx (disabled by launcher/build-and-install.sh after the
#   new launcher is confirmed Home). On this build setupwraith re-claims Home (.RecoveryActivity/.MainActivity)
#   the moment launcherx is off, and the shell cannot disable that component alone (SecurityException), so
#   setupwraith has to be disabled too (listed below). The active Wi-Fi here was system-owned (OwnerUid 1000),
#   so disabling setupwraith did NOT drop Wi-Fi - but disable.sh's guard is conservative, hence
#   FORCE_SETUPWRAITH=1. Disabling setupwraith may break Chromecast (mediashell reads device info from it);
#   re-enable setupwraith to get casting back.
# Live TV / tuner app: com.realtek.tv (set as live_tv_package in config.xml, and hidden from the grid).
# Netflix (com.netflix.ninja) shipped already disabled on this unit.
# Remote app buttons (for config.xml app_keys): YouTube 190, Netflix 191, Prime Video 195, TL;DR 200.
# Tested same day over Wireless debugging (classic port 5555 was already open): every HDMI/tuner input and
# installed app verified by screenshot; rebooted and the fork launcher came back as Home.
