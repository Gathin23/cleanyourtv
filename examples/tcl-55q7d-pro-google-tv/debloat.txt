# TCL 55Q7D Pro (model "Smart TV Pro", device G08, product G08_4K_GB, client type TCL-EU-MT9653-S1,
# MediaTek tcl9618), EU Google TV build (SKU eu): Android 14 (Google TV), firmware UTT2.250416.001 AU02.
# Remote BT_RC833A_B5 (Bluetooth).
# Same G08 board as examples/tcl-g08-us-google-tv (US, AU16) and the C755 / QM6K / 85RM7L Google TV lists;
# this list started from the US one and keeps only what this build ships.
#
# Tested 5 November 2026 on one set. 33 packages in all: 18 were already off from an earlier session, the
# other 15 went with tools/disable.sh in four batches, a screenshot between batches, and then a reboot; all
# 33 were still disabled afterwards. Home, Live TV, the input list, Play Store and the streaming apps still
# worked. That is one evening of use, not weeks.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-55q7d-pro-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-55q7d-pro-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.tcl.tv, and its "Live TV"
# input is com.tcl.channelplus/com.tcl.iptv.service.InputService.
# Left enabled on purpose: com.tcl.tv, com.tcl.tvinput, com.tcl.channelplus, com.tcl.suspension (the input
# list), com.tcl.autopair, com.tcl.systemserver, com.tcl.providers.config, com.tcl.initsetup,
# com.tcl.useragreement, com.tcl.globalkeyoverlay, com.tcl.systemui.plugin, com.tcl.factory.view,
# com.tcl.gamebar, com.tcl.ttvs (also TCL's firmware OTA updater on this build), com.google.android.katniss
# (voice), com.google.android.mediashell (Cast), Google TTS, AirPlay/Miracast, the Play Store, Play Services
# and every streaming app.
#
# com.tcl.interactive is disabled here and the remote's Source key still opens the input list — the older
# Android 12 EU build (examples/tcl-g08-eu-android12) loses that key without it, so do not carry this line to
# that list. On this build com.tcl.tv then logs a Tbrowser getService NullPointerException while Live TV runs;
# Live TV, the guide-less channel list and the input list were used for one evening without a visible loss,
# so uncomment the line if TCL's channel browser matters to you.
#
# The TV icon button (keycode 4001) is swallowed by TCL's own shortcut manager on this firmware; the
# README.md in this folder has the app_keys entry that brings it back.
