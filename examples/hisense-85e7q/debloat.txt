# - com.hisense.tv.tiletransition, signal-source switching. Tried and re-enabled: with it off the Inputs
#   panel still draws and the HDMI rows still highlight, but choosing one switches nothing. This is the
#   one package on this firmware that looks optional and is not.
# - com.hisense.tv.inputs, com.jamdeo.tv.livetv: the panel and the tuner app the panel starts.
# - com.keylab.speech.view.vidaa, com.hisense.widget.pro: the two other Home candidates (see above).
#   keylab is the JuUI "second screen" home with a hot-list chart row on top; it is also what a cold boot
#   falls back to when a launcher is not direct-boot aware, which is why it stays enabled.
# - com.hispeech.ai.area, com.keylab.speech.core.vidaa, com.iflytek.xiri, com.intelligent.speech,
#   com.hisense.msvoicetome, com.hisense.vidaaassistant: the voice chain, and the last one also handles
#   app installs and permissions. A replacement launcher that reads its own app list needs it.
# - com.sohu.inputmethod.sogou.tv: the only keyboard on this build. Without it no text field accepts
#   input, including a Wi-Fi password.
# - com.jamdeo.updateservice, com.hisense.usbupgrade, com.hisense.playerupdate: OTA, left on so firmware
#   updates still arrive. Comment them out only if you have decided against them.
