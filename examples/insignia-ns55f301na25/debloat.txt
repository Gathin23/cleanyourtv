# Insignia 55" Class F30 4K Fire TV (NS-55F301NA25, model AFTDCT31, codename duckie), Fire OS 7 / Android 9 (SDK 28),
# firmware PS7715.5585N. Also a good starting point for other Insignia / Toshiba / Pioneer Fire TV Edition sets on Fire OS 7.
#
# FIRE OS: DEBLOAT ONLY. Fire OS will not let a third-party launcher take over Home: com.amazon.tv.launcher and
# com.amazon.firehomestarter are protected packages (pm disable-user is refused), their HOME filter has priority 950,
# and `cmd package set-home-activity` prints Success but is ignored. launcher/build-and-install.sh does not apply
# here; this list removes Amazon's ads, telemetry and preloads around the stock home screen.
# Live TV app: com.amazon.tv.livetv.
#
# Apply (bash):       TV_HOST=<tv ip> tools/disable.sh examples/insignia-ns55f301na25/debloat.txt
# Undo  (bash):       TV_HOST=<tv ip> tools/restore.sh examples/insignia-ns55f301na25/debloat.txt com.amazon.tv.launcher
# Apply (PowerShell): powershell -ExecutionPolicy Bypass -File tools\disable.ps1 -TvHost <tv ip> examples\insignia-ns55f301na25\debloat.txt
# Undo  (PowerShell): powershell -ExecutionPolicy Bypass -File tools\restore.ps1 -TvHost <tv ip> examples\insignia-ns55f301na25\debloat.txt -Stock com.amazon.tv.launcher
# (restore.sh re-enables the stock launcher as a matter of routine; on Fire OS it was never disabled, which is harmless.)
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
#
# Keep enabled: com.amazon.tv.livetv, com.amazon.tv.quicksettings and com.amazon.tv.settings.v2 (HDMI/tuner inputs and
# the Picture/Sound/System settings), com.apple.airplay.amazon.airplay if you use AirPlay/HomeKit.
# Two packages in the telemetry group, com.amazon.device.metrics and com.amazon.ftvads.deeplinking, were reported as
# protected on a Toshiba Fire TV (Fire OS 7): if disable.sh prints an error for them, that is why; everything else applies.
# The Alexa, Prime Video, cast and OTA groups below are personal choices, marked as such: comment out what you use.
