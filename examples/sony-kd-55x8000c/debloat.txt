# Sony BRAVIA KD-55X8000C (2015, "BRAVIA 4K 2015", device SVP-DTV15, MediaTek), China firmware
# Android TV 7.0 (API 24), build SVP4KDTV15_CN-user 7.0 NRD91N.S35 5.435, 1.5 GB RAM, Ethernet
#
# Apply:   $env:TV_HOST="<tv ip>"; tools\disable.ps1  examples\sony-kd-55x8000c\debloat.txt   (Windows)
#          TV_HOST=<tv ip> tools/disable.sh  examples/sony-kd-55x8000c/debloat.txt            (macOS/Linux)
# Undo:    $env:TV_HOST="<tv ip>"; tools\restore.ps1 examples\sony-kd-55x8000c\debloat.txt   (Windows)
#          TV_HOST=<tv ip> tools/restore.sh  examples/sony-kd-55x8000c/debloat.txt            (macOS/Linux)
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.leanbacklauncher (the 2015 Sony launcher, NOT tvlauncher).
# It is NOT in this list: the launcher half needs Android 8 (minSdk 26), this set is API 24, so the
# stock home stays. Home also answers fallback com.android.tv.settings/.system.FallbackHome.
# Live TV / input app: com.sony.dtv.tvx. Keep it: it also plays every HDMI input.
# Keep: com.sony.dtv.tvinput.*, braviasync* (HDMI-CEC), remotepairing, uinputservice, imeproxy,
# leanback.ime, softwarekeyboard (ime.chww), settingsprovider, mtktvapi.agent, com.mediatek.*,
# chinaapkenabler (China setup/app plumbing), partnerkeycn + systemapp + scrums.action (remote keys),
# servicemode, webapi, dialservice, hddmgr, timers, usbmsgservice, audiooutput, configsettings,
# interactivetv* (screens on/off, time, discovery plugins), irbservice, rcplayer*.
# 屏幕镜像: the Inputs menu's fixed entry opens com.sony.dtv.networkapp.wifidirect
# (.ui.screens.ScreenMirroringHomeActivity); screnmirroring.com + com.mediatek.wfd are the WFD stack
# behind it, so with those two disabled the entry stays and does nothing.
# com.sony.dtv.b2b.hotelmode is kept too: Settings reads its hotelsettings provider (see the b2b group).
#
# This firmware has no Google Play Services: there is no Play Store, no katniss/pumpkin voice, no
# YouView, no Play Movies/Music. The Google packages in the EU 2015 Sony lists do not exist here.
#
# Only packages that ship with this firmware are listed; apps installed after purchase are not.
# Also kept: com.sony.dtv.appassistant (应用助手, preloaded).
#
# Reported on one China-market KD-55X8000C, one evening of use. If something breaks, re-enable it with
# `pm enable <package>` and please report it.
