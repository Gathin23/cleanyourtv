# TIM Box (Technicolor Jade, uzw4010tim)
# Android TV 8.0.0 Oreo (API 26), Technicolor / Telecom Italia (TIM)
#
# Hardware: Synaptics/Broadcom BG4CT SoC, 2 GB RAM, 8 GB Flash, integrated DVB-T/T2 Tuner.
#
# All packages are disabled safely using `pm disable-user --user 0 <pkg>`.
# Nothing is uninstalled from system partitions; everything is 100% reversible.
#
# TWO MODES FOR TIMVISION LAUNCHER & LIVE TV:
#
# MODE 1 - COMPLETE DEBLOAT (Pure Clean):
# Disable `timvision.launcher` below. CleanYourTV is the single native launcher
# with 0ms Home response. For live television, use streaming IPTV apps like OpenTV
# (already preloaded in dock slot 3).
#
# MODE 2 - HYBRID DTT SETUP (Keep Antenna TV):
# Keep `timvision.launcher` enabled (comment it out below). CleanYourTV handles
# the physical remote HOME button via HomeKeyService (instant 8ms overlay and
# task reordering so TIM launcher is never visible), and clicking "Digitale Terrestre"
# in the CleanYourTV dock opens the antenna TV player directly.
