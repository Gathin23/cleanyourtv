# TIM TIMVISION Box (Vantiva/Technicolor UZW4010TIM, codename uzw4010tim, board skipper_tim, Marvell Berlin BG4CT), Android TV 8.0, firmware OTT1.201231.001 (6.0.5.0412), Italy
# Operator streaming box with no HDMI inputs, on Wi-Fi. Tested on one unit in one session with two reboots,
# not yet over several days.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tim-timvision-box-uzw4010tim/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tim-timvision-box-uzw4010tim/debloat.txt timvision.launcher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: timvision.launcher (com.canal.box.ui.boot.BoxMainActivity) is the TIMVISION app itself.
# Its HOME filter has priority 2, so on Android 8 `cmd package set-home-activity` prints Success and Home
# still opens TIMVISION. The new launcher only takes Home with the stock one disabled:
#   STOCK_LAUNCHER=timvision.launcher TV_HOST=<tv ip> launcher/build-and-install.sh
# which disables it after the launcher has started and rolls back if Home does not follow. Only then is
# TIMVISION gone; a TIMVISION subscriber keeps the stock launcher and the TIMVISION service group below.
# No other app claims HOME (only com.android.tv.settings/.system.FallbackHome, priority -1000).
#
# Kept: remote and pairing (com.technicolor.android.remotecontrolservice, com.technicolor.tv.remotepairing,
# com.technicolor.globalkey, com.technicolor.tim.customization), the com.marvell.* HDMI-CEC/power/overscan
# services, Play Store and Play Services, Gboard, Chromecast (com.google.android.apps.mediashell) and every
# updater (com.technicolor.ota, com.technicolor.app.ota, com.technicolor.checkota, timvision.upgrade).
# The DVB-T tuner input (com.technicolor.android.dtvinput, dtvscan.project) was left enabled although unused.
# it.telecomitalia.digitalsupport stays enabled: tools/disable.sh skips it because it requests
# TV_INPUT_HARDWARE.
#
# After a reboot this box starts in standby (mWakefulness=Asleep, black screenshots); the remote's power
# button or `input keyevent WAKEUP` brings up Home. Nothing in this list was re-enabled by the firmware at boot.
# Private DNS does not exist on Android 8.0.
