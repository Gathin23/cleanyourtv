# Epson LS800 laser projector, Android TV module HA90 (built by Askey, board sti6202d101, Amlogic/droidlogic),
# Android TV 14 (API 34), firmware UKG3.250826.001 (u-2.05-U-0, 2026-06-15), UI at 1920x1080 on a 3840x2160 panel.
# Fingerprint: Epson/sti6202d101/sti6202d101:14/UKG3.250826.001/20260615:user/release-keys
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/epson-ls800/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/epson-ls800/debloat.txt com.google.android.tvlauncher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.tvlauncher (Android TV home with Search/Home/Live/Shop/Apps tabs, not
# Google TV's launcherx). HOME claimants on stock: tvlauncher and com.android.tv.settings/.system.FallbackHome.
#
# KEEP, the Android side drives the projector itself:
# - com.epson: projector control (auto focus, auto keystone, cinema/picture modes, Bluetooth speaker mode).
# - com.epson.droidsettings (projector menu), com.epson.flexiblepicture, com.epson.installation,
#   com.epson.visualization, com.epson.warningui (lamp/temperature warnings), com.epson.bizmodeui.
# - com.epson.logcollection: it collects operation logs, but it also owns the Information screen
#   (com.epson.intent.action.INFORMATION). Disabled, Projector Settings > Information crashes Projector
#   Settings with ActivityNotFoundException. Opt out of operation logs on that screen instead.
# - com.droidlogic.tv.extras: input-source screen (com.android.tv.action.VIEW_INPUTS) and sleep timer.
# - com.droidlogic.tvinput, com.droidlogic.android.tv, com.droidlogic.tv.settings: HDMI inputs and settings.
# - Firmware updates kept by choice: com.epson.fwupdate, com.droidlogic.updater, com.askey.autousbota.
#
# Notes from this unit (verified with screenshots, 21 October 2026):
# - Only Wireless debugging (TLS) is offered; pair once with `adb pair`, then `adb tcpip 5555`. Port 5555
#   came back by itself after a reboot.
# - The saved Wi-Fi network belongs to setupwraith (cname=com.google.android.tungsten.setupwraith), but
#   setupwraith does not claim HOME here, so it stays enabled and is not in this list.
# - Launcher: install and HOME takeover work (mFocusedApp = com.gathin.tvhome after Home and after a reboot).
#   Inputs lists HDMI 1-3 (droidlogic HW5-HW7, HDMI 1 also as a CEC device); HDMI opens in
#   com.droidlogic.android.tv, so keep that enabled and only hide its tile. No tuner, no Live TV row.
# - Remote ("EPSON PJ REMOTE", BT, Vendor_005d_Product_0001.kl): Home, Input (opens droidlogic's source
#   screen), Settings, projector menu and mic all keep working without the stock launcher.
#   The YouTube button is usage 0x0c008d -> KEYCODE_MACRO_3, and Epson's PhoneWindowManager.startCustomApp
#   hard-codes it to com.google.android.youtube.tvmusic (Play Store page if that is missing), which forwards
#   to YouTube. It runs in interceptKeyBeforeQueueing, so app_keys cannot remap it; keep YouTube Music enabled.
#   The Apps button (ALL_APPS) goes dead once tvlauncher is disabled: Android 14 consumes it before
#   accessibility services and sends it only to a system launcher, so HomeKeyService cannot catch it either.
# - Reboot-checked: everything listed stays disabled. Left out on purpose:
#   com.google.android.tvrecommendations. Disabled, it is back to enabled=1 within minutes, with
#   `dumpsys package` naming com.droidlogic (Amlogic's system package) as lastDisabledCaller. It only feeds
#   the stock launcher's rows, so with that launcher gone it is harmless; don't keep disabling it.
#
# Notes from a second unit (same HA90 module and firmware, sold as an Epson HA90, 25 October 2026):
# - com.google.android.katniss (Assistant) gets the same treatment as tvrecommendations: disabled, it is back
#   within minutes with lastDisabledCaller com.droidlogic. `pm uninstall --user 0` on either sticks (the factory
#   copy stays; `cmd package install-existing --user 0 <package>` brings it back), but that is outside what
#   this list does, so neither is listed.
# - Amlogic's TV extras app carries a hidden "Startup Setting" (Settings.System tv_start_up_enter_app, 0 =
#   launcher, 1 = TV app) and a "Power on behavior" slice; set over adb and reboot-checked, the key changes
#   nothing on this firmware: Home still comes up. To start on an HDMI port, use the launcher instead
#   (boot_to_live_tv opens com.droidlogic.android.tv, which returns to the last source).
# - On this unit USB debugging alone had port 5555 open, no wireless pairing needed; the TV does not answer
#   ping, so check the port. Android 14 names the foreground activity topResumedActivity in
#   `dumpsys activity activities`; HDMI on screen gives a 0-byte screencap.
# - Disabling com.epson.fwupdate, com.droidlogic.updater and com.askey.autousbota (updates off by choice) and
#   com.epson.onlinemeetings, com.epson.logcollection kept as above: Projector Settings > Picture, Sound,
#   Installation, Information and Bluetooth Speaker Mode all still open.
