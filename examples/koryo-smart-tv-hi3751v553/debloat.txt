# Koryo 55" 4K Smart TV (CVTE TP.HV553.PC821B, HiSilicon Hi3751V553 "bigfish"), Android 7.0, build NRD90M release-keys, firmware 20180808_165024
# 1 GB RAM (850 MB usable), 3840x2160 panel (BOE HV550QUB_N5A).
# Tested on one set, with stock launcher kept; notes in README.md in this folder.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/koryo-smart-tv-hi3751v553/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/koryo-smart-tv-hi3751v553/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.cvte.tv.launcher.fall (+ .skin). Keep it ENABLED: the remote's physical
# Home key and on-screen input source switcher route to it, and disabling it breaks remote navigation.
# Live TV / Inputs: com.cvte.tv.setting/.TvSettingActivity.
# Kept on purpose: com.cvte.tvservice, com.cvte.tv.setting (inputs and hardware tuning),
# com.cvte.settings, com.cvte.tv.ucservice and com.cvte.tv.appstore (without these, clicking any app
# tile in the stock launcher crashes with an unhandled exception), com.cvte.tv.media (USB file manager),
# com.cvte.directboot.application (FallbackHome), com.android.vending (official Google Play Store),
# com.google.android.gms, and factory packages com.cvte.fac.menu, com.cvte.gaochuang.factory.at (never launched).

# CVTE background services and ad telemetry

com.cvte.tv.pictorial             # screensaver with ad recommendation push
com.cvte.ui.help.unit2k17         # user guide / help manual app
# Firmware updater: off on the tested set (the firmware is end-of-life), kept on in this list so
