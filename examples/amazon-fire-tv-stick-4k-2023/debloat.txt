# Amazon Fire TV Stick 4K, 2nd gen 2023 (AFTKM, codename karat), Fire OS 8.1.8.5 (RS8185.3891N, build 0033018557316),
# Android 11 (SDK 30), Brazil. The first Fire OS 8 list here: it starts from amazon-fire-tv-stick-lite-2020/ and
# amazon-fire-tv-stick-4k-2018/, and every package new in Fire OS 8 was checked with `dumpsys package` before listing.
#
# FIRE OS: DEBLOAT ONLY. Home is com.amazon.tv.launcher/.ui.HomeActivity_vNext (priority 950); launcher/ does not apply.
#
# Apply:   TV_HOST=<stick ip> tools/disable.sh examples/amazon-fire-tv-stick-4k-2023/debloat.txt
# Undo:    TV_HOST=<stick ip> tools/restore.sh examples/amazon-fire-tv-stick-4k-2023/debloat.txt com.amazon.tv.launcher
# Everything is DISABLED for user 0, never uninstalled. Comment out any line you want to keep.
# ADB on Fire OS 8: Settings > My Fire TV > About > press select 7 times on the device name, back > Developer Options >
# ADB Debugging. Port 5555, accept the prompt on the TV (ro.adb.secure=1).
#
# Applied 2026-10-20 in four batches with a screenshot after each, then rebooted: all 57 stayed disabled, Home, Prime
# Video, Netflix, Globoplay and Disney+ open, Wi-Fi validates.
# Protected on this build (pm disable-user: "Cannot disable a protected package"), so commented out below, the same set
# as Fire OS 7 plus the help app: com.amazon.device.metrics, com.amazon.device.logmanager, com.amazon.device.crashmanager,
# com.amazon.diode, com.fireos.usagestats.proxy, com.amazon.ftvads.deeplinking, com.amazon.tv.csapp.
#
# Kept on purpose: com.amazon.tv.launcher, com.amazon.firehomestarter, com.amazon.tv.settings.*, com.amazon.venezia and
# com.amazon.tigris (Appstore), com.amazon.tv.ime, remote/Bluetooth services, OTA updates (device.software.ota*,
# tv.forcedotaupdater.v2), Alexa voice search, Prime Video (com.amazon.firebat, com.amazon.tv.support), casting and
# mirroring (cast.sink, dialservice, awvflingreceiver, whisperplay, whisperlink, com.amazon.tv.matter for Matter
# casting), Amazon sign-in for apps (com.amazon.tv.ottssocompanionapp, com.amazon.imp), profiles, com.amazon.tv.oobe
# (needed for a factory reset), the screensaver, accessibility (com.amazon.logan), notification center.
# com.amazon.imp confirmed load-bearing on a second AFTKRT unit (same karat board, Fire OS 8.1.8.5): disabling it
# together with shoptv.client, shoptv.firetv.client, media.recommendations, sneakpeek, systemnotices, tv.earlyaccess
# and tv.acr left HomeActivity_vNext resumed and the remote fully responsive, but painted nothing -- confirmed black
# on the physical TV. Re-enabling just those eight (imp included) fixed it within seconds, no reboot needed; the
# other seven were not re-tested standalone, so this list's existing success with them already disabled stands.
# Fire OS 8 packages looked at and left alone: com.amazon.adep (package verification / security events),
# com.amazon.platform.fdra (package allowlisting), com.amazon.tv.turnstile (PIN sign-in), com.amazon.tv.consents,
# com.amazon.ssm / ssmsys (captive portal, error codes), com.amazon.tiramisubootsupport, com.amazon.d3 (has a demo
# content provider but also OOBE and provisioning receivers).
#
# What the list cannot remove: the hero banner, the "Patrocinados" (Sponsored) row and the Luna tile in "Your apps"
# come from the launcher's own feed. Point the stick's DNS at a blocker for those (Pi-hole, or Private DNS
# dns.adguard-dns.com on Android 11). Also turn off Settings > Preferences > Privacy Settings (Device Usage Data,
# Collect App Usage Data, Interest-based Ads) and Featured Content autoplay in the menus: those values sync with the
# Amazon account, so the menu is the place to change them, not `settings put`.
# Prime Video registers only LEANBACK_LAUNCHER, so `monkey -p com.amazon.firebat 1` does nothing; start
# com.amazon.firebat/com.amazon.pyrocore.IgnitionActivity with `am start -n` to test it.
# Leave the animation scales at 1.0 on this build. At 0.5 (window, transition and animator) every entry in the
# side menu (☰: Settings, Appstore, My Stuff...) closes the menu and goes back to Home without opening anything:
# NavigationActivity logs "onStop with slideoutState=false, finishing to prevent stuck menu" before the navigation
# request is sent. Back at 1.0, Settings opens again with all 57 packages still disabled.
