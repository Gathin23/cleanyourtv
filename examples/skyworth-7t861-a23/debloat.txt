# CRITICAL SAFETY NOTE:
# Do NOT disable com.skyworth.officehomepage or com.tianci.movieplatform directly.
# Coocaa OS boot chain hardcodes dependencies on these stock home launchers. Disabling
# either package causes the system to hang indefinitely at the boot logo (network stack
# does not initialize, ADB drops). Recovery requires a hardware factory reset.
# Also keep com.loostone.tuning (audio HAL) and com.tianci.user (auth IPC) enabled.
#
# RECOMMENDED BEST PRACTICE:
# On this model, switching the television to "Office Mode" (办公模式) in the native settings
# shuts off all video streaming feeds, banner advertisements, and background cloud preloading.
