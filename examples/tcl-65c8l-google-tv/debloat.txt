# TCL 65C8L Google TV, 2025, Australia (device G17, model "Smart TV Pro", MediaTek tcl9655)
# Android 14 (Google TV), firmware UTT2.250416.001 AU08, product G17_4K_GB.
# Newer board than the C7L (G08): this list started from examples/tcl-65c7l-google-tv/debloat.txt and was
# checked package by package against this unit with dumpsys. Everything is DISABLED, not uninstalled.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-65c8l-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-65c8l-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Comment out any line you want to keep.
#
# ADB: this set offers only Wireless debugging (no plain 5555). Pair with a code, adb connect, then
# `adb tcpip 5555` so tools/tv.py can reach it; a reboot closes 5555 and needs pairing again.
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / tuner / HDMI app: com.tcl.tv.
# Left alone as load-bearing or unclear: com.tcl.tv / com.tcl.tvinput (Live TV + tuner/HDMI),
# com.tcl.suspension (Input source panel), com.tcl.initsetup (holds the tuner channel-install service),
# com.tcl.globalkeyoverlay (remote keys), com.tcl.systemserver, com.tcl.webview (a WebView provider),
# com.tcl.hearaid (audio), com.tcl.t_solo, com.tcl.useragreement, com.tcl.factory.view (factory - never touch).
# Kept by this owner: Google Assistant (katniss), Chromecast (mediashell), AirPlay (tcl.airplay2 +
# com.mediatek.AirplayAPK + com.mediatek.airplaydaemon), Miracast (tcl.miracast), the game bar, the USB
# media player (ui_mediaCenter), Play Games, YouTube Music, and every installed streaming app.
#
# Tested 2026-10-24 on a real unit in one session, applied in batches with screenshots between them: Home,
# the Input source panel, Live TV, the HDMI inputs, YouTube with AdGuard Private DNS and the remapped remote
# buttons all kept working. All 27 packages stayed disabled after a reboot; nothing re-enables at boot.
#
# Known quirks on this firmware:
# - The saved Wi-Fi network belonged to setupwraith (dumpsys wifi: cname=...setupwraith). This TV is Wi-Fi
#   only, so forget the network and join it again in Settings (owner moves to com.android.tv.settings)
#   BEFORE setupwraith is disabled, or the TV drops off Wi-Fi and ADB. setupwraith's HOME components could
#   not be disabled on their own (shell SecurityException), so the whole package goes.
# - With launcherx gone, the Settings, TV-guide and app-shortcut buttons go dead. They are remapped in this
#   folder's config.json app_keys by Android keycode (all share scancode 240): Settings 83, TV guide 4001,
#   Netflix 4062, Prime Video 4099, YouTube 190 (the TCL button is 4020, left unmapped). This needs
#   INPUT_KEY_SERVICE=1, and on this board the key-filter service stops continuous volume-repeat (hold-to-ramp
#   becomes one step per press) - a trade, not a fault. Leave the helper off to keep volume repeat.
