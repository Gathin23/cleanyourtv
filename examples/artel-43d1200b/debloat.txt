# Stock Home: com.yandex.tv.home/.HomeActivity. Same m5621 platform as docs/devices/hi-vhix-43f169msy.md.

# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/artel-43d1200b/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/artel-43d1200b/debloat.txt com.yandex.tv.home
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Kept on purpose:
#   com.yandex.tv.services*, com.yandex.io.sdk: the Yandex account (Kinopoisk sign-in) and the system glue.
#   com.yandex.tv.setupwizard, com.yandex.tv.vendor.config, com.yandex.tv.settings, com.yandex.tv.live,
#   ru.yandex.androidkeyboard.tv (the only on-screen keyboard), com.mediatek.tvinput (HDMI, tuner, AV)
#   and the rest of the MediaTek/CVTE TV stack.
#   com.yandex.launcher.updaterapp: installs and updates YouTube and Kinopoisk, there is no Play Store.
#   com.cultraview.osupdate, com.example.upgrad: firmware updates.
#   com.android.se: still starts at boot when disabled, so disabling it gains nothing.
#   Factory and test packages (com.ctv.newfactorytest, mediatek.factorymenu.ui, com.cultraview.factory.debug,
#   com.ctv.autotest.helper): never touched, never started.
#
# Tested on one set for a week with YouTube (com.yandex.tv.ytplayer) and Kinopoisk: every line below,
# active or commented out, was disabled on it. Nothing came back when the Yandex system apps updated
# (3.245 to 3.367), and tools/check.py found nothing re-enabled a week later.
