# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-bravia-bf1/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/sony-bravia-bf1/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep. A factory reset
# re-enables every package, so nothing needs undoing before one.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh, as above).
# Keep: Play Store and Play Services, Sony's update centre, the TV inputs and tuners
# (com.mediatek.dtv.tvinput.*, com.sony.dtv.tvinput.dvbtuner), com.sony.dtv.sonysystemservice,
# com.sony.dtv.smartui (the Input menu), Sony and Android settings, Dolby audio, AirPlay, Chromecast, Gboard.
#
# Quirks on this firmware:
# - A plain `reboot` can lose a disable: pm disable-user is saved a few seconds later. Wait ~30 s,
#   then restart with `svc power reboot`. Check Home, Netflix, YouTube, Input and AirPlay after each group.
# - com.sony.dtv.applicationdisabler re-enables some packages at every boot (the IoT ones below,
#   airplayapp, m2.devicecontrolservice). Leave them; disabling the disabler is not worth it.
# - Remote: Home sends KEYCODE_HOME. Input sends KEYCODE_TV_INPUT, which smartui opens system-wide,
#   so INPUT_KEY_SERVICE isn't needed. OK never repeats while held, so long presses don't work.
# - `dumpsys meminfo` without `-t 90` times out on this set. The IP changed after most restarts:
#   reserve one in the router.
#
# Applied group by group on 2026-10-19 (voice search kept). Stock vs after, ~15 min after boot:
# Home p90 frame time 31 -> 15 ms, janky frames 2.41% -> 0.07%, Home memory ~96 MB (with its helper)
# -> ~46 MB, MemAvailable 1.09 -> 1.14 GB.
