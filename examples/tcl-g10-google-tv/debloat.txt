# TCL 55" 4K Google TV, 2023 model year, US (device G10, product G10_4K_US_NF, Realtek RTD2875P)
# Android 12 (Google TV, basic mode), firmware STT2.230203.001, software V8-R75PT01-LF1V499
# Likely a good starting point for other 2023+ TCL Google TV sets on the Realtek G10 platform.
#
# Also confirmed on a TCL 55P6K (Spain retail name for the same G10 platform), product
# G10_4K_GB_NF_32BIT, identical firmware build STT2.230203.001 — this list applies unchanged.
#
# Also tested on a TCL 43P69K, Netherlands (G10_4K_GB_NF_32BIT, Android 12 / SDK 31,
# build STT2.230203.001, ro.adb.secure=1). Unlike the original US unit, logkit, Samba TV ACR
# and ttvs shipped enabled; all three were disabled and stayed off after a reboot (2026-10-22).
# Its TCL Channel package is com.tcl.waterfall.overseas. That unit also disabled TGuard and
# MagiConnect, but kept TalkBack and re-enabled dreamx to keep the screensaver menu in Settings.
# Comment out TalkBack and dreamx below to match that choice; the unit-specific additions are optional.
# Tweakers groups the Netherlands range as "TCL P6K/P69K/P61K":
# https://tweakers.net/televisies/tcl/p6k-p69k-p61k_p1739438/vergelijken/
# Only the 43P69K unit above was tested here; check the product and build before using this list.
#
# Also used on a TCL C69B (EU, product G10_4K_GB, software V8-R75PT01-LF1V548, same build
# STT2.230203.001; tv.plus and smartlink.core are not installed there). That set kept
# partnercustomizer, gamebar and tv.remote.service by choice, so those three are untested on it;
# everything else on the list was disabled and lived with. Its BT_RC833 remote sends
# YouTube 4065, Netflix 4062, Prime Video 4099 and Web 4159, which only app_keys brings back once
# launcherx is off, and the gear as keycode 83 on scancode 233 (settings_key_keycodes).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-g10-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-g10-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh, the default is wrong here).
# Live TV app: com.tcl.tv (keep it, it also owns HDMI/antenna playback). Keep com.tcl.tvinput,
# com.tcl.dashboard, com.tcl.suspension, com.tcl.autopair and com.tcl.systemserver too.
# Already disabled at the factory on the original US unit: com.tcl.logkit, tv.samba.ssm.ui
# (Samba TV ACR), com.tcl.ttvs. These shipped enabled on the Netherlands 43P69K (see optional lines).
#
# Known quirks on this firmware:
# - The red "TV" tile disappears from the Google TV Home row after this list (probably
#   com.tcl.partnercustomizer). TV stays in the Apps row and behind the Inputs tile.
# - Disabling dreamx leaves screensaver_components pointing at it. Switch to the AOSP fallback with
#   tools/tv.py 'settings put secure screensaver_components com.android.dreams.basic/.Colors'
#   On the 43P69K it also removes the screensaver menu from Settings. dreamx was re-enabled there;
#   leave its line commented out if you need that menu, even when using a third-party screensaver or the add-on photo-screensaver.
# - screencap writes an empty file while Live TV/HDMI is on screen. Press Home first.
# - The Google TV promo banner is drawn by launcherx itself, so only launcher/ removes it.
# - Disabling the stock launcher alone is not enough to install a replacement:
#   com.google.android.tungsten.setupwraith (the setup wizard) also claims Home at a lower
#   priority and takes over once launcherx is disabled. Disable it too before setting the new
#   launcher as Home — launcher/build-and-install.sh does this automatically and rolls back if
#   Home doesn't land on the new launcher. List it in your own debloat file so restore.sh brings
#   it back. Confirmed on two separate 55P6K units.
# - On the 43P69K, the saved setup Wi-Fi belonged to setupwraith (dumpsys wifi: cname=...setupwraith).
#   Forget and re-join it in Settings BEFORE disabling setupwraith, so the network belongs to Settings;
#   otherwise disabling its owner drops Wi-Fi and the ADB connection.
# - TclAppBoot blocks the launcher's key services (and WireGuard's VPN) at every boot until the
#   package has APP_AUTO_START (docs/TROUBLESHOOTING.md). Run `appops write-settings` after
#   `appops set com.gathin.tvhome APP_AUTO_START allow`: app-ops are saved lazily, and a plain
#   `reboot` drops the change. Confirmed on the C69B over three reboots.
# - The remote's mic button needs com.google.android.tv.remote.service, which is commented out below: a
#   press starts AtvSearchAssistantService inside that package, so with the package disabled the button
#   does nothing (no key on any /dev/input/event*) and logcat says the service is "not found".
#   `pm enable com.google.android.tv.remote.service` brings voice back without a reboot. Confirmed on a
#   43T6C (G10, Realtek, build STT2.230203.001); the phone-remote app pairing needs it too. (#1441)
