# TCL 65EP640, Finland (ro.product.model BeyondTV, board RTD2851 / platform rtd285o), Android TV 9 (API 28),
# build PPR1.180610.011 AP06, fingerprint TCL/BeyondTV/BeyondTV:9/PPR1.180610.011/AP06, 32-bit (armeabi-v7a).
# Same board as examples/tcl-55ep640 (AR04, Android TV 11), on older firmware with a different package set:
# no overseasappshow, tclhome_master/passive, waterfall, guard or dashboard here; instead TCL's own content
# service (cyberui), the "TV Guard" cleaner (tvweishi) and the TCL app store (appmarket2).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-65ep640/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-65ep640/debloat.txt
# Install the launcher BEFORE disabling the stock launcher (launcher/build-and-install.sh).
# Stock launcher: com.google.android.tvlauncher. Other HOME claimants are only fallbacks:
# com.tcl.keycustomfunctionservice/.FallbackHome and com.android.tv.settings FallbackHome.
# setupwraith does not claim Home on this build, and the saved Wi-Fi network belongs to the Play services
# shared UID (com.google.uid.shared), not to setupwraith; it is left enabled anyway.
# Live TV app: com.tcl.tv. Tuner and HDMI: com.tcl.tvinput (never disable either).
# Port 5555 only opened after USB debugging was switched off and on again in Developer options.
#
# Already disabled when we started, left alone: com.tcl.bootadservice (boot ad), com.tcl.usercenter,
# com.tcl.common.terminalmanagerplus, the 14 uk.co.freeview.* apps, au.com.stan.and, com.eros.now,
# com.graymatrix.did, com.linecorp.linetv, com.tcl.gallery, com.tcl.notereminder, com.tcl.smartalexa,
# tv.wuaki.apptv.
#
# Tested 2026-10-24 on a real unit: applied in five batches with a screenshot after each (28/28 disabled,
# the stock launcher via launcher/build-and-install.sh), then rebooted once: nothing came back enabled and
# Home came up as the new launcher. The launcher's Inputs menu lists HDMI 1-3 and AV; Live TV works from the
# remote's TV and Input buttons. On the real remote Home, Back, Input, Settings, the app buttons and a held
# Volume Up (it keeps repeating, no key helper enabled) all work. Streaming plays with Private DNS on.
# Not yet lived with for days.
#
