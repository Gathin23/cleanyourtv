# Stock launcher: com.google.android.apps.tv.launcherx (left enabled; see below). Live TV / input app: com.mediatek.wwtv.tvcenter.

# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/formovie-xming-page-one-tianshan/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/formovie-xming-page-one-tianshan/debloat.txt

#
# A light list, used daily for six days: all 14 packages were still disabled after a reboot, and HDMI, the Bluetooth
# remote, focus and keystone worked after every batch (disabled in three batches); the owner reports nothing broke.
# The saved Wi-Fi network belongs to com.google.android.tungsten.setupwraith (dumpsys wifi | grep -o 'cname=[^ ]*'),
# so setupwraith and the stock launcher stay enabled: disabling setupwraith deletes that network.
# setupwraith/.RecoveryActivity (HOME priority 1) outranks a third-party launcher, so the launcher cannot become Home by
# disabling launcherx alone; that needs setupwraith off too, which also costs the saved Wi-Fi (and risks Chromecast).
# Instead the reference launcher (com.gathin.tvhome) was installed with launcherx left enabled, HOME_KEY_SERVICE=1 and
# "stock_home_redirect": "com.google.android.apps.tv.launcherx" (config.json in this folder). Home, the app buttons,
# Input and the launcher's Inputs pill (HDMI) work. Trade-off measured on this set: with the helper on, holding Volume Up
# gives one step per press instead of a ramp. Sideloading the launcher works (no verification failure).
# Kept on purpose: com.fengmi.* (projector imaging = focus and keystone, Autopair = BLE remote, fmsettings, platform),
# com.mediatek.* (tv service, tvinput, tvcenter), com.dolby.android.audio.service, fusion.android.tv.demo (RetailDisplay),
# com.mstar.android.tv.disclaimercustomization, Play Store and Services, Gboard, the Google Assistant (katniss, tv.assistant),
# Chromecast (mediashell), TalkBack and every streaming app (Netflix, YouTube, Prime Video, Disney+, HBO Max, Canal+,
# TVN Player, TVP VOD) because the owner uses them.
# Never launch com.fengmi.testsuite or mediatek.factorymenu.ui (factory tools). No firmware updater package of its own was seen.
