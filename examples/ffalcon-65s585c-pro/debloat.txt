# Android 11 (SDK 30), build RQ3A.210705.001 / 2026012200 (2026-01-22), 3.7 GB RAM, armeabi-v7a only.
# Same platform and the same firmware build as examples/tcl-q10g-pro/; read that list's notes first
# (ADB via 本机信息 + UP DOWN LEFT RIGHT). A third-party launcher DOES install on this firmware,
# through a short packageinstaller window, and can be made the cold-boot Home:
# see docs/devices/tcl-mt5879-cn-launcher.md.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/ffalcon-65s585c-pro/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/ffalcon-65s585c-pro/debloat.txt com.tcl.cyberui
#
# Stock launcher: com.tcl.cyberui, the only HOME handler. Never disable it.
# Nothing was disabled at the factory (`pm list packages -d` was empty).
# com.tcl.bi from the tcl-q10g-pro list is not present on this unit.
#
# DO NOT DISABLE: com.tcl.cyberui, com.tcl.tv, com.tcl.settings, com.tcl.systemserver, com.tcl.ttvs,
#   com.tcl.TFDS.service (persistent factory service), com.sohu.inputmethod.sogou.tv (only keyboard),
#   com.tcl.appmarket2, com.tcl.guard, com.tcl.ui_mediaCenter, com.tcl.autopair (remote pairing),
#   com.tcl.tcl_bt_rcu_service, com.tcl.providers.config, com.tcl.initsetup, com.tvos.
#
# Every group below is active. To keep a group, comment it out before running disable.sh. The recovery
# record keeps the state from before the first run and adds names that join the list later.
#
# Tested 2026-10-20 on a real unit, then two full `reboot`s: Home, HDMI inputs and no crash-buffer
# entries, and all packages below stayed disabled.
# Wait at least 10 seconds after disable.sh before rebooting: PackageManager writes the new states to
# disk after a short delay, and a reboot inside that window brings the packages back enabled.
