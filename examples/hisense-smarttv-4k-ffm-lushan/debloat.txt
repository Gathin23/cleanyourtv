# Google TV setup wizard. Its RecoveryActivity claims HOME and beats the new launcher once
# com.google.android.apps.tv.launcherx is disabled; `pm disable` of that one component is refused, so
# the whole package has to go for a launcher swap. It also owns saved Wi-Fi networks, so check first:
# `dumpsys wifi | grep -o 'cname=[^ ]*'`. If the network the TV is actually connected to belongs to
# setupwraith, forget and re-join it in Settings before running this, or the disable deletes that
# network and takes the TV off Wi-Fi and ADB. Needs FORCE_SETUPWRAITH=1 to pass disable.sh's Wi-Fi guard.
# On the second unit the connected network was owned by android.uid.system and only an older saved network
# by setupwraith; that one was deleted, the TV stayed on Wi-Fi and ADB.
