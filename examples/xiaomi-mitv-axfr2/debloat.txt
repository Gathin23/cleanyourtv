# firmware UKG3.250107.001.

# Live TV app: com.mitv.livetv (also inputs via mitv.service).
# Stock launcher: com.google.android.apps.tv.launcherx.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-axfr2/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-axfr2/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Notes from this firmware:
# - Sideloading works (pm install over the shell), and third-party HOME app is accepted.
# - setupwraith does not own the saved Wi-Fi network (cname is system uid 1000).
# - Disabling com.google.android.apps.tv.launcherx and setupwraith hands HOME to com.gathin.tvhome. Disabling
#   setupwraith gives Home back but can cost casting.
# - PatchWall (com.mitv.tvhome.atv) and related OEM tabs are safe to disable.
# - The remote's YouTube button sends 190 (KEYCODE_BUTTON_3) which routes to launcherx;
#   can be mapped in the launcher's config.xml as 190:com.google.android.youtube.tv.
# - PatchWall button sends 192 (KEYCODE_BUTTON_5).
