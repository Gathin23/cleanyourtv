# Hisense 43QD65QFC (AFTOLCBC82, ginza), Fire OS 8.1.8.0 / Android 11, firmware RS8180.3746N, US market
# Reported and tested on the owner's set by @rabbit718 in issue #3523.
# 43-inch sibling of hisense-fire-tv-55qd6qf: same RS8180/3746N board family. Every name verified
# installed on THIS set with pm list packages before disabling; applied with tools/disable.sh and
# checked with tools/check.py (0 drift) after a reboot.
# Differences from the sister set: vizzini did NOT re-enable at boot here (it stayed DISABLED_USER
# across the reboot, unlike the 55QD6QF note); on US sets com.tubitv.ott is a user-installed app,
# not a retailer preload, so it is not on this list at all.
# Stock Home com.amazon.tv.launcher (its own pm route: Fire OS never hands Home to a third-party
# launcher here, so no launcher install) and Live TV com.amazon.vodcsp.livefiretv are kept.
# AirPlay, Casting, Live TV/inputs, Silk and the firmware updater are kept. Wi-Fi is owned by
# com.amazon.tv.oobe: never disable it.
# ADB quirk on this firmware (ro.adb.secure=1): the "Allow USB debugging?" popup only renders when
# a fresh client challenges right after adbd restarts - if a connection sits at unauthorized, start
# the client and toggle ADB debugging off and on; adbd serves one client, so kill other adb clients
# first. "Always allow from this computer" persists across reboots, and the ADB debugging switch
# itself stayed on across the reboot.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/hisense-fire-tv-43qd65qfc/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/hisense-fire-tv-43qd65qfc/debloat.txt
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
