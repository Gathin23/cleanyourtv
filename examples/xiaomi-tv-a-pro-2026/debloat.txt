# Default IME is Gboard, no keyboard quirk. 1.8 GB RAM.
#
# Google TV 14 quirk (the important one): HOME is resolved by intent priority here and the saved
# "default home" is ignored. launcherx has priority 2, the setup wizard's RecoveryActivity priority 1,
# a sideloaded launcher 0. Disable launcherx alone and Home lands on RecoveryActivity, which
# crash-loops system_server (soft reboots every ~60 s, Wi-Fi drops). Shell may not disable that one
# activity, so the whole setup wizard package is disabled below; it is only used for first-time setup.
# Re-enable it (and launcherx) before a factory reset or to get the Google home back: restore.sh does.
# The firmware re-enables com.netflix.ninja by itself (Netflix button), so don't bother disabling it.
