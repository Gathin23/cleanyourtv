# Hisense 65E5H (reports ro.product.model "VIDAA_TV", device MTK9652, board hisense_m7642_cn), China
# JuUI 9 on Android 9 (API 28), build PPR2.180905.006.A1 `release-keys`, incremental 02.02.60.01.
# Panel reported as 1920x1080 / density 320, ABIs armeabi-v7a only, 126 packages installed and
# nothing disabled at the factory. Stock Home is com.jamdeo.tv.vod (com.ju.main.launcher.LauncherActivity)
# and Live TV is com.jamdeo.tv.livetv; both are left enabled, so this is a debloat-only list.
#
# ro.adb.secure=1 on this firmware: the TV asks "Allow USB debugging?" for the computer once and keeps
# the key. service.adb.tcp.port=5555, so USB debugging alone opens the port over Wi-Fi, no cable and
# no separate network-debugging toggle. Reaching USB debugging needs the factory menu on this set
# (ToFac U->M, then the Menu key on the version page opens native Settings); README.md in this folder
# has the steps, including the prompt problems and the ToFac switch back to U. Switch USB debugging
# off when done: on this firmware it also leaves ADB open on port 5555 over Wi-Fi.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/hisense-65e5h/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/hisense-65e5h/debloat.txt
# Everything is DISABLED (pm disable-user --user 0), nothing is uninstalled.
#
# Applied on 2026-10-29 in six batches, one cold reboot after each, and verified after every reboot:
# 29/29 stay disabled, Home starts, Wi-Fi reconnects, the source panel / input animation and
# Bluetooth pairing services keep running. Same-day, not several days of use - the owner asked for it
# in one session, so treat "lived with for a few days" as not done for this list.
#
# Timing pitfall found on this set: reboot sooner than ~60 s after `pm disable-user` and the state can
# be lost. The first batch (5 packages) came back enabled after a reboot ~30 s later and stick once
# the reboot waits a minute. Wait, then reboot, then check `pm list packages -d`.
#
# Not a package, but needed to actually stop the screensaver: settings put secure screensaver_enabled 0
#
