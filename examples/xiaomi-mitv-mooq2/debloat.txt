# Xiaomi Mi TV P1 43" (MiTV-MOOQ2, codename croods, MediaTek), Android TV 11, firmware RTM4.220307.164.8238
# Latin America retail unit (L43M6), 1.7 GB RAM, Android low-RAM mode on. Same croods chassis as MiTV-MOOQ0.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-mooq2/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-mooq2/debloat.txt
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
# Provisional: applied in one session and reboot-checked; every package stayed disabled after reboot.
#
# Stock launcher: com.google.android.tvlauncher. It is NOT in this list: launcher/build-and-install.sh
# disables it after com.gathin.tvhome is installed and verified as Home (default STOCK_LAUNCHER detection works).
# Only com.android.tv.settings and the stock launcher claim HOME on this firmware; setupwraith does not, so
# it stays enabled and the saved Wi-Fi network is untouched.
#
# Kept deliberately, checked with `dumpsys package`:
#   com.mitv.overseaservice                        hosts netflixService (the Netflix key), as on MOSR4
#   com.xiaomi.android.tvsetup.partnercustomizer   holds BleRcActivity, the Bluetooth remote pairing
#   com.xiaomi.tvqs.overseas                       TV quick-settings receivers
#   com.mediatek.tvinput, com.mediatek.wwtv.tvcenter, mitv.service, com.mediatek.tv.service   HDMI 1-3, AV, tuner
#   com.xiaomi.mitv.updateservice                  firmware updates, kept by owner's choice
#
# Before disabling com.mitv.dream and com.google.android.backdrop, point the screensaver elsewhere:
#   settings put secure screensaver_components com.gathin.tvhome/.ClockDream
#
# Tested after the debloat: launcher Inputs menu lists HDMI 1-3, AV and Live TV; Netflix, YouTube, Prime Video
# and Max launch; Chromecast, Mi Cast/Miracast and the Bluetooth remote still work.
