# Stock launcher: com.google.android.tvlauncher (the only HOME claimant besides Settings' FallbackHome;
# setupwraith does not claim HOME on this firmware). Nothing was disabled from the factory.

# Launcher notes (applied and verified on a real unit on 2026-10-19, including a reboot):
# - The Inputs menu needs `"input_action": "com.xgimi.action.hdmiPlayer"` in the theme (or input_action
#   in config.xml): XGIMI's HDMI player (com.xgimi.xhplayer/.InputActivity) does not answer the standard
#   ACTION_VIEW on the passthrough channel URI, so HDMI1 otherwise does nothing.
# - No tuner: set `"live_tv_package": ""`. Only HDMI1 is registered, although tvinput has 3 services.
# - Projector settings (keystone, focus, picture) stay reachable: Settings pill -> Projector Settings.
# - Tailscale does not come back after a reboot by itself. Making it the always-on VPN fixes that:
#   settings put secure always_on_vpn_app com.tailscale.ipn; settings put secure always_on_vpn_lockdown 0
#   (takes effect at the next boot). With `"vpn_app": "com.tailscale.ipn"` the network pill shows a red
#   "VPN off" badge while it is down and opens Tailscale when pressed.
# - The default Backdrop screensaver is disabled below; point the screensaver at
#   com.android.dreams.basic/.Colors (or another dream) or it has nothing to show.
#
