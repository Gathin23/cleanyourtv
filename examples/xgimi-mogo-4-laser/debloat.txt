# Tested for one session (a few hours) on 2026-10-25, then a reboot by the owner, not the several days
# CONTRIBUTING asks for. Every entry was applied in four batches with a screenshot after each, on the real
# unit; what is not proven is that nothing surfaces after days of use. See README.md in this folder.
#
# The laser version of the MoGo 4: same altai board as examples/xgimi-mogo-4 (WK08K, LED), a newer
# build, and the same packages. Nothing laser-specific showed up in the package list: the only XGIMI
# packages the MoGo 4 list does not name are resource overlays (com.android.xgimi.overlay.*,
# com.android.tv.settings.xgimi.tv.resoverlay), and the light source, eye protection and autofocus
# run in the XGIMI services kept below. Eye protection (the image dims when a hand is held in front of the lens)
# was checked by hand after the reboot and still works. Nothing shipped disabled from the factory.
# The unit arrived on Android 11 (RTMA.250416.085) and took the Google TV 14 update before this list.
#
# Stock launcher: com.google.android.apps.tv.launcherx, with setupwraith's RecoveryActivity behind it.
# setupwraith owned the Wi-Fi network in use (`dumpsys wifi`: cname=com.google.android.tungsten.setupwraith
# on the entry with "Currently Connected: true"). The network was forgotten and joined again on the
# projector first; the entry then showed cname=android.uid.system:1000 and setupwraith went without
# losing Wi-Fi or ADB.
#
# Launcher notes (applied and verified on a real unit on 2026-10-25):
# - Install with HOME_KEY_SERVICE=1 and push config.json from this folder with tools/theme.sh. Its
#   "key_filter": false is the difference from the MoGo 4: see README.md.
# - launcherx re-enables itself (com.xgimi.xrmservice, as on the MoGo 4 and MoGo 3 Pro). It was back
#   within a minute of build-and-install.sh disabling it, and the script stops with "Home resolves to
#   ... setupwraith/.RecoveryActivity" / "launcherx owns Home again"; set-home-activity prints Success and
#   changes nothing. stock_home_redirect is what holds Home. The script stopped before it enabled
#   HomeKeyService, so the helper was switched on by hand (README.md).
# - HDMI 1 (the only port) opens from the Inputs menu with no input_action, as on the MoGo 4.
# - Network ADB: Developer options offers Wireless debugging; with it on, port 5555 answers tools/tv.py.
#
