# Coocaa P9 projector (MediaTek mt5862_bga_1g), Android 9 (SDK 28),
# build PPR2.180905.006.A1 dev-keys, China-market Coocaa OS.
# Verified across cold reboots: 16 packages disabled with pm disable-user --user 0.
# Autofocus, electric focus, keystone correction, remote Bluetooth, Wi-Fi and ADB reconnect remain fully functional.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/coocaa-p9-projector/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/coocaa-p9-projector/debloat.txt
# Everything is DISABLED (pm disable-user --user 0), not uninstalled.
#
# ADB entry:
# Go to Settings -> 通用 (General) -> focus on 关于本机 (About this TV).
# Press LEFT on the remote 7 times (LEFT LEFT LEFT LEFT LEFT LEFT LEFT).
# Return to General menu: 开发者选项 (Developer options) appears below About this TV.
# Enter Developer options and turn on "USB 调试" (USB debugging).
#
# Boot video ad skip (no root, survives reboot):
# tools/tv.py 'setprop persist.sys.bootvideo.time 1'
# Stock value before modification was unset / empty (defaults to 15s video at /vendor/stream/bootvideo.mp4).
#
# ⚠ DO NOT DISABLE:
# - com.tianci.movieplatform: Coocaa stock launcher base, boot hard-depends on it.
# - com.coocaa.home.plug.projection: Projector optical engine, autofocus & keystone correction.
# - com.coocaa.os.softsettings / com.skyworth.setting: System settings.
# - com.tianci.system / com.coocaa.os.ccosservice: Core system framework.
# - com.tianci.de: Daemon service (disabling crashes About page).
# - com.skyworth.tianciime: System IME.
# - com.tianci.localmedia: Local USB media player.
#
# Launcher handover:
# 1. Build launcher with applicationId com.coocaa.tvhome:
#    (cd launcher && ./gradlew assembleRelease -PlauncherApplicationId=com.coocaa.tvhome)
# 2. Install and set home properties:
#    tools/tv.py 'setprop persist.service.homepage.pkg com.coocaa.tvhome'
#    tools/tv.py 'setprop persist.service.homepage.cls com.gathin.tvhome.MainActivity'
#    tools/tv.py 'cmd package set-home-activity com.coocaa.tvhome/com.gathin.tvhome.MainActivity'
# 3. Undo launcher handover:
#    tools/tv.py 'setprop persist.service.homepage.pkg com.tianci.movieplatform; setprop persist.service.homepage.cls com.coocaa.homepage.vast.projector.ProjectorHomeActivity; cmd package set-home-activity com.tianci.movieplatform/com.coocaa.homepage.vast.projector.ProjectorHomeActivity'
# Note: Stock values were pkg=com.tianci.movieplatform, cls=com.coocaa.homepage.vast.projector.ProjectorHomeActivity.
