# TCL 58S571F (TCL Fire TV, S5 series, AFTDEC012E, codename ginza, MediaTek merak / mt5896), Fire OS 8 / Android 11
# (SDK 30), firmware RS8185.3885N, US. Same Fire OS 8 generation as hisense-fire-tv-aftcibfbd1/ and its notes apply
# here; this list adds what this TCL set ships on top: OpApp, the KSO service, Luna, News, Gallery and System Status.
# The same AFTDEC012E platform is also in examples/tcl-43s450f-ca/ (the S4 sibling) and examples/amazon-fire-tv-aftdec012e/.
#
# FIRE OS: DEBLOAT ONLY. com.amazon.tv.launcher keeps Home and also owns the full Settings grid on this firmware
# (MainSettingsActivity), so it must stay enabled. Live TV app: com.amazon.tv.livetv.
#
# Apply:  TV_HOST=<tv ip> tools/disable.sh examples/tcl-58s571f-fire-tv/debloat.txt
# Undo:   TV_HOST=<tv ip> tools/restore.sh examples/tcl-58s571f-fire-tv/debloat.txt com.amazon.tv.launcher
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
#
# Lived with since 2026-10-20 (the last group since 2026-10-21), through several reboots: Netflix, YouTube
# (SmartTube), Spotify, Stremio, AirPlay from an iPhone and a Mac, and Settings all work.
# Every package stayed disabled across reboots.
#
# Fire OS 8 notes (as on the Hisense):
# - com.amazon.vizzini (Alexa voice) comes back at every boot, so it is not listed. Setting secure voice_disabled=1
#   turns voice off, but Fire OS resets it at boot too.
# - com.amazon.ftvads.deeplinking and com.amazon.device.crashmanager are protected (pm disable-user is refused).
# - com.amazon.device.telemetry.emitter disables, but its native emitter keeps running outside ActivityManager.
#
# Kept on purpose: AirPlay, Miracast, Live TV, OTA updates, Silk, Quick Settings, profile picker, and the Appstore
