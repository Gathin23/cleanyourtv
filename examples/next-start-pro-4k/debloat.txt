# ADB: only Wireless debugging. Pair once (Developer options > Wireless debugging > Pair device with pairing
# code), `adb pair <ip:pairport> <code>`, `adb connect <ip:port>`, then `adb tcpip 5555`. persist.adb.tcp.port
# stays 5555, and port 5555 answered after later reboots. ro.adb.secure=1, so each computer is accepted on screen.
#
# Setup wizard (com.google.android.tungsten.setupwraith):
# - With launcherx disabled and Projectivy as Home, setupwraith's RecoveryActivity took HOME and system_server
#   crashed in a loop (FATAL EXCEPTION IN SYSTEM PROCESS: android.display, positionChildAt ... is not a child),
#   as described in docs/TROUBLESHOOTING.md. Disabling setupwraith stopped it.
# - The box then dropped off Wi-Fi: the network had been saved during setup, so it belonged to setupwraith.
#   Re-joining it in Settings fixed it (owner now android.uid.system). tools/disable.sh checks this for you.
# - The Cast credentials provider lives in setupwraith here too (CastInfoProvider), yet casting YouTube from a
#   phone still worked four days and several reboots after disabling it, unlike on the Google TV Streamer list.
#
# AUDIO (Realtek Dolby MS12, soundbar over HDMI). See README.md in this folder for the logs.
# - With Settings > Display & Sound > Advanced sound settings > Surround sound = Always
#   (settings global encoded_surround_output=2), ExoPlayer apps (Stremio, Nuvio) open a DIRECT E-AC3 track and
#   the sound stutters about once a second on a Samsung HW-Q990C. Never (=1) stops the stutter, but the
#   soundbar then reports 2-channel PCM.
# - Fix: keep Surround sound on Never and set Realtek's hidden "Preferred MS12 output" page to
#   "Dolby Digital Plus/Dolby Atmos" (2nd entry; the list is MAT, DD+/Atmos, PCM, DD/AC3):
#     adb shell am start -n com.android.tv.settings/.slice.SliceActivity \
#       -d content://com.realtek.slices.sliceprovider/ms12 --es slice_uri content://com.realtek.slices.sliceprovider/ms12
#     adb shell input keyevent DPAD_DOWN; adb shell input keyevent DPAD_CENTER
#   logcat then reads `GetAudioMs12OutputMode ... mode=2`. It survives reboots (checked twice). Result: no
#   stutter and the Q990C shows Dolby Atmos for an E-AC3 Atmos stream in Stremio.
# - The box ships with HDMI-CEC auto wake/standby off; left that way.
#
