# Formovie Laser 4K projector (codename hanlla, MediaTek T31 / m7632), Android TV 14 (SDK 34),
# firmware UKNV.260619.001. Classic Android TV home (com.google.android.tvlauncher), not Google TV.
# Live TV / input app: com.mediatek.wwtv.tvcenter (already live_tv_package and hidden in config.xml).
# Stock launcher: com.google.android.tvlauncher (build-and-install.sh finds it by itself).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/formovie-laser-4k-hanlla/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/formovie-laser-4k-hanlla/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# A light list: there is no Formovie ad or content service on this build, and the projector's own
# apps carry the features. Keep: cn.formovie.projectormanager (persistent; BLE remote service, global
# keys, projector settings: focus, keystone), com.formovie.launchboard (all-apps overlay on a remote
# key), cn.formovie.fengos.usermanual, com.fengmi.testsuite (factory tests, left alone), fusion.android.tv.demo (listens
# for the input/source button), com.mediatek.* (tv service, tvinput, tvcenter, autopair = BT remote
# pairing), com.dolby.android.audio.service (Dolby / optical out), com.mstar.android.tv.disclaimercustomization.
# Never launch mediatek.factorymenu.ui.
# Already disabled at the factory: com.google.android.play.games, com.google.android.youtube.tvmusic,
# com.google.android.videos.
# The only Ethernet is the built-in RJ45 (eth0); USB debugging does not affect it.
# 1.8 GB RAM. Default IME is Gboard.
#
# Second unit: sold as Formovie Theater (first generation). Same ro.product.model
# "Formovie Laser 4K projector", device hanlla, board m7632 and build UKNV.260619.001
# (ro.vendor.mtk.system.marketregion=eu). Differences from the first unit:
# - Tested on Wi-Fi. It has the same built-in Ethernet port (eth0) as the first unit, but that was
#   not tested.
# - Nothing came disabled from the factory: Play Games, YouTube Music and Play Movies were enabled.
# - A second Play auto-installer, android.autoinstalls.config.formovie (correct spelling), sits next
#   to the "fomovie" one. Both were disabled here.
# - No tuner: the TV input framework lists HDMI 1 to 3 only (com.mediatek.tvinput HW5 to HW7). An empty
#   live_tv_package in config.xml drops the Inputs menu's Live TV row, which leads nowhere here.
# - HDMI from the launcher's Inputs menu opened Android's "Open with" chooser: Google Live Channels
#   (com.google.android.tv) claims the vnd.android.cursor.item/channel MIME type next to tvcenter
#   (Tivify claims it too). Choosing "Always" on the wrong row sends HDMI to Live Channels for good.
#   Disabling Live Channels sends HDMI straight to tvcenter (commented out below, since a unit
#   that uses Live Channels would lose it).
# - com.softmedia.receiver.lite (an AirPlay/DLNA receiver that starts at boot) was installed.
# - With tvlauncher disabled, Home, Back, Input, Settings and volume on the remote all still work, and
#   a held Volume Up still ramps. No key helper service is needed.
# - Nothing was re-enabled after a reboot. ADB on port 5555 is back about two minutes after boot.
# - wm size reports a 1920x1080 override on the 3840x2160 panel out of the box; leave it alone.
