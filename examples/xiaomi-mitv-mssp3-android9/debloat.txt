# Xiaomi MiTV-MSSP3 (codename machuca), Android TV 9 (SDK 28), firmware PI.7524, MediaTek, 1.8 GB RAM.
# Same model as examples/xiaomi-mitv-mssp3 on its older Android 9 firmware, before the Android 11 update.
# Live TV app: com.mediatek.wwtv.tvcenter (already the live_tv_package in launcher config.xml).
# Stock launcher: com.google.android.tvlauncher (the default, disabled by build-and-install.sh).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-mssp3-android9/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-mssp3-android9/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Notes from this firmware:
# - Before: swap full (200 of 200 MB) and over 200% iowait a few minutes after boot, so the UI froze.
#   After this list and the launcher: about 900 MB available instead of 570, swap nearly empty, no iowait.
#   The load average stays near 100 either way: MediaTek kernel threads (VMon_Task, DMX_Filt_Task,
#   hdcp22_hdmi_rx_) sit in D state permanently and count towards it while the CPU is idle.
# - USB debugging alone opens port 5555; there is no network debugging toggle.
# - Default IME is already Gboard and every package below exists on this build.
# - The stock screensaver is com.mitv.dream/com.mitv.dream.MiDream, disabled below; point it elsewhere:
#     settings put secure screensaver_components com.gathin.tvhome/.ClockDream
# - The voice assistant (katniss) does not stay disabled: at every boot the package manager rescans it
#   as an updated system app ("Expecting better updated system app for com.google.android.katniss"
#   in logcat -b events) and it comes back enabled, bound as voice_interaction_service. Disabling it is
#   all this list does. Beyond what this repo does, and your own call: removing it for user 0 and
#   clearing the voice services held across reboots here
#     settings put secure voice_interaction_service ''
#     settings put secure voice_recognition_service ''
#     pm uninstall --user 0 com.google.android.katniss
#   and is undone with
#     cmd package install-existing com.google.android.katniss
#     settings put secure voice_interaction_service com.google.android.katniss/.search.serviceapi.KatnissVoiceInteractionService
#     settings put secure voice_recognition_service com.google.android.katniss/com.google.android.apps.tvsearch.voice.recognition.KatnissRecognitionService
# - Left alone on purpose: com.mediatek.wwtv.tvcenter / tvinput* (HDMI + tuner), mitv.service,
#   com.xiaomi.mitv.mediaexplorer (Media Player), com.google.android.tv.remote.service.
# - Netflix, Prime Video, Pluto TV, YouTube Music and Chromecast kept by choice; com.mstar.netflixobserver
#   starts Netflix at boot (about 130 MB) and needs the same treatment as in examples/xiaomi-mitv-mssp3.
#
# Older Android 9 firmware PI.4663 (ro.build.display.id "PI.4663 release-keys", same 1.8 GB set), Italy:
# - com.mitv.tvhome.michannel and com.mitv.dream are not installed. The screensaver there is
#   com.google.android.backdrop/.Backdrop, which this list already disables.
# - The older Android TV home is still installed and enabled next to tvlauncher, and its receiver runs at
#   every boot: com.google.android.leanbacklauncher and com.google.android.leanbacklauncher.recommendations.
#   Both disabled here with the CleanYourTV launcher as Home, and Home kept resolving to it.
# - The voice assistant stayed disabled across a power cycle on this build (pm list packages -d a minute
#   after boot), unlike PI.7524 above.
# - After 7 days of uptime MemAvailable was about 740 MB and adbd stalled; a minute after a cold boot with
#   this list and the launcher it was about 850 MB.
