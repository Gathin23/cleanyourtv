# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.

# Stock launcher: com.google.android.apps.tv.launcherx (HOME priority 2), with the setup wizard's
# RecoveryActivity at priority 1, so setupwraith is listed below (see docs/TROUBLESHOOTING.md, Google TV).
# Wireless debugging is the way in: pair, then `adb tcpip 5555`. It turns itself off whenever the projector
# rejoins Wi-Fi. Already disabled from the factory: com.google.android.youtube.tvmusic.
#
# Launcher notes (applied and verified on a real unit on 2026-10-19/20):
# - Install with HOME_KEY_SERVICE=1, and put this in config.xml or a theme's config.json:
#     "live_tv_package": ""                    no tuner
#     "settings_key_keycodes": [83]            the gear button sends KEYCODE_NOTIFICATION
#     "app_keys": ["KEYCODE_F4:com.google.android.youtube.tv",
#                  "KEYCODE_F9:com.netflix.ninja",
#                  "KEYCODE_F8:com.amazon.amazonvideo.livingroom",
#                  "KEYCODE_F5:mute",
#                  "KEYCODE_F6:ignore"]
#     "stock_home_redirect": "com.google.android.apps.tv.launcherx"
#   XGIMI's xrmservice re-enables the disabled stock launcher on every one of its remote keys
#   (docs/TROUBLESHOOTING.md). app_keys takes YouTube (F4), Netflix (F9), Prime Video (F8), the programmable
#   button (F5, mute by default) and the profile button (F6) away from it; only power (F11) still revives it,
#   and stock_home_redirect sends its home screen back.
#   Left to xrmservice, the profile button starts launcherx's profile chooser, which a disabled launcherx no
#   longer has: xrmservice crashes, and about 11 s after each restart the projector runs its autofocus.
#   "KEYCODE_F6:ignore" takes the button so nothing crashes; it then does nothing (verified 2026-11-03).
# - HDMI 1 opens through com.google.android.tv.inputplayer from the Inputs menu, so no input_action is needed
#   (unlike the Horizon S Pro).
# - The default Backdrop screensaver (dreamx) is disabled below: point the screensaver at
#   com.android.dreams.basic/.Colors first, or it has nothing to show.
# - Check who owns the saved Wi-Fi network before setupwraith is disabled (TROUBLESHOOTING, "drops off Wi-Fi for
#   good"): on this unit the network set up during first-run setup disappeared and had to be joined again.
# - Screenshots from `screencap -p` start with a vendor log line ("Init wrapper sys mutex ..."): strip
#   everything before the PNG signature.
#
