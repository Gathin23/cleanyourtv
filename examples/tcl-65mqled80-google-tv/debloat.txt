# TCL 65MQLED80 Google TV, Norway (device G08, model "Smart TV Pro", MediaTek tcl9618)
# Android 14 (Google TV), firmware UTT2.250416.001 AU02. Same board and firmware build as
# examples/tcl-65c7l-google-tv and examples/tcl-c755-google-tv; the 65C7L list was the starting point.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-65mqled80-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-65mqled80-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# ADB: USB debugging alone opened port 5555 (Wireless debugging stayed off). Built-in Ethernet.
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.tcl.tv.
# Keep (as on the C755/65C7L): com.tcl.tv, com.tcl.tvinput, com.tcl.suspension (the Input button's source
# panel), com.tcl.dashboard, com.tcl.autopair, com.tcl.systemserver, com.tcl.providers.config,
# com.tcl.initsetup, com.tcl.factory.view, com.tcl.inputmethod.international, com.tcl.globalkeyoverlay,
# com.google.android.tv.remote.service and all com.mediatek.* except AirPlay. com.tcl.hotelmenu is not
# installed on this model. The TCL soundbar updater (com.tcl.UpdatePeripheral) was left on; firmware
# updates come through Google Play Services.
#
# Applied 2026-10-30 on a real unit in seven batches with screenshots between them, then reboot-checked twice:
# all 32 packages stayed disabled, nothing is re-enabled at boot, and power-on lands on the new Home (not
# Live TV). All four HDMI inputs, AV and the tuner stayed registered in tv_input, Live TV opened from the
# launcher's Inputs menu, and YouTube loaded with AdGuard Private DNS. One session; not yet lived with for days.
#
# Known quirks on this firmware:
# - The saved Wi-Fi network belonged to setupwraith (dumpsys wifi: cname=...setupwraith) although the TV runs
#   on Ethernet. The owner let it go: FORCE_SETUPWRAITH=1 disabled setupwraith, Android deleted that network,
#   Ethernet was unaffected. On Wi-Fi, forget the network and join it again in Settings first.
# - Unlike the 65C7L, four remote buttons went dead with launcherx disabled: gear (keycode 83, scancode 561),
#   YouTube (190, 569), Netflix (4062, 566) and Prime Video (4099, 752). Input (178, KEYCODE_TV_INPUT) and
#   volume kept working. HOME_KEY_SERVICE=1 with this folder's config.json brought all four back (pressed on the
#   real remote). The cost: a held Volume Up (sent over CEC to a soundbar here) moved about two steps instead
#   of ramping, reported by the owner, not measured (docs/devices/tcl-55p71b-g09-key-repeat.md).
# - Disabling dreamx: set screensaver_components to com.gathin.tvhome/.ClockDream first.
