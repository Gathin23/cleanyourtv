# DO NOT DISABLE on this EU set — each was reproduced here (2026-10-22), none is in the Brazilian list
# as an active line except the first four and com.tcl.guard, which broke as follows:
# com.tcl.ttvs         - TIAS chain. Off, com.tcl.tv's embedded tbrowser client logs
#                        "vendor.tcl.tvinput.extend-service: Passing null binder object as
#                        non-@nullable AIDL IBinder" plus a Tbrowser NullPointerException at
#                        Tbrowser.java:600, about ten times a second, indefinitely. Cheap (~1% CPU)
#                        but endless. Re-enabled, the log went to zero.
# com.tcl.interactive  - the TIAS service itself; same signature when it alone is off.
# com.tcl.channelplus  - TCL's Live TV source loses its channel list.
# com.tcl.waterfall.overseas - same Live TV source dependency here.
# com.tcl.suspension   - hosts the source-menu QuickPanel. Off, the remote's Source key
#                        (KEYCODE_TV_INPUT, 178) is silently dead. Verified working on this set.
# com.tcl.autopair     - Bluetooth remote pairing. Off, an unpaired remote can never pair again.
# com.tcl.miracast     - the only "cast screen" route on this set. Chromecast is a different
#                        package (com.google.android.apps.mediashell) and is untouched.
# com.tcl.t_solo       - Bluetooth speaker output ("listen alone"), kept by the owner.
# com.tcl.eva          - TCL's own voice layer; com.google.android.katniss is the other one.
# com.tcl.guard        - system retried .memorymanager.TGuardService every 5 s while it was off.
# com.tcl.hearaid      - hearing aids, wireless speakers, sound field.
# com.tcl.UpdatePeripheral - remote / soundbar firmware updates.
# com.tcl.gamebar      - runs under android.uid.system; holds a SourceReceiver on the input path.
# com.tpa.kb           - runs under android.uid.system; purpose unknown.
# com.tcl.dashboard    - kept for parity with Free My TV's PROTECTED list (it pushes tcl:// rows on
#                        other TCL boards). Off on this set for five days with nothing missed.
# com.tcl.android.webview - kept for parity with Free My TV's PROTECTED list even though
#                        com.google.android.webview is the active one here.
# com.mediatek.network - kept: it may carry cast/DLNA on this board and nobody has shown otherwise.
