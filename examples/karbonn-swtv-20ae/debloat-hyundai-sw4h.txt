# Hyundai TV (Hyundai-branded Skyworth OEM, device SW4H, product SW4H_B), Android TV 10 (API 29),
# firmware QTG3.200617.002, security patch 2021-10-05.
# Unit 4 of this folder: same build and same device as Units 1-3, sold under the Hyundai name in
#   Latin America. ro.product.manufacturer=skyworth, armeabi-v7a, ~1.6 GB RAM (MemTotal 1724616 kB),
#   1920x1080 at 320 dpi.
# Stock launcher: com.google.android.tvlauncher (classic Android TV home, not Google TV launcherx).
# Live TV: com.smartdevice.livetv. Inputs: com.mediatek.tvinput. Never disable a com.mediatek.* package.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/karbonn-swtv-20ae/debloat-hyundai-sw4h.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/karbonn-swtv-20ae/debloat-hyundai-sw4h.txt com.google.android.tvlauncher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
# Order: install the launcher first (launcher/build-and-install.ps1 -TvHost <ip>), then this list; the
# stock launcher is left to that script and is only named in a comment here.
#
# Status: applied 2026-11-24 in one session from Windows over Wi-Fi, after the CleanYourTV launcher had
# taken Home; one reboot, every disable held. Not yet lived with for days: this PR stays a draft until
# it has been in daily use, and this line moves with it.
#
# Nothing was re-enabled so far. The set was chosen by measuring what ran at boot on this unit:
# available RAM went from 770 MB to 902 MB and swap in use from 186 MB to 20 MB after it plus the
# launcher, which is what made the set worth writing down (1.6 GB of RAM).
#
# Arrived with com.sky.market and com.smartdevice.tvworkwithalexa already disabled by the firmware, so
# neither is listed here. Wi-Fi belongs to android.uid.system on this unit
# (dumpsys wifi shows only cname=android.uid.system), not to setupwraith.
# Remote keys: the Netflix button and the nine-dot APPS key route through com.mediatek.partner.netflix,
# which stays enabled. fusion.android.tv.demo stays enabled as well, as on Units 1-2, so the physical
# Input key keeps reaching the TV tuner; the launcher's Inputs menu lists HDMI and Live TV without it.
