# (com.google.android.apps.tv.launcherx), 2 GB RAM, 32-bit userspace.
# List derived from examples/tcl-43c645 (same R51MT platform), checked against this unit's packages.
# Same firmware family as examples/tcl-65q550g (a different model, tested over Ethernet there).
#
# Tested 2026-10-20 on a real unit, applied in three batches with a screenshot after each: Home, the
# remote's Input panel (com.tcl.suspension) and Live TV (com.tcl.tv/.TVActivity, all four HDMI ports in
# TvInputManager) kept working. Quirks: Git Bash rewrites /data/... paths for tools/tv.py --pull, so set
# MSYS_NO_PATHCONV=1; screencap to /sdcard fails here, use /data/local/tmp. Launcher installed with
# tools/tv.py --push + pm install, later with build-and-install.sh (b64push md5 matched). Reboot-checked: all
# packages stayed disabled, Home stayed on the new launcher, both key services re-bound.
#
# Stock launcher: com.google.android.apps.tv.launcherx (disabled by build-and-install.sh). setupwraith claims
# HOME (priority 1) once it is off, so it is in group 1b. Check `dumpsys wifi | grep -o 'cname=[^ ]*'` first:
# on this unit the Wi-Fi network in use belonged to android.uid.system, so disabling setupwraith kept it.
#
# Remote (Bluetooth BT_RC813_M1, /dev/input/event3, /system/usr/keylayout/Generic.kl):
# - Input (TV_INPUT) and the mic keep working without launcherx.
# - Netflix (242, TCL_NETFLIX), YouTube (245, TCL_YOUTUBE) and Prime Video (752, TCL_PRIMEVIDEO) do nothing
#   once launcherx is off: app_keys KEYCODE_TCL_NETFLIX:com.netflix.ninja, KEYCODE_TCL_YOUTUBE:
#   com.google.android.youtube.tv, KEYCODE_TCL_PRIMEVIDEO:com.amazon.amazonvideo.livingroom with
#   INPUT_KEY_SERVICE=1 bring them back (getevent -l names Prime KEY_PRIMEVIDEO; its scancode is 752, not 365).
# - Gear (233, TCL_SET) also went dead; app_keys KEYCODE_TCL_SET did not catch it, settings_key_scancodes 233
#   with HOME_KEY_SERVICE=1 did.
# - TclAppBoot refuses to start the key services at boot until `appops set com.gathin.tvhome APP_AUTO_START allow`.
# All verified with the real remote, also after a reboot. Live TV app: com.tcl.tv (live_tv_package, hidden_apps).
