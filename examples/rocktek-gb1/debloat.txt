# Home handover:
# - The stock Google TV home is com.google.android.apps.tv.launcherx. build-and-install.sh disables it
#   only after com.gathin.tvhome has become Home, so it is left commented below.
# - com.google.android.tungsten.setupwraith was disabled on this box so the replacement Home can stay in
#   charge. Before applying the line, check whether it owns the saved Wi-Fi network: disable.sh will
#   refuse it while it does. Rejoin the network in Settings first if necessary, and re-enable it before
#   a factory reset or remote re-pairing. Disabling it gives Home back but may cost casting.
# - With launcherx disabled, the gear and Macro buttons that Google TV Home handled initially stopped
#   working. examples/rocktek-gb1/config.json restores them through HomeKeyService: gear is Android
#   keycode 83 and opens TV Settings; Macro is KEYCODE_GUIDE (172) and opens com.seena.app. Enable
#   HomeKeyService at installation and test the physical remote, not an injected key. Other branded
#   buttons are untested; see examples/rocktek-gb1/README.md before adding a mapping.
